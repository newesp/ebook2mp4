# 啟動時載入上次專案

2026-11-06 使用者追加需求：開啟 APP 時，自動載入上次載入的專案。

- 正式 APP 啟動時讀取本機最後一次成功開啟或建立的專案位置，沿用 ProjectWorkflow.open 驗證來源與內容後，載入工作台。
- 只恢復已保存的專案資料。沒有批次時停在匯入頁；有批次時載入第一個批次及其已保存校對稿。不恢復未存編輯、播放器或製作任務。
- 手動開啟取消、開啟失敗、建立取消或失敗，不改最後成功記錄。
- 首次啟動沒有記錄時維持原空白工作台。專案不存在、無法讀取或損壞時不阻止啟動，在既有狀態列顯示原因及手動開啟路徑。不建立新專案、不修復或覆寫原資料。
- 本機設定損壞時仍可手動開啟。設定保存失敗不影響已載入的專案，並提示無法記住位置。
- 記錄預設為 `%LOCALAPPDATA%/ebook2mp4/session.json`，與書籍專案及正式程式分離。`EBOOK2MP4_APP_HOME` 可覆寫設定目錄，供隔離驗證使用。
- 沿用目前 UI，沒有版面調整。T20 草圖仍待核准，本追加需求不表示核准 T20 實作。

驗收路徑：

1. 專案 → 開啟專案 → 選取有效 project.json。
2. 關閉 APP → 重新啟動 → 確認同一本書與已保存校對稿已載入。
3. 手動取消開啟另一個專案 → 重新啟動 → 確認仍載入上一個成功專案。
4. 將測試專案移走 → 重新啟動 → 確認空白工作台及無法自動載入提示。
5. 專案 → 開啟專案 → 選取另一個有效專案 → 確認可正常工作。
