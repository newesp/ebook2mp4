# 語音流程 mock 涵蓋

僅 HTML 示範，狀態保存於 `S.voice`。不存檔、不送出網路請求、不讀取金鑰、不播放真實聲音。使用既有工作區 CSS；固定操作列由主檔放置，僅內容各自捲動。

## 操作與可觀察結果

- 語音設定 → 選已存設定／全書預設／歷史任務 → 按載入 → 檢查服務、音色、語速、節奏已更新。返回後保留文字與草稿。
- 語音設定 → 切換 Edge、Gemini、Fish、Kokoro → 檢查模型、語系、聲音 ID、音色更新或本機包入口依情境顯示。
- 輸入自訂模型／音色 → 儲存 → 切換內頁後返回 → 檢查值保留。更新清單不清除自訂值。
- 選自然／舒緩 → 檢查停頓為 0/500 或 200/800 ms。輸入自訂停頓 → 儲存 → 檢查整數範圍錯誤提示。
- 取消雲端同意 → 檢查產生試聽停用。改用本機 → 檢查雲端同意改為本機提示。
- 產生試聽 → 模擬任務結束 → 檢查成功、連線失敗、儲存失敗。取消 → 檢查上一份成功試聽保留。重播／停止更新可見狀態。
- 服務 → 新增／編輯 → 檢查連線 → 模擬成功／失敗／取消 → 儲存返回 → 檢查文字與節奏保留。金鑰僅提供示範選項。
- 服務 → 修改後返回 → 檢查放棄修改確認。刪除 → 檢查名稱、影響及保留／刪除確認。內建服務不提供刪除。
- 全書預設 → 儲存 → 套用到既有批次 → 選取批次 → 檢查語音更新／重組／相同設定影響 → 套用 → 檢查選取及舊成品保留。
- 本機包 → 選擇示範 ZIP → 匯入 → 模擬成功／驗證失敗／取消 → 檢查原有效安裝保留。移除需確認。
- 設定 `S.projectBusy=true` → 檢查衝突變更、服務儲存、套用及語音包管理停用。

## 限制

所有工作階段由使用者按示範完成控制，沒有背景計時器。音色清單僅保留代表候選，不列出全部 Kokoro 音色。批次與歷史記錄為固定示範資料。無 OS 檔案對話框、真實音訊、憑證、網路或檔案操作。原生的跨視窗未儲存變更衝突、外部移除服務、全書預設外部更新與底層檔案驗證仍須實作時沿用原有保護。
