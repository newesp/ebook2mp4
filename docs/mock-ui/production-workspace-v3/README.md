# 試聽與成品 mock v3

開啟 index.html。此版取代 v2 作為下一輪設計討論稿；尚未通過瀏覽器視覺驗收，不可當成已核定的實作規格。正式 APP 與 dist 未修改。

## 本輪修正

- 文件列表：修正 aside ID 規則蓋過隱藏規則的問題。收合後移除側欄與間距，主工作區使用全部欄寬。保留重新開啟按鈕、提示與 aria-expanded。
- 導覽：語音設定與試聽 →〔本批音訊／影片製作〕→ 全書合併 → 全書成品。括號內為相關工作，不表示必須先完成本批影片才能合併音訊。
- 子頁：任務來源、區塊詳情、重新開始均選定本批音訊；接點頁選定全書合併。以底線、背景與 aria-current 標示位置。
- 本批音訊：縮短摘要；上一版成品摘要改為一列；播放、另存、資料夾、影片入口與任務動作合併到固定操作列。空間不足才換列。區塊清單取得其餘高度。
- 全書合併：固定顯示來源／設定／結果切換列與完成摘要，不再把結果堆到頁底。表格及獨立內容頁各自捲動，底部主要動作固定。檢查接點按鈕使用內容寬度。
- 影片：使用共用製作頁，切換本批／全書範圍。兩個範圍的素材、來源、任務與成品仍獨立。全書的「總音訊製片／合併既有批次影片」契約保留；成品頁可返回對應製作入口。
- 語音設定與試聽：voice.js 與 v2 完全相同，本輪未調整該頁布局。

## 設計依據

使用指定 ui-ux-pro-max skill：Navigation / Active State 與 quick-reference 的一致性、單一主要操作、圖示狀態規則。漸進展開搜尋兩次未取得符合情境的結果；面板空間策略依 frontend-visual-qa 的主要區域空間預算、專用視圖與固定操作原則。

## 驗收路徑（待實際瀏覽器驗證）

使用 CSS viewport 1536×864、1280×720，並測試瀏覽器 100% 與 125% 縮放。不以縮小至 80% 作為合格條件。

1. 開啟本批音訊 → 收合文件列表 → 確認側欄消失且主區填滿 → 展開 → 確認選取保留。
2. 開啟任務來源 → 確認本批音訊仍有底線及選取背景 → 返回。
3. 以 251 個區塊顯示清單 → 1536×864 目標至少 6 列、1280×720 目標至少 4 列 → 捲至最後一列 → 確認底部操作仍可見。此為驗收目標，尚未量測。
4. 開啟全書合併 → 切換來源、設定、結果 → 確認切換列與主要按鈕保持可見 → 啟動任務 → 確認自動切到結果。
5. 設定本批素材 → 切到全書素材 → 再返回 → 確認兩份設定獨立保留。
6. 製作兩種輸出 → 模擬 MP4 失敗 → 重試 → 確認成功的 MP3 保留。

## 已驗證與限制

node verify.cjs：34 項頁面、事件語法、狀態、導覽歸屬、收合狀態及範圍保留檢查通過。程式檢查不能證明像素布局、滑鼠滾輪或鍵盤捲動可用。

本機 HTML 的瀏覽器工具存取被 URL policy 阻擋，因此沒有新截圖、沒有完成上述尺寸驗收。未啟動測試伺服器、媒體程序或建置工作。

全部功能仍使用記憶體示範資料；播放、另存、檔案選擇與服務請求不執行真實操作。原始功能對照見 voice-coverage.md、video-coverage.md；本文件的 v3 布局說明優先於舊版布局描述。
