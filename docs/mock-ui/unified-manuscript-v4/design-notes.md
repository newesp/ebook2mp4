# 第四版互動設計稿

開啟 index.html。這是本機、無外部依賴的 HTML mock，尚未核准或整合至正式程式。AI、保存、來源處理及專案操作是明示的示範，不會操作正式資料。

## 設計決策

- 文件清單標頭使用「匯入」「管理」同列。常用匯入不藏選單；偶用管理操作放選單，刪除操作以分隔線區分。相較上下排列少占高度；相較合併選單減少匯入的尋找與點擊。
- 三個主要內容容器共用 48px 標頭高度與同一網格起點。文件清單、PDF、編輯器的上緣齊頭；PDF 與文稿等寬。文件標題與操作都位於各自區塊。
- 文件名稱、範圍、版本、字元數與草稿狀態集中在底部。頁碼與縮放留 PDF 區；比較基準留版本區；錯誤應靠近可處理它的控制項。底部保留簡短結果與訊息紀錄入口。
- 文稿設定改名 AI 設定，內容限 AI 模型、字體轉換、標點及服務設定。編輯字級應歸文稿顯示設定，不能因改名就一起塞入 AI 設定。
- 版本紀錄、AI 設定、來源處理採同窗內容切換。文件清單保留，右側完整工作區切成工具頁；返回時原編輯 DOM 保留。沒有「外層可捲工具容器再包可捲編輯器／差異」的組合。
- 工具頁固定標頭與底部動作，只有中間內容捲動。版本選擇固定在工具標頭，長差異使用唯一內容捲動區；AI／來源設定不另包內層 scroller。
- 取捨：工具頁開啟時不與文稿同時顯示。來源框選需要原頁的正式流程應在此工具頁內採左右並列「設定／原頁」且各自明確捲動，不能重新堆回編輯器下方。本 mock 尚未涵蓋框選流程。

## 可操作範圍與限制

可操作文件清單收合、管理選單、原稿開關、頁碼、縮放、文字編輯、工具頁切換與返回、AI 設定於此工作階段保留、長內容捲動、訊息紀錄。PDF 使用排版文字示意，不是真正 PDF 渲染；來源連結示範預覽入口，不開真實來源檔。搜尋僅示範查詢與命中計數，文件切換沿用示範內容。尚未實作拖曳分隔線、真實版本還原及完整資料流程。

## 驗證狀態

JavaScript 語法及 ID 唯一性檢查通過。自動瀏覽器啟動未完成，已中止該次執行；內建瀏覽器拒絕 file: 協定，故未取得截圖，未完成實際視覺／捲動／鍵盤驗收。

待驗收：1440×900、1366×768 與縮窄尺寸；三區上緣等高；長文捲至底端；版本差異捲至底端且操作列不動；返回編輯後文字與捲動保留；AI 設定保存後再開；窄視窗原稿／文稿切換與必要按鈕可達。

ui-ux-pro-max 設計系統搜尋偏向行銷頁，未採用其頁面模式；使用其通用一致性、內容優先、可見焦點與滾動區域準則，配合專案綠色系與最新需求。此設計取代先前「匯入放右上」建議，仍待使用者確認。
