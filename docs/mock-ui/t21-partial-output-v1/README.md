# T21 UI 草圖 v1（已核准並實作）

本草圖階段只建立 HTML。使用者隨後核准在同一 session 直接實作，已完成正式程式；驗收見 `../../verification/T21.md`。請用本機瀏覽器開啟 `index.html`。所有書名、批次、結果與任務均為示範資料；不讀書稿、不呼叫 TTS、不產生媒體。

## Ticket 範圍

依 `.scratch/pdf-txt-audiobook-video/v1.1/issues/21-per-format-partial-success-retry.md`，選擇總 MP3、總 MP4 或兩者，保存選擇並分別顯示準備、執行、完成、缺項、失敗與取消。僅全部要求成功才顯示完成；成功格式與同版 SRT 獨立保存。缺項依總音訊製片／批次影片合併區分。可用格式先完成，補素材或重試只做未完成輸出。有效總音訊可重用；MP4 必要時先準備總音訊，循序執行且不新增 TTS。來源失效時須明示更新。

## 設計

沿用 `assembly_desktop.py`、`production_desktop.py`、T20 草圖的淺底綠色桌面工作台。保留左側批次、主要功能導覽、右上影片方式、批次來源表及共用接點設定。在全書合併主頁加入「要求輸出」勾選與最多兩列結果；MP4 單選且缺總音訊時，額外顯示前置總音訊，其完成數不計入要求格式。素材與詳情使用同視窗內頁，返回保留輸出狀態。長清單／詳情各自捲動，主要操作列固定可見。

現行 UI 尚無統一的雙格式結果及續作入口。因此以同一父層 grid 分配來源表的剩餘高度，輸出選擇、結果與主要操作保持自然高度；不把整頁放進捲動區。窄寬度允許工具列換行。實際 1040×640、1360×800 及其他 DPI 的瀏覽器／原生版面仍待目視驗證。

「成品版本」保留 T20 入口，草圖只用摘要示意；正式版須沿用既有三路徑完整版本頁。「影片素材」、接點與合併設定只示意導向，正式版沿用既有功能。重開以記憶體序列化模擬，並非磁碟保存驗收。

## 確認操作

1. 開啟草圖 → 保持預設情境 → 確認顯示「部分完成」及影片缺項。
2. 按「補齊缺項」→ 按「模擬加入素材並返回」→ 確認 MP3 保持完成。
3. 按「只重試未完成輸出」→ 確認只有 MP4 執行 → 確認最後全部要求完成。
4. 選「MP3 可做，批次影片缺項」→ 按「先製作可用的 MP3」→ 確認 MP3 成功與影片缺項同時保留。
5. 選「MP3 失敗，批次影片可合併」→ 按製作 → 確認 MP4 可成功，整體仍為部分完成。
6. 選「只要 MP4，須先準備總音訊」→ 按製作 → 確認先總音訊、後 MP4，要求格式完成數為 1／1。
7. 選「只要 MP4，重用有效總音訊」→ 按重試 → 確認直接執行影片。
8. 選「MP3 成功，影片失敗」→ 按重試 → 按取消 → 確認 MP3 保留且 MP4 已取消。
9. 選「只要 MP3，沒有視覺素材」→ 確認影片方式及素材入口隱藏 → 確認 MP3 可完成。
10. 變更輸出勾選 → 按「模擬重開專案」→ 確認選擇、路徑與結果保留。
