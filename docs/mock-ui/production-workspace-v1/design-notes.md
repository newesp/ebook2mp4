# 製作與合併工作區提案

日期：2026-11-09。入口 index.html。尚未核准或實作原生程式。

## 截圖問題與取捨

- 製作頁同時呈現朗讀長文、區塊清單、重複狀態、尚無成品的播放操作。改以任務狀態與區塊處理為主，全文與詳細設定按需切換同窗工具頁。固定底部主動作，成功後才提供成品操作。
- 重試狀態集中在任務卡，其他頁才顯示返回執行中任務入口；避免同頁重複進度。狀態提示包括下一步與成功結果保留，不以不明灰條代替進度。
- 合併頁的三筆批次占用巨大空白區，而設定／缺項／任務阻擋分散在多列。使用清單與設定／製作前檢查並列，保留長清單伸展及獨立捲動；選取有效批次、排序就近配置。
- 保留無效批次的可見狀態與解除方式，不自動取消使用者選取。來源無效或專案任務衝突時停用製作，原因在製作前檢查中顯示。
- 導覽保留語音設定、製作、全書合併；合併音訊完成後再從結果前往製片。影片輸出入口保留總音訊製片與既有批次影片合併兩種方式；本次不重定義兩格式獨立失效與部分完成契約。
- 傳送同意是語音製作的現有契約，本次保留並預設勾選；取消勾選阻擋開始／續作。不能將先前取消 AI 校對勾選框的指示擴張到語音。

## 可操作情境

製作中、未開始、部分失敗、成功、取消；取消及續作；同意勾選；文件列表收合釋放欄位；批次勾選、選取有效批次、排序；缺項及背景任務阻擋；來源預覽、設定及接點工具頁；模擬合併完成。

模型、朗讀文字、時間與輸出均為示範。沒有雲端請求或真實輸出，聲音播放、素材及檔案操作僅入口示意。區塊明細以 40 列代表長清單，總區塊數 251 為情境資料。影片完整設定、各格式完成狀態、成品版本、實際倒數及長任務更新仍需後續設計／實作。

## 驗證與後續

JavaScript 語法檢查通過；未進行瀏覽器截圖、原生 UI 或執行期互動驗收。未啟動測試服務或正式程式。本次技能搜尋命中通用 Progress Indicators，採其明確步驟與進度回饋原則；其他布局依既有專案約定與截圖分析。

驗收應包含：收合側欄無空軌道；長明細只移動內容；縮小視窗操作可達；取消同意無法送出；忙碌狀態不啟動衝突任務；來源失效不能合併；返回保留選取／順序；失敗與取消保留成功成品。
