# T20 成品版本草圖 v1

狀態：使用者於 2026-11-06 明確要求根據本 HTML 草圖開始實作。實作與驗收見 `docs/verification/T20.md`；以下保留草圖階段的設計與檢查紀錄。

開啟 `index.html`。沿用目前綠色桌面工作台、左側批次清單、製作導覽及全書合併兩步驟。

## 設計

- 在全書合併頁增加「成品版本」，進入同主視窗內頁，返回保留原頁狀態。
- 三列分別顯示總音訊、總音訊製片、批次影片合併。每列顯示狀態、來源摘要及待更新原因。
- 選取一列，再按「查看來源與版本」。比較成品快照與目前設定；技術識別與檔案參照按需展開。
- 操作列固定在下方。舊成品可播放及另存同版 SRT；更新操作依路徑導向適用的來源或製作頁。
- 不增加獨立視窗，不加入全頁捲動；列表與來源詳情分別在內容區捲動。外層 grid 使用 `minmax(0,1fr)`，避免長內容擠出底部操作。

## 操作確認

1. 按「成品版本」→ 檢查三條路徑 → 確認狀態及來源分開顯示。
2. 選「更換全片背景」→ 檢查版本清單 → 確認只有總音訊製片待更新。
3. 選「更換 A 批次畫面」→ 檢查版本清單 → 確認只有批次影片合併待更新。
4. 選「修改未選 C」→ 檢查版本清單 → 確認三條路徑仍有效。
5. 選「修改 A 朗讀稿」→ 按「查看來源與版本」→ 確認更新來源指引。
6. 選「更新總音訊版本」→ 檢查影片來源 → 確認舊影片仍使用總音訊 v3。
7. 選「更改共用順序／停頓」→ 檢查清單 → 確認三條總成品待更新。
8. 選「任務中修改設定」→ 檢查提示 → 確認本次使用啟動快照且衝突操作停用。
9. 選待更新成品 → 按「播放上一版」→ 確認模擬播放提示。
10. 按「返回全書合併」→ 檢查批次清單 → 確認原選取仍保留。

所有版本、來源、任務及檔案操作均為示例。未讀取真實專案；未執行 TTS、FFmpeg、檔案匯出或持久保存。情境選單只示範狀態，不會實際編輯來源。
