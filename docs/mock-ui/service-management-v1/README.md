# 試聽與製作：服務編輯與刪除提案

2026-11-05。使用者已核准編輯頁，並要求改用右側單一「新增／管理服務…」下拉入口。HTML 已同步更新，正式程式驗證見 [服務管理驗證](../../verification/service-management.md)。

開啟 [互動 mock](index.html)。沿用正式程式的綠色、微軟正黑體與主視窗內頁。示範服務來自截圖中的類型與名稱，金鑰皆為空，不存取任何本機設定，也不呼叫服務。重新整理會重設示範修改。

## 設計決策

- 試聽頁：保留右側單一「新增／管理服務…」入口。下拉選單提供「新增服務…」及「編輯目前服務…」。直接編輯目前選定的自訂服務，省去到設定頁再次找設定檔。
- 編輯頁：在原主視窗切換內頁。固定服務類型，允許修改顯示名稱、金鑰及 Gemini 校對金鑰沿用選項。金鑰留白保留原值。名稱不強制加上技術識別碼，識別碼在詳情中查看；原有重名服務以目前名稱保留識別尾碼。
- 儲存：回到試聽頁並選用該服務。保留試聽文字、節奏與範圍；重新驗證試聽結果。新增不同類型服務時使用該類型預設模型，音色須重新核對。
- 取消：有修改時在頁內確認放棄，否則直接返回。檢查連線不隱性儲存；檢查中停用衝突操作，提供取消檢查。
- 刪除：編輯頁下方顯示紅色次要操作；按下後在頁內說明影響並要求確認。刪除成功才返回，將目前服務切到 Edge-TTS，清空音色並使舊試聽結果失效。既有音訊、字幕與稿件保留；其他引用該設定的批次下次使用前須重新選服務。刪除沿用校對金鑰的服務不刪除共用校對金鑰。
- 內建服務：Edge-TTS 的編輯選項停用並標明內建服務不適用。選 Kokoro 時，第二個選項改為「管理本機語音包…」，不將內建服務當成自訂設定刪除。
- 縮小視窗：上方操作列換行。桌面表單獨立捲動，底部操作列固定；窄螢幕改為單欄。

## 確認設計的操作路徑

以下「編輯服務」與「新增服務」均由右側「新增／管理服務…」下拉選單進入。

1. 選擇「Google Gemini TTS · 51cfff」 → 展開「新增／管理服務…」 → 選「編輯目前服務…」 → 確認載入該服務名稱。
2. 修改名稱 → 金鑰留白 → 按「儲存並返回試聽」 → 確認選單顯示修改後名稱。
3. 按「編輯服務」 → 修改名稱 → 按「取消並返回試聽」 → 按「繼續編輯」 → 確認修改仍在。
4. 按「取消並返回試聽」 → 按「放棄修改並返回」 → 確認選單名稱未變。
5. 按「編輯服務」 → 按「刪除此服務」 → 按「保留服務」 → 確認仍在編輯頁。
6. 按「刪除此服務」 → 按「確認刪除服務」 → 確認返回試聽頁且選用 Edge-TTS。
7. 開啟服務選單 → 確認已刪除項目消失 → 確認試聽文字保留。
8. 選擇 Edge-TTS → 展開管理選單 → 確認編輯選項停用。選擇 Kokoro → 確認第二個選項為語音包管理。
9. 按「新增服務」 → 選 Fish Audio → 確認不顯示 Gemini 金鑰沿用選項。
10. 新增頁保留空白金鑰 → 按儲存 → 確認顯示欄位錯誤。
11. 在編輯頁按「檢查連線與音色」 → 確認儲存與刪除停用 → 按「取消檢查」 → 確認恢復操作。
12. 返回試聽頁 → 取消文字傳送同意 → 確認線上試聽按鈕停用。

HTML 僅模擬成功與取消狀態。正式程式另有設定檔讀寫與服務檢查錯誤處理；失敗時不移除服務。既有批次引用已刪除服務時沿用未連結服務提示。
