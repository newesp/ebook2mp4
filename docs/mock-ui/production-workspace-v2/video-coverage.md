# 影片與全書合併 mock 覆蓋

本模組只操作記憶體，不產生媒體、不呼叫 TTS、不寫專案。由主殼提供共用 CSS 與導覽。

- `video`：依 `S.videoScope` 分為本批或全書。獨立保留素材、解析度、待存設定、任務與上一版成品。
- `merge`：選取、排序、來源詳情與修復、停頓、MP3／MP4／兩者、兩種全書影片來源、獨立格式結果。
- `joins`：接點切換、文字與頁碼、重疊警告確認、音訊／影音預覽、校對往返。
- `versions`：總音訊、總音訊製片、批次影片合併三條成果、來源詳情、技術資訊展開、播放／另存、前往製作。

操作驗收：

1. 進入本批影片 → 選圖片 → 製作 → 按模擬成功 → 確認本批成品出現。
2. 改背景素材 → 選短片 → 切換循環／定格 → 拖曳時間軸 → 確認素材秒數與最後一格提示。
3. 選長片 → 確認短片模式欄位隱藏，顯示結束時裁切。
4. 設定素材 → 返回 → 再開製片 → 確認設定保留。
5. 進入全書合併 → 勾 MP3 與 MP4 → 設定全片素材 → 返回 → 製作 → 模擬 MP4 失敗 → 確認 MP3 完成與部分完成。
6. 按只重試未完成輸出 → 模擬成功 → 確認已有 MP3 成品保留。
7. 製作 → 模擬保存失敗 → 按重試保存 → 確認完成，無須重新編碼。
8. 製作 → 取消任務 → 確認上一版仍可播放與另存。
9. 選既有批次影片合併 → 檢查來源 → 確認只要求批次 MP4／SRT，無全片素材欄位。
10. 選第一章 → 檢查接點 → 勾確認 → 返回 → 確認來源警告解除。
11. 接點頁 → 前往校對 → 返回 → 確認選取、順序及接點設定保留。
12. 進入成品版本 → 查看三條成果 → 展開詳情 → 確認各路徑來源語義獨立。

模擬任務以任務卡按鈕完成／失敗，不使用計時器。播放、另存及資料夾為明確標示的入口示範。

主殼整合：`go('produce')` 返回音訊製作；`go('proof')` 前往校對。`S.returnFromVideo` 與 `S.joinReturn` 記錄往返來源。

高度不足或寬度低於 1200 時，影片改用「素材設定／畫面預覽／影片成品／目前任務」內容面板。合併改用「批次來源／輸出設定／結果與任務」。底部動作固定，設定本身不包整欄捲動；清單、結果與版本詳情各自捲動。

程式驗證：`node --check video.js` 通過。Node stub 互動驗證通過：四頁 render、本批製作、重試保存、兩格式部分完成、只重試 MP4、影片路徑切換保留 MP3、忙碌阻擋。實際尺寸與瀏覽器驗收由主殼整合後執行。
