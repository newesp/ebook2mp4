# 試聽與成品：完整流程互動 mock

開啟 `index.html`。由「流程總覽」進入各流程。此版供設計評估，不修改正式程式或專案資料。

## 流程範圍

| 工作 | 互動範圍 |
| --- | --- |
| 語音設定 | 服務、模型、自訂音色、語速、節奏、試聽文字、同意傳送、保存設定 |
| 服務管理 | 新增、編輯、連線檢查、失敗、刪除、未保存返回確認 |
| 全書語音預設 | 儲存、選批套用、影響分類、保留舊成品 |
| 本機語音包 | 匯入、驗證、取消、失敗、移除確認 |
| 本批音訊 | 任務來源、歷史選擇、區塊清單、重用、續作、取消、來源變更、重試保存、舊成品 |
| 本批影片 | 圖片／背景影片、短片循環／定格、長片裁切、預覽定位、解析度、製作與結果 |
| 全書合併 | 選批排序、來源缺項、接點確認、停頓、MP3／MP4／兩者、獨立結果與部分完成 |
| 全書影片 | 總音訊加全片素材；或合併既有批次影片。分開保留兩條來源 |
| 成品版本 | 總音訊與兩條影片成果、來源詳情、播放／另存入口 |

## 建議評估路徑

1. 語音設定 → 修改音色 → 試聽 → 模擬完成 → 儲存並製作。
2. 本批音訊 → 開始 → 切換頁面 → 返回執行中任務 → 模擬完成 → 本批影片。
3. 本批影片 → 選素材 → 保存 → 製作 → 模擬保存失敗 → 重試保存。
4. 全書合併 → 選 MP3 與 MP4 → 設定全片素材 → 返回 → 製作 → 模擬 MP4 失敗 → 只重試未完成輸出。
5. 全書合併 → 切換既有批次影片 → 補齊來源 → 檢查接點 → 製作 → 查看成品版本。

右上「音訊情境」直接切換音訊狀態；其他流程使用頁內模擬結果按鈕。重新整理會重設全部示範資料。

## 版面原則

共用導覽與操作列固定。清單、文字、預覽各自取得內容空間。收合文件列表後完全釋放欄寬。影片及全書頁在較窄或較矮視窗改為內容面板切換，避免整條設定側欄捲動。正式實作仍須以原生 UI 量測確認。

## 驗證與界線

- `node verify.cjs`：25 項頁面、事件語法與狀態檢查通過。
- 子模組另驗證語音試聽、服務保存、全書套用、模型包取消、影片製作、部分完成及重試保存。
- 尚未完成瀏覽器截圖與尺寸驗收；不宣稱視覺驗收通過。
- 批次、歷史任務、來源文字為固定代表資料；未複製真實專案資料庫。
- 媒體播放、另存與資料夾為入口示範；不播放或輸出真實媒體。服務、憑證、模型包與背景任務均為記憶體模擬。
- 正式實作需保留原有外部變更衝突、檔案驗證及任務快照保護。詳細功能對照見 `voice-coverage.md` 與 `video-coverage.md`。
- 本次未建立媒體程序、建置暫存或正式成品；保留 mock 原始檔與驗證程式作為評估證據。
