# T19 UI 草圖 v2

尚待使用者確認。只新增 HTML 草圖，未修改或封裝主程式。

## v2 版面修正

依使用者截圖修正「左側堆疊控制項、右側大面積空白」：製作功能導覽與影片方式分置同一列左右側；合併音訊／製作影片步驟移入內容標題列，不再獨占第三列。將「本機製片」說明移至頁尾。

主內容改為「自然高度工具列＋填滿剩餘空間的目前內頁」。條件顯示的清單、選項、素材區使用明確 grid-area，避免隱藏元素後，剩餘空間分配到錯誤列。維持目前配色、字型、控制項與操作。這次未調整主程式。

開啟 HTML → 檢查上方功能導覽及右側影片方式 → 確認不再各占一列。切換影片方式 → 檢查主要內容 → 確認預覽或批次清單取得剩餘高度。實際瀏覽器目視驗收仍待確認，詳見 `verification.md`。

依據 T19 ticket、Spec v1.1、目前 `AssemblyPage` 及 T18 工作台外觀。保留綠色原生介面、四步驟、左側書籍清單、全書合併清單及固定底部操作。新增區域位於全書合併內容欄。

既有內容欄同時放清單、接點預覽與素材設定會擠壓主要內容。因此依影片方式顯示適用控制項；接點與來源詳情使用同主視窗內頁，不再加入常駐大面板。批次清單、接點文字與來源詳情各自捲動。

## 操作檢查

1. 開啟 `index.html` → 檢查影片方式 → 確認預設是「總音訊製片」。
2. 選「合併既有批次影片」→ 檢查批次清單 → 確認不需總 MP3 或全片背景。
3. 選一列 → 按上移／下移 → 確認合併順序變更。
4. 按「合併設定」→ 輸入停頓 → 確認一／二／三批預設新增 0／0.5／1 秒。
5. 按「對照畫面與試聽接點」→ 拖曳至接點 → 確認示意停頓維持前批畫面、清空字幕。
6. 按「校對後批」→ 按返回接點 → 確認當次選取、順序與停頓保留。
7. 選「PDF 頁碼重疊」→ 進入接點 → 勾選確認 → 返回後確認可以製作。
8. 選缺漏／失效／無法解碼 → 檢查錯誤 → 確認阻擋製作。取消選入問題批次後可繼續。
9. 選音色／語速不同 → 確認僅提示，仍可合併。
10. 按製作 → 按取消 → 確認顯示取消結果，保留上一版。
11. 選失敗 → 按只重試總影片 → 確認只模擬影片工作。
12. 儲存合併設定 → 重開 HTML → 確認範例選取、順序、停頓與解析度保留。

全部畫面、字幕、預覽、任務與檔案操作皆為模擬。不讀使用者書稿，不呼叫 TTS 或 FFmpeg，不產生影音成品。色塊分鏡只供確認互動，正式版必須以實際影片與音訊預覽。設定只保存至此 HTML 的瀏覽器 localStorage，不寫入專案。

建議檢查 1040×640 與 1360×800。僅為 Windows 桌面版設計，沿用目前字型及尺寸規則。
