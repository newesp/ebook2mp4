# T17 背景影片 UI 草圖 v1

狀態：使用者已確認，T17 已依此方向實作。HTML 仍保留為核准時的設計草圖；實作驗證見 `docs/verification/T17.md`。

依據：T17 票稿、規格 v1.1、`total_video_desktop.py` 與 T16 原生 1040 視窗證據。保留現有主視窗、批次清單、兩步驟、左右素材／預覽及底部操作列。正式成品後續固定更新至 `dist/ebook2mp4`。

## 設計範圍

- 在原圖片選擇區增加素材類型。保留 JPEG／PNG，新增一支背景 MP4。
- 背景較短時顯示循環／最後一格定格。預設循環。背景較長時隱藏該選項，直接說明從開頭裁切至音訊結束。
- 右側保留比例及黑邊預覽。無聲預覽與時間滑桿用於檢查循環、定格與裁切；不是多素材時間軸。
- 總 MP3／SRT 決定長度與字幕。背景原聲排除。改素材、模式、解析度只使總影片待更新。
- 返回保留當次輸入。正式版保存素材副本；草圖只在 localStorage 保存範例設定。本機選檔只供當次瀏覽器預覽。
- 失敗後只重試影片。取消、失敗與來源失效均保留上一版成品的明確標示。

## 操作驗收

1. 開啟 `index.html` → 選「短背景／循環」→ 將滑桿移至 9 秒 → 確認素材位置約為 1 秒。
2. 選「最後一格定格」→ 將滑桿移至 20 秒 → 確認位置約為 8 秒，顯示「最後一格定格」。
3. 選「長背景／裁切」→ 檢查左側 → 確認短背景選項隱藏，結束時間為 10:08。
4. 選「直式背景／黑邊」→ 檢查預覽 → 確認左右有黑邊。
5. 切換素材類型為圖片 → 檢查左側 → 確認背景模式與背景原聲說明隱藏。
6. 選「影片已完成」→ 改解析度 → 確認影片標為待更新，總音訊仍有效。
7. 按「返回合併音訊」→ 按「加入視覺素材，製作 MP4」→ 確認素材與設定保留。
8. 按「製作總 MP4」→ 按「取消任務」→ 確認取消結果與舊成品保留說明。
9. 選「製片失敗／保留舊版」→ 按「只重試影片」→ 確認只模擬製片。
10. 選「其他任務執行中」→ 檢查操作 → 確認衝突操作停用，仍可切換示範狀態。
11. 分別使用 1040×640 與 1360×800 視窗 → 檢查主要按鈕與預覽 → 確認無重疊與裁切。

## 驗證與限制

已完成需求／現有 UI 對照及 JavaScript 靜態語法檢查。內建瀏覽器因 URL 安全政策拒絕 `file://`，未執行瀏覽器畫面、尺寸或互動驗收；上列路徑供設計確認。沒有啟動測試或建置程序，也沒有新增服務、依賴、媒體或快取。

範例畫面使用標示明確的測試色塊，不是實際背景 MP4。選本機 MP4 只檢查瀏覽器是否能載入預覽；串流、完整解碼、實際輸出影音、離線素材保存與時長容許差須待設計核准後用真實 FFmpeg 驗證。草圖的成品、製作與匯出操作均為模擬。
