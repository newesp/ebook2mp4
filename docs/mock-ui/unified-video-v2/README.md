# 整合影片製作工作區 mock v2

開啟 index.html。此為設計評估稿，正式 APP 與 dist 未修改。

## 整合決策

共用一個影片工作區，使用「製作範圍」選本批／全書，全書再選統一素材／沿用各批影片。各範圍的設定、任務及成功成品獨立保留；本批也按文件保留素材設定。

音訊製做的 MP4 入口、全書合併的影片入口，以及成品的更新入口，未來都開啟此工作區並帶入範圍。返回按鈕依範圍回音訊製做或全書合併。頂部影片入口與主流程以分隔線區別，不表示全書合併前必須先做本批影片。mock 的外部頁面入口僅顯示說明，不另做假音訊／文稿頁。

## 參照附圖的排版

頂部單列導覽；第二列集中範圍與來源入口。主區取得剩餘高度，文件列表預設收合且能完整回收欄寬。畫面與素材、來源與順序、任務與成品採同區切換；無整頁包住內容的巢狀捲動。底部狀態與主要操作固定；同級 button/select 採相同高度，select 使用單一原生箭頭。

預覽以16:9示意素材呈現，提供無聲預覽狀態、定位、短片循環／定格及長片裁切說明。不是實際影片播放或編碼。一般控制項不足一列時明確換列。

## 操作路徑

1. 本批 → 選示範素材 → 改解析度 → 保存 → 製作 → 模擬成功 → 播放／另存入口。
2. 再製作 → 模擬失敗或取消 → 確認上一版成品保留。
3. 製作 → 模擬保存失敗 → 重試保存 → 確認成功。
4. 全書／統一素材 → 來源頁模擬來源失效 → 製作 → 確認導向缺項 → 模擬補齊。
5. 全書／沿用各批影片 → 選批排序 → 檢查相鄰接點並確認 → 製作。此路徑不要求總MP3或全片素材。
6. 切換範圍與文件 → 確認素材設定保留。忙碌時範圍及衝突變更鎖定；可切換內容面板。
7. 收合／展開文件列表 → 檢查欄寬回收、內容與固定操作可達。

## 驗證界線

node verify.cjs：24項路由、事件語法與狀態檢查通過。此檢查不證明畫面尺寸與捲動可用。

實際瀏覽器截圖、1280×720／1536×864與125%縮放的版面、鍵盤焦點及滾輪驗收尚待完成。先前本機HTML存取受瀏覽器工具URL政策限制，本次不宣稱已通過視覺驗收。

評估時應確認：預覽可辨識畫面與字幕；來源清單首末列可達；設定與任務展開不遮住底部操作；不同範圍名稱及保存對象明確。所有資料僅存記憶體，重新整理即重設；播放、檔案與外部頁面均為標示清楚的示範入口。

## v2 調整

文件列表開關維持窄版 >／< 圖示，hover 提示及 aria-label 說明顯示／隱藏文件列表，展開時釋放／恢復實際欄寬。

移除右上成品、來源與製作設定、狀態詳情等重複入口。內容內重複的播放／另存及返回頁籤按鈕亦移除；底部集中成品操作。

畫面與素材／來源與順序／任務與成品為 tabs：tablist、tab、tabpanel、aria-selected、aria-controls、單一 tabindex=0。左右鍵循環切換；Home／End 到首末頁籤並移動焦點。原生 APP 實作應使用 ttk.Notebook 或具等價鍵盤與選取語意的頁籤元件，不以一般操作按鈕代替。

程式檢查另涵蓋 tab 選取、鍵盤操作、唯一焦點入口、列表圖示及重複入口移除；尚未完成實際瀏覽器版面與輔助科技驗收。
