# T18 批次影片 HTML 草圖 v1

狀態：等待使用者確認。尚未實作主程式，尚未更新正式封裝。

依據：`docs/implementation-status.md` 最新 T17 交接、T18 票稿、目前 `narration_desktop.py`、`production_desktop.py`、`total_video_desktop.py` 與核准的 T17 草圖。沿用目前配色、主視窗、左側批次區、製作與成品頁、素材／預覽左右配置及固定操作列。

## 設計範圍

- 「製作與成品」的批次成品區新增「加入素材，製作 MP4」。在同主視窗進入批次影片頁，返回保留設定。
- 影片頁僅使用目前批次的有效完整 MP3／SRT。音訊失效時阻止製片，提供返回更新入口，上一版影片仍可取用。
- 每批獨立選 JPEG／PNG 或 MP4，獨立保存循環／最後一格定格、720p／1080p。長背景從開頭裁切，短背景預設循環。預覽保持比例、黑邊補齊；背景預覽無聲。
- 本批音訊決定影片長度；不加全書交接停頓、不新增 TTS、不要求 PDF、OCR、總音訊或總影片。
- 修改視覺設定只標記本批影片待更新。取消、失敗保留上一版。成品操作包含播放、另存 MP4／SRT、開啟資料夾與保存設定。
- 草圖以兩個 TXT 批次示範切換。範例設定可按批次保存於瀏覽器；本機選檔僅供當次預覽，不會複製到專案。正式版須保存素材副本與來源版本。

## 操作確認

1. 開啟 `index.html` → 檢查「製作與成品」→ 確認本批 MP3／SRT 下方有製作 MP4 入口。
2. 按「加入素材，製作 MP4」→ 檢查批次影片頁 → 確認留在同一主視窗。
3. 選示範狀態「圖片」→ 檢查素材區 → 確認背景模式與時間滑桿隱藏。
4. 選「短背景／循環」→ 將滑桿移至 9 秒 → 確認素材位置約為 1 秒。
5. 選「最後一格定格」→ 將滑桿移至 20 秒 → 確認顯示最後一格定格。
6. 選「長背景／裁切」→ 檢查左側 → 確認短背景選項隱藏，影片結束時間為 03:12。
7. 選「影片已完成」→ 改解析度 → 確認本批影片待更新，本批音訊仍有效。
8. 按「返回製作與成品」→ 再開批次影片 → 確認素材與設定保留。
9. 切換第二章 → 檢查本批影片 → 確認沒有沿用第一章素材。返回第一章 → 確認原設定保留。
10. 選「本批音訊失效」→ 檢查製作按鈕 → 確認已停用，上一版仍可播放。
11. 按「製作本批 MP4」→ 按「取消任務」→ 確認取消結果與上一版保留說明。
12. 選「製片失敗／保留舊版」→ 按「只重試影片」→ 確認只模擬影片製作。
13. 使用 1040×640 與 1360×800 視窗 → 檢查底部操作與預覽 → 確認沒有重疊或裁切。此項待實際目視確認。

## 檢查與限制

JavaScript 語法檢查通過；47 個 HTML ID 無重複，109 個直接 DOM 引用沒有缺項。內建瀏覽器安全政策拒絕 `file://`，未執行瀏覽器目視、尺寸與互動驗收，不宣稱這些項目通過。

本草圖使用測試色塊，製片、播放成品、另存與資料夾操作為模擬。選取本機素材只供瀏覽器預覽。完整解碼、真實影音、時長誤差、字幕時間軸、專案保存、安全發布與程序釋放須待設計確認後驗證。

本輪只新增本目錄 HTML 與本文件；沒有修改應用程式、建立測試／建置程序、下載依賴或產生媒體暫存。沒有需清理的本輪背景程序。正式實作仍固定發布至 `dist/ebook2mp4`。
