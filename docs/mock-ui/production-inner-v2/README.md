# 朗讀稿與任務設定：內頁 Mock v2

本稿承接使用者指定的頂部排列，取代 v1 內頁的重複返回設計。僅製作設計圖，未修改產品或 dist/ebook2mp4。

## 調整

- 一般尺寸：流程導覽移至頂列，主步驟與流程間加分隔線；任務列與左側匯入、管理同列。
- 內頁只保留任務列右側的「← 返回區塊清單」，使用一般按鈕，不顯示下拉箭頭。移除內頁重複的返回列，頁籤與文稿向上延伸。
- 「重新檢查目前稿件與設定」移至「狀態詳情」左側；兩顆按鈕同高，文字完整顯示。
- 播放使用同一個固定位置的按鈕：可播放時顯示「播放成品」；啟動成功後顯示「停止播放」；停止或自然結束後恢復「播放成品」。播放失敗時恢復可重試狀態並顯示錯誤。無成品時停用播放。切換頁籤不應使按鈕與實際播放狀態不同步。
- 播放中示意沿用狀態摘要位置顯示時間；時間必須來自實際播放器，無可靠時間資料時僅顯示「播放中」。本稿的播放時間為示意資料。
- 900×640 時流程導覽移至下一列；全寬底部六顆按鈕仍容納於同一列。文稿摘要收成一列，保留約六行文字高度。更高文字縮放若容納不下，操作應分列，不能裁切。
- 成品可播放的示意採已完成任務；因此下一步顯示「全書合併」。正式實作依原有任務狀態顯示適用操作。
- 狀態與錯誤詳情沿用同區域切換；返回區塊清單後保留選取與捲動位置。

## 核准後的原生驗收

1. 開啟朗讀稿與任務設定 → 檢查返回按鈕 → 確認只出現一個且沒有下拉箭頭。
2. 檢查狀態列 → 確認重新檢查在狀態詳情左側，兩者同高且未裁切。
3. 按下播放成品 → 聽取語音 → 確認原按鈕變為停止播放。
4. 按下停止播放 → 聽取輸出 → 確認語音停止且按鈕恢復播放成品。
5. 播放至結束 → 檢查按鈕 → 確認恢復播放成品。
6. 觸發播放失敗 → 檢查狀態 → 確認沒有錯誤顯示為播放中。
7. 播放時切換頁籤 → 檢查聲音與按鈕 → 確認兩者狀態一致。
8. 返回區塊清單 → 檢查原選取與捲動位置 → 確認保留。
9. 縮至 900×640 → 檢查文稿與必要操作 → 確認至少六行文字空間及完整按鈕。
10. 捲動長文至末行 → 檢查底部操作列 → 確認只有文稿區捲動。
11. 跑原生回歸測試 → 檢查正式封裝畫面 → 分別記錄測試結果與實際尺寸、縮放、畫面證據。

以上均為待執行驗收，靜態設計稿不能證明實際播放、停止、狀態保留或正式封裝已通過。
