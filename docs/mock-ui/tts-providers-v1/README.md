## 後續需求補註：模型欄

Google Gemini TTS需支援gemini-3.8-flash-lite-tts及gemini-3.8-flash-tts，並使用「可編輯下拉選單」，可選預置ID或直接輸入未來模型。擬放主畫面第1區服務設定檔之下，然後往右選音色與試聽；Google Cloud憑證／區域留在服務設定。傳統Cloud TTS與Gemini TTS的API入口分開。詳見[追加評估](../../tts-provider-evaluation.md)。目前圖片尚未更新，本次未改程式。

### 存取方式修訂

依使用者提供的Gemini Developer API文件，本案優先採「Google Gemini TTS＋API key」。服務管理不要求一般使用者填Cloud專案／區域／ADC。可明確選擇沿用Gemini校對金鑰或另設金鑰；主畫面模型欄可選可填。原圖Google Cloud TTS帳戶示意與先前Cloud認證說明尚未重繪，未來圖面應以上述修訂為準。
