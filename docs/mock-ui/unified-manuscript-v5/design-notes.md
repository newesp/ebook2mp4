## 本次調整

- 頂部縮為 48px，僅留步驟、專案名稱與專案入口；內容間距縮為 8px。一般尺寸三個內容區共用 52px 標頭帶，較窄時共同增加高度，維持內容上緣齊頭。實際斷點與文字適配仍待視覺驗收。
- 文件列表開關依狀態顯示「顯示文件列表／隱藏文件列表」。同時提供 title、aria-label、aria-expanded，以及 hover／focus 提示；按鈕不用圖片專屬的 alt 屬性。
- 開啟來源 PDF 移到頁碼、縮放及來源選單旁。
- AI 全文校對與暫存草稿移到文稿區，與隱藏原稿、編輯、校對及版本入口同列。窄視窗才在共用標頭帶內換行。
- 附件僅見原更多工具選單，未見橘／紅標記；留白及開關按第四版位置解讀。
