# 音訊頁訊息與背景任務列 Mock v4

依使用者「先回應，別實作」後確認製作 mock 的範圍，僅提供一般視窗 1360×820 三種狀態。未修改產品、測試或 dist/ebook2mp4。本版在訊息、箭頭與背景列部分取代前版設計；其餘操作順序延續已核准配置。

## 圖片

- ready.png：更新前。主按鈕顯示「更新 MP3／SRT」，沒有箭頭。
- running.png：目前正在查看製作中的任務。只顯示頁內進度及適用的取消操作；不顯示重複的返回任務列。
- background.png：切換到同書另一批次。背景任務仍屬 book1-ch3，目前選取 book1-ch2；背景任務列提供明確批次名稱、階段、進度與返回入口。

## 設計規則

1. 文件摘要占用整列，不再分配右側固定訊息欄。摘要在操作列上方保持可見。
2. 「已載入專案」改為載入時短暫提示，並保留於既有訊息記錄；「原始來源檔不會被改寫」放在既有專案位置與來源資訊。這兩項不再常駐底部。
3. 重要錯誤仍在相關工作區明確顯示；必要時以穩定的全寬訊息列呈現，詳情由既有訊息記錄或狀態詳情開啟。不得因合併摘要而吞掉錯誤。
4. 正在查看同一個執行任務時，隱藏全域返回列，以頁內即時進度為單一來源；不得重複列出略有時間差的兩份進度。
5. 切換頁面、批次或書籍，且執行中任務未在目前內容區顯示時，保留背景任務列。按下返回任務後恢復正確書籍、批次及製作頁，並隱藏該背景列。
6. 背景列使用獨立版面列，位於底部文件摘要與操作區上方。出現時只讓內容區縮短；隱藏時移除該列高度及間距。不得和操作區共用格子或浮蓋其上。
7. 製作中維持既有忙碌與同意阻擋契約。切到同書其他批次時，不允許啟動會衝突的製作。本 mock 未增加平行製作能力。
8. 停止、失敗或成功後更新頁內結果；背景列若需保留結果提示，應明確標示結果，不得繼續顯示「製作中」。
9. 底部維持「播放成品／停止播放」、「更新或繼續製作」、「成品操作」、「製作 MP4 →」的順序；取消只在適用時出現。工具順序仍是同意欄、狀態詳情、重新檢查。

所有按鈕、下拉與任務欄為相容的 36 設計像素高度。原生實作沿用共用 Workspace 控制項及樣式，實際同角色高度差須在 2 個 Tk 座標像素內。圖片中的資料及進度為示意。

## 確認後的原生驗收

1. 開啟音訊製做 → 檢查更新按鈕 → 確認「更新 MP3／SRT」沒有箭頭。
2. 更新目前任務 → 檢查底部操作 → 確認只有頁內進度，且每個按鈕完整可見。
3. 切換批次 → 檢查背景列 → 確認顯示執行任務的批次，且沒有遮擋目前操作。
4. 按下返回任務 → 檢查書籍與批次 → 確認回到正確任務，背景列隱藏且內容區收回空間。
5. 觸發錯誤 → 檢查訊息 → 確認重要錯誤仍可見並可查看完整內容。
6. 完成或取消任務 → 檢查進度與返回入口 → 確認沒有過期的製作中狀態。
7. 檢查文件摘要 → 確認使用整列，沒有固定保留的右側狀態欄。

本輪僅檢查靜態設計，沒有執行原生操作、測試或封裝驗收。
