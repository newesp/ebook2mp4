# 朗讀稿與任務設定：內頁 Mock v3

本版為目前設計提案，取代 production-inner-v2 的同意欄、留白與頁籤外觀；其餘已確認設計延續。僅更新設計稿，尚未修改產品及正式封裝。

- 將「同意傳送待處理文字（可能計費）」移至「重新檢查目前稿件與設定」左側，與「狀態詳情」同列。預設勾選及取消後阻止送出的契約維持。
- 移除原勾選框的獨立列及多餘底部間距。1360×820 時文稿區向下增加 64 設計像素；900×640 時增加 32 像素。紅框空間供文稿使用。
- 「朗讀稿與設定」及「狀態與錯誤詳情」為頁籤。選取頁籤與內容區相連，未選頁籤使用次級底色。正式實作沿用現有 ttk.Notebook，不替換成 Button；需保留焦點、鍵盤切換及頁籤內容狀態。
- 一般尺寸狀態、同意欄、重新檢查、狀態詳情同列。最小視窗將狀態摘要獨立為上列，另外三項保持同列。文稿獨立捲動，固定操作不隨之移動。
- 保留唯一的「← 返回區塊清單」，以及同位置的「播放成品／停止播放」切換。
