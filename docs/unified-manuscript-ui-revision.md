## 版面及操作方案（待設計圖確認）

| 區域 | 直接入口 | 次要功能與行為 |
| --- | --- | --- |
| 左上 | 1 文稿、2 試聽與製作 | 目前步驟清楚可辨；使用共用尺寸樣式。 |
| 右上 | 匯入文稿、AI 全文校對、暫存草稿、專案 | 匯入選 PDF／TXT；專案選建立、開啟、資料夾及專案資訊。AI 附屬選單提供校對設定。 |
| 文件管理 | 標頭展開／收合、文件清單 | 命名、排序、移除放本區操作入口。收合保留開啟控制；記住選取及捲動。 |
| 原稿標頭 | 頁碼、符合頁寬、縮放、開啟來源 PDF 小連結、原稿收合 | 來源處理／來源異常／來源資訊放「來源」選單；無 PDF 時不顯示 PDF 控制。收合仍可就近恢復。 |
| 文稿標頭 | 搜尋取代、編輯、版本；審閱時提供改動導覽 | 編輯：換行整理、匯出 TXT、重載外部稿。版本：版本記錄、歷史 AI 候選。差異顯示、還原目前改動、放棄 AI 結果限審閱情境；放棄與一般操作分隔。 |
| 工具內容 | 在同一主視窗展開 | 版本、設定與來源處理可共用內容容器，但入口依用途命名。設定按字級／校對／來源歸屬配置；保留自訂模型與服務連線設定。 |
| 底部 | 單列狀態與右側主要下一步 | 未完成時將繼續校對與保留原文相鄰排列；停用儲存的原因就近顯示。儲存成功後顯示前往試聽與製作。 |

全域操作靠右不等於把頁碼、縮放、文件管理開關搬到右上。局部控制應與控制對象保持直覺關聯。

同用途 button/input 共用高度、字體、內距與互動狀態。允許有明確用途的緊湊變體，但同一列尺寸須相容；小型連結仍須容易點擊、可鍵盤聚焦並有可讀標籤。

版本等工具預設收合；展開不能將編輯器壓成僅供展示的小框。窄視窗原稿／文稿可同區切換，還原寬度後恢復使用者比例及狀態。長文獨立捲動，固定操作不遮擋內容或焦點。

在設計圖階段記錄實際客戶區尺寸、DPI、字級、內容區與編輯器高度、可見行數；定義可驗收下限。先前建議的內容區約 65% 是設計起點，並非已核定的硬性門檻。以 1366×768、1920×1080 螢幕及適用的 100%／150% 系統縮放規劃；記錄實際可用視窗尺寸，不能只用螢幕解析度冒充驗證。

改動標示須指出比較基準，支援上一處／下一處；避免整篇底色代替精確標示。摘要一列，技術時間戳與狀態代碼按需查看。

## 防回歸與驗收

實作前建立受影響功能清單，記錄舊入口、新入口、驗收路徑及結果。至少涵蓋 PDF 頁碼／縮放／符合頁寬／來源檔、原稿開關、文件管理、搜尋取代與復原、差異與版本、模型及服務設定、旋轉／框選重辨／失敗頁重試、TXT 編碼與重載、匯出及換行整理。截圖未顯示不代表功能可移除。

- 開啟 PDF → 使用符合頁寬 → 確認可閱讀正文；改變縮放 → 確認可移動到需要核對的位置。
- 點開啟來源 PDF → 確認開啟目前文件對應來源；缺檔時顯示可行提示，文稿不變。
- 顯示原稿 → 確認預設兩欄等寬；拖曳後執行 AI／切換工具 → 確認比例、頁碼與文字位置保留。
- 收合文件管理 → 確認原位置有開啟入口；再次展開 → 確認選取及捲動保留。
- 展開版本／設定／來源工具 → 量測編輯器 → 確認達到設計核准的可用下限；縮小及還原視窗後重做。
- 以長內容操作兩區捲動至底端 → 確認只移動目標區域，最後一行及主要操作可達。
- 開啟各相關頁面 → 比較同用途控制項 → 確認共用元件樣式與尺寸；檢查聚焦、停用、忙碌及選取狀態。
- 模擬部分校對 → 確認續作／保留原文選項相鄰，儲存的阻擋原因清楚；來源異常仍不可略過。
- 依原 ticket 驗證保存失敗、晚到結果、草稿恢復、快照一致性及舊專案相容。

保留原生 UI 截圖與操作結果，標明內容規模、視窗／縮放條件及未驗證項目。舊版交付證據不能充當本次通過證據。完成後僅更新正式成品至 `dist/ebook2mp4`，清理本次測試資料、建置暫存、快取與自有程序，保留需求文件及最終證據。
