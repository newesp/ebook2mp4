## 問題與目標

文稿與音訊頁已使用同一個 DocumentList，卻由不同父層布局決定標頭帶、內容起點及底列，造成相同元件跨頁高度不同。抽檔、使用相同樣式、同窗顯示或共用部分元件，均不足以判定全頁接入完成。

工作順序固定：**先統一共用外框 → 所有頁面真正接入同一布局與共用元件 → 最後整合各頁專屬 UI 與功能。** 不再完成一頁專屬改版後，才替下一頁另補外框。

## 範圍與起點

涵蓋所有主頁、工具內頁、製作內頁、頁籤與詳情狀態；同頁的搜尋列等局部狀態不強制變成獨立頁。完整接入矩陣由 ticket 維護。

- 延伸既有 `desktop_shell.py`、`workspace_layout.py`、`ui_controls.py` 及 `desktop.py:make_app`；不另建平行樣式或框架。
- DesktopShell、InnerPageHost、ActionBar、ActionSpec、PagePresentation 已存在。ProductionPageLayout 及兩個合併 Workspace 尚未形成全 APP 的唯一布局持有者。
- `manuscript_desktop.layout_workspace()`、`production_desktop.sync_chrome()` 及各頁直接配置共用容器的程式是遷移重點。先讀當前來源，再確認介面；下列為行為契約，非既有 API 宣告。

## 共用外框契約

1. 同一 shell 擁有導覽、文件列表、工作區標頭帶／內容宿主／區域狀態及固定底部摘要／操作列。控制項只在固定父容器建立，頁面切換不搬動或重建共用元件。
2. shell 是上述區域 grid／pack、row／column、顯隱、尺寸、間距與重排的唯一持有者。內容頁不得直接配置 `app.left_panel`、`app.actions`、導覽或其他頁的控制項；舊相容別名須移除布局用途。
3. 頁面只配置取得的內容 port，提供具穩定 id 的頁面描述：導覽位置、標題／工具描述、文件範圍、區域／全域狀態、ActionSpec、忙碌狀態與適用區域。固定返回、列表開關與全域動作由 shell 呈現；內容中的播放等局部動作沿用共用元件規則。
4. 頁面切換、啟用／停用、返回、釋放有清楚介面。只有目前頁能更新共用呈現及執行其動作；晚到回呼、隱藏頁、舊專案結果不得改寫目前操作列。解除綁定、計時器及播放資源的責任明確。
5. 同尺寸、字級、列表狀態下，共用導覽帶、文件工具帶、列表上下緣、工作區內容起點及底列使用同一套尺寸規則。同角色基準線差≤2個 Tk 座標像素；不能以各頁補償 padding、空白列或依頁名硬編碼高度通過。
6. 窄版換列、列表收合及情境區域顯隱由 shell 統一決定，釋放實際空間。內容差異只發生在內容 port；確有必要的角色例外先記錄原因、影響及核准依據。
7. 共用元件集中建立樣式、尺寸角色、淨距及互動狀態。改動共用元件後，所有已接入頁面同步生效；不能留單頁布局或樣式副本。

## 階段與門檻

### A：全頁盤點與現有 UI 基線

盤點實際入口／子頁／狀態／返回、父容器、直接操作共用區的程式、資料與任務持有者。設計圖涵蓋主頁與工具、製作頁、寬窄版、列表收合、適用大字及空／長內容。布局對照與功能契約分開記錄。

使用者已指定沿用目前 UI 並免除提供新設計圖；保存現有原生畫面與量測作重構比對。下方 B～E 依現有布局執行，不將舊單頁或本輪未核准草圖擴張為新布局授權。

### B：統一原生父層布局

由單一整合者集中 shell 責任，建立固定內容 port 與頁面描述入口。先以代表頁與等價資料核對原生結構、共用基準線和尺寸，再擴展全頁。

### C：所有頁面接入

每個入口都經同一 shell，頁面交付描述和命令，撤除自行修改共用外框的程式。可先以 adapter 承載既有內容／功能，避免過渡期間功能消失；adapter 也不得越界操作 shell。

**所有矩陣列通過外框接入門檻後，才進入 D。** 有任一頁仍自行配置共用區，C 仍未完成；不能以重新命名、空占位頁或單頁通過代替。開發中占位只用於結構檢查，不作正式交付。

### D：整合各頁專屬 UI 與功能

在已統一的內容 port 內整合編輯、設定、任務、預覽、合併及影片等 UI；保留既有可用功能。各頁完成設計對照、功能回歸、原生 UI 及正式 EXE 驗收，逐項清除繼承的未測項。

## 功能及資料保留

- 保留來源原檔、人工稿、草稿、朗讀快照、AI 候選、版本／備份、原子保存、失敗不前進、過期結果拒絕。返回保留輸入、選取、捲動、頁籤及既有設定；不擴大磁碟保存範圍。
- 任務按專案、批次／全書及路徑隔離；切頁不取消或重啟製作。保留增量重用、取消、續作、部分完成、重試保存與上一份成功成品。
- 雲端 TTS 取消同意後不得送出，切頁不重勾；本機不顯示無關欄位；文稿 AI 不恢復已移除的同意框。驗收不新增私人書稿傳送或計費請求。
- 全書合併維持音訊專用；MP4 留在影片製作。本批、全書統一素材、沿用各批影片的設定／來源／任務／成品隔離，不新增 TTS 或重複交接停頓。
- Kokoro 設計工作承接原 K03 全部條件：包安裝／移除、服務／音色／語速、固定範例／選取文字試聽及正式製作路徑；未安裝、檢查、成功、缺包／損毀／不相容、載入、合成、失敗與取消。標示本機及有品質證據的音色、不要求 key、細節按需展開；保留輸入、窄版操作、忙碌／取消及清楚刪除語意。閒置卸載／限時政策以 K01 實測決定，未定值明列；設計須取得確認。K01／K02／K04～K09 的 CPU、離線、品質、包管理與生命週期驗收仍屬 Kokoro 原票，不能因 UI 移交視為通過。
