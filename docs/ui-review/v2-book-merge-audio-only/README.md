## 功能契約（與布局對照分開）

- 本頁只讀取批次音訊及配套字幕，依勾選順序合併；不呼叫TTS，不製作或合併MP4。
- 後續實作必須以明確的音訊路由建立頁面，啟動音訊合併工作（既有start_total_audio路徑）。不能只移除MP4勾選，卻繼續依output_formats／total_video_method啟動start_outputs或轉到影片合併頁；先前保存的MP4偏好不得改變本頁責任。
- 原有選批、順序、來源版本、停頓、接點確認、驗證與保存契約保留。0～5秒，下拉提供0／0.5／1／2／5並可手動輸入三位小數；圖示單位「秒」不納入數值解析。
- 切換詳情、接點與返回時保留輸入、焦點及閱讀位置。保存失敗不得顯示已保存。音訊製作失敗或取消保留上次成功成品；媒體完成但保存失敗時顯示「重試保存」，不重做音訊。
- 合併音訊列的查看詳情、補齊缺項沿用既有狀態分支，於同宿主切頁；完成後同位置改為成品操作選單。成品版本入口應定位音訊路徑，不能混入影片來源或設定。
- 合併來源及正文MP4控制全部移除；全域「影片製作」仍開啟現有工作區。其本批／全書、統一素材／各批影片、任務與成品契約維持獨立。
- 未完成或缺項時顯示原因；忙碌時停用來源變更、保存與重複製作，提供取消。完成且設定未變更時主要按鈕停用，變更後才允許更新。

## 按鈕文字與箭頭

主要按鈕為「製作合併音訊」，不帶→；儲存合併設定、取消任務及重試保存也不帶→。來源詳情、檢查接點、查看詳情、補齊缺項、成品版本會切換頁面，因此帶→；返回使用既有←。下拉選單的原生三角指示與→不同。頂部既有流程連接箭頭保留，不是操作按鈕的動作後綴。

## 證據與界線

measurements.json保存繪圖及共用來源SHA256、所有元件外框、固定欄線與列高、來源視口、71組相鄰按鈕量測。正常、縮小及接點展開狀態已提供；來源、文件列表、接點前後文字涵蓋短／fit／overflow／long，同份繪圖資料產生49筆scroll-contract，幾何檢查通過。fit包含明確繪圖尾端內距；短內容無軌道，溢出滑塊按viewport／content比計算，PIL最少1實體像素。交接與結果兩列完整容納，不設整頁或水平捲動。

本目錄check-list.md保存設計階段的量測與當時尚未執行的原生項目。後續實作及驗收以交付證據內的check-list.md為準；不以設計幾何通過宣告原生或EXE合規。
