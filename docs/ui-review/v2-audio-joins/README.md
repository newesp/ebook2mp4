## 共用尺寸與閱讀空間

14px 字體配 36px 高控制項；18px 字體配 44px 高控制項。18px 為 128.6% 靜態文字放大，沒有模擬原生系統 DPI。停頓、片段長度、播放與停止均為 120px 寬；左右校對均為 128px；接點前後導航均為 112px。主要保存操作為 196px 寬，返回為 168px 寬，分屬提交與導航角色。文件列表頁的返回另使用 196px 寬導航變體，容納其完整標籤。

同組相鄰動作淨距為 4px；標頭操作列到文字區為 8px。設定與播放屬不同任務群組，依左右閱讀欄線定位。兩個設定欄同寬且標籤列對齊。頁面不以任意不同按鈕寬度消化留白。每個下拉只畫一個指示；「秒」是顯示單位，不納入數值解析。

| 畫布／狀態 | 每側文字區高 | 完整可讀行數 | 配置 |
|---|---:|---:|---|
| 1920×1000，正常 | 590px | 25 | 導覽單列、文件欄顯示 |
| 1360×820，正常 | 410px | 17 | 導覽單列、文件欄顯示 |
| 1280×720，正常 | 270px | 11 | 導覽換列、文件欄顯示 |
| 900×640，正常 | 190px | 7 | 文件欄收合 |
| 900×640，18px | 136px | 4 | 文件欄收合、控制項增高 |
| 1360×820，短警告詳情展開 | 268px | 11 | 詳情自然高 134px，與文字區間距 8px |

一般比較最低保留 4 行完整文字；次級詳情內嵌時最低保留 6 行。畫布為內容尺寸，未包含 OS 標題列。1920×1000 只是大型內容區的代表，不是已操作正式程式最大化的證據。主程式最大化、原生小視窗與系統縮放在實作後重驗。

## 功能契約

- 接點選擇、批次順序、全書停頓、逐接點確認及前後閱讀位置各自保存上下文。切換詳情、文件列表或校對後返回，沿用既有保留機制。來源文字相同時不重填 Text，不重設閱讀位置。來源版本改變時重新驗證，不沿用已失效的確認或舊預覽。
- 交接停頓套用全書所有接點。提供 0／0.5／1／2／5 秒選項，可手動輸入 0～5 秒、最多三位小數。片段長度提供前後各 3／5／10 秒，預設 5。非法輸入在原欄附近顯示原因，停用播放與保存；不得把無效值靜默改回預設。
- 試聽讀取既有 MP3／SRT，不呼叫 TTS。新增停頓期間字幕留白；實際可聽間隔另含來源檔案頭尾靜音。來源版本及實體檔案須沿用既有檢查，不用靜態文字狀態取代。
- 原稿對照與試聽字幕是不同內容。畫面以「前批結尾／後批開頭」或「前批字幕／後批字幕」標頭區分。未來實作以 content_kind 記錄目前內容，與 playing 分開；停止後若仍保留字幕，標頭仍為字幕。不能只依播放旗標改回原稿標籤。切換接點後才載入對應原稿並更新標頭。
- 準備中停用來源變更、校對、接點導航、設定欄、確認及保存。原停止位置顯示「取消準備」，保留返回。取消或離頁後忽略過期非同步結果，不能將預覽覆寫到其他接點／專案。
- 播放中保留停止操作；切換接點、片段長度、校對及保存沿用先停止再執行的流程。停頓仍可編輯；編輯後須停止舊預覽，下一次試聽使用新值。不要只因正在播放，就把既有可用設定全部鎖住。
- 停止、取消、失敗與正常結束分別顯示結果。重試試聽使用原播放位置；保存失敗使用原保存位置，保留輸入。錯誤文字換行計入設定列高度；不能以提示遮住主要操作。
- 頁碼重疊、缺口、手動倒序沿用既有警告及實際來源／物理頁次。警告確認只針對目前接點，不自動去重、補頁或補半句。詳情的開關不得等同確認。
- 確認框的整個文字列均可點選，支援焦點與 Space；每個接點確認先在記憶體保留，再由保存流程寫入。未勾選仍可保存設定並返回；全書合併必須繼續受未確認警告阻擋。保存不能自動勾選警告，也不能錯誤顯示可製作。
- 「儲存並返回」遵循 owner.save 成功後才返回的既有契約。失敗保留頁面與修改，不顯示已儲存。一般返回保留本次工作區輸入，不等同已寫入磁碟。重新載入後沿用已保存的有效設定。
- 校對入口仍前往對應批次文稿。修改後必須重新確認朗讀稿並重製批次音訊，回到接點時重新驗證。這不是直接在唯讀對照區修改文字。
- 文件列表顯示、詳情開關保留於所屬區域附近。沒有另建「更多工具」選單。主入口及操作不重複。

「校對前批 →／校對後批 →」會進入另一頁，因此有 →。「播放接點」「停止試聽」「儲存並返回」沒有 →；返回使用 ←；展開／收合詳情使用單一下拉指示。頂部流程箭頭只是既有流程連接，不是製作動作後綴。

## 捲動與狀態檢核

[measurements.json](measurements.json) 與 [scroll-contract.json](scroll-contract.json) 由繪圖程式使用的同一份布局、實際字型行高、換行及內容產生。46 張設計涵蓋短、剛好容納、溢出、長文、展開、收合、空狀態、字體放大及準備／播放／失敗／取消。前批、後批、文件列表與警告詳情各覆蓋四種內容長度；固定設定列也有容納量測。

## 核准後的原生驗收路徑

2026-11-13補驗：文件列表與接點頁的「標頭帶」及「內容起點」須分別量測；首次開啟須實見前批末行與後批開頭，保存狀態須與實際設定一致。量測定義集中在[元件規範](../../ui-components.md#文件列表與檢查接點的兩條基準線)，修正與證據見[本批記錄](../../verification/audio-join-corrections/README.md)。

1. 開啟全書合併 → 按檢查接點 → 確認同宿主內頁及選批狀態。
2. 選第二接點 → 捲前批到末行 → 確認後批及固定工具不動。分別用滾輪、滑塊及鍵盤到首末。
3. 展開警告詳情 → 縮小至 900×640 → 確認切換詳情頁 → 收合後確認原接點及閱讀位置恢復。
4. 開啟文件列表 → 捲到最後文件 → 返回接點文字 → 確認欄位、確認框及焦點恢復。
5. 輸入停頓 0.123 → 試聽 → 確認既有媒體與新停頓 → 修改停頓並確認舊播放停止。
6. 準備試聽 → 取消或返回 → 確認沒有過期結果覆蓋其他頁。重新進入確認輸入保留。
7. 按校對後批 → 修改並完成既有批次流程 → 返回接點 → 確認舊來源被重新驗證。
8. 保留未確認警告 → 儲存並返回 → 確認設定保存且合併仍受阻擋。重新進入確認後再保存。
9. 觸發可恢復的試聽及保存失敗 → 確認原因及重試入口 → 確認沒有遺失輸入或假成功。
10. 最大化／1360／1280／900 與支援的系統文字縮放 → 重測同角色原生外框、4px／8px、可讀行數及末行可達。另驗焦點、hover、Tab／Space／Enter。
11. 在正式 EXE 重做上述受影響路徑 → 分別記錄功能、mock 布局及 EXE 結果。全部適用項目通過後才標記 UI 驗收完成。
