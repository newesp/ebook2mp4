## 功能及保存契約（與布局對照分開）

- 合併來源、排序、0～5秒停頓、接點確認沿用現有保存與驗證契約。停頓下拉提供0／0.5／1／2／5及手動小數；不新增保存狀態。
- 格式選擇沿用既有即時保存，示例預選MP3不代表重設專案既存選擇；重新開啟須載入專案設定。只選MP4且需要總音訊時，沿用既有「前置總音訊」列及狀態規則，不偽稱要求MP3輸出；此組合尚未單獨出圖。
- 恢復原有「查看詳情／補齊缺項／成品操作」狀態分支，移除自訂「輸出詳情」。準備／失敗等顯示詳情；缺項導向現有修復入口；成功格式顯示成品操作。播放、另存、資料夾、版本與配對SRT保留原能力，不因圖中選單收合而刪除。
- 全書MP4的範圍、統一素材／各批影片方式、素材、預覽、來源及任務均由現有「影片製作」模組負責。本頁不另放影片方式或素材設定；MP4缺項按既有處理導入該模組，不新增平行入口或保存責任。
- 製作中鎖定衝突變更及重複開始，取消可見；可安全切換頁面但不得修改正在處理的來源。部分完成保留成功格式，只重試未完成格式。保存失敗只重試發布，不重做媒體。
- 來源詳情沿用現有同宿主內頁與返回保留契約。本輪沒有重設該內頁；接點內頁沿用前一版並提供同內容尺寸對照。

## 量測與界線

原版900×640來源視口84px；新版只選MP3為179px（四個完整40px列），兩格式為135px（三列）。格式區分別88／132px，均小於來源視口。正常1360只選MP3為359px、兩格式315px。相較原版「尚未製作」至「輸出詳情」694px，新版各狀態與操作距離64～92px，依字寬量測；不把這個關聯距離與相鄰按鈕的4px淨距混同。

用同份繪圖資料計算52筆捲動區，涵蓋來源、文件列表、接點前後文字的短／fit／overflow／long。完全容納的交接／格式區不設捲動；無整頁及水平捲動。fit案例包含繪圖資料定義的尾端內距。scroll-contract檢查通過，只證明幾何。79組同角色尺寸／間距以及來源高度預算、狀態至操作距離核對保留於design-checks.json。來源、字寬與實際viewport均見measurements.json。

所有圖均為靜態設計，不能證明原生滾輪、鍵盤、焦點、hover、最大化、125%文字縮放、播放、保存或EXE可用。各項結果見check-list.md；這些原生項目仍未測，不宣告UI驗收完成。
