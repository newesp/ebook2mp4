## 布局／操作分組／空間分配對照

| 設計決策 | 後續原生實作對照 | 驗收方式 |
|---|---|---|
| 同一頂列保留全域操作及製作導覽；不足寬度時導覽換至第二列 | 沿用 desktop_shell 與 ProductionWorkspace。調整父層 grid，不壓縮標籤 | 還原視窗 → 確認導覽換列 → 確認專案及訊息不重疊 |
| 清單上方依序放選批、上移、下移、來源詳情；同組等寬 | AssemblyPage 工具列與 Treeview 共用內容邊界 | 按上移 → 檢查所選批次順序 → 確認勾選保留 |
| 清單擁有可捲動區；標頭及下方設定固定 | bounded Treeview；無整頁 ScrollPage 包住清單 | 捲至末列 → 確認最後一列可見 → 確認主要操作不動 |
| 停頓摘要與接點操作同列；開啟停頓設定時置換摘要，不另增加一整塊設定面板 | 共享 pause 變數；editable Workspace.TCombobox，0／0.5／1／2／5 秒及手動輸入 | 開啟設定 → 輸入 0.75 → 收合再展開 → 確認值保留 |
| 輸出勾選、狀態、結果操作放在同一格式列 | OutputControls 保留每格式狀態；不再另外建立一排重複成品入口 | 選 MP3 → 確認影片控制隱藏；選 MP4 → 確認影片來源與素材操作可見 |
| 底部摘要一列；返回靠左；保存及製作靠右 | 共用固定 footer；保存／製作同組 196×36、4px 淨距 | 製作中 → 確認取消可見 → 確認來源修改與重複製作停用 |
| 接點內頁並列前後文字；各自捲動；警告、播放及保存固定 | JoinPage 在同一宿主取代主內容，獨立 Text owner；保留目前 pair 與文字位置 | 長文捲至末行 → 確認另一欄不動 → 返回後確認順序不變 |
| 900×640 主畫面收合文件列表；接點頁省略重複情境列，釋放正文高度 | 釋放文件欄及間距；接點導覽仍可返回 | 開關文件列表 → 確認欄寬回收；縮小接點頁 → 確認警告與保存仍可見 |
| 詳情在同一主內容區替換清單 | 不新增彈窗；不丟棄清單 focus／排序／offset | 打開詳情 → 返回 → 確認選批及原閱讀位置保留 |

原生不能直接套用 PIL 圖片像素：Tk 座標與 DPI 換算須實測，元件同角色尺寸差≤2。圖中控制項高36px，同組水平淨距4px，來源工具列至清單標頭8px。接點兩欄是獨立內容區，中間12px；各欄校對按鈕同寬，此12px不是同一工具列的動作間距。

## 功能與保存契約

這份對照獨立於布局核對；保留功能不代表保留舊容器或比例。

| 既有功能 | 設計入口／行為 |
|---|---|
| 選批、排序、有效來源檢查及新成品版本辨識 | 來源清單與詳情；無效來源不混同成功成品。重新檢查不刪除選批草稿 |
| 合併設定保存 | 只按保存才提交選批、順序、停頓、接點確認；製作前沿用既有保存／驗證順序，失敗不顯示已保存 |
| 格式選擇原有即時保存 | 勾選格式沿用 OutputControls 的保存契約。底部「儲存合併設定」不改為格式選擇的第二個保存入口 |
| MP3／SRT、MP4／SRT 獨立結果 | 每格式一列；成功保留配對 SRT，失敗只重試未完成格式。只選 MP4 時依原路徑顯示必要的前置總音訊狀態，不偽稱已要求輸出 MP3 |
| 全書統一素材、沿用各批影片 | 已由現有「影片製作」模組處理。圖中的內嵌影片來源下拉／素材設定為未核准設計，應撤回；沿用現有模組的範圍、來源、素材、任務及保存契約，不另造平行入口 |
| 接點文字對照、校對、試聽與警告確認 | 主畫面檢查接點；前後文字來自該成品對應朗讀稿，不以目前未製作文字冒充。頁碼重疊、缺口及手動順序警告沿用既有規則 |
| 停頓及試聽 | 0～5 秒，最多三位小數。前後各播3／5／10秒；停頓全書共用，來源頭尾原有靜音另計。新增靜音不加字幕 |
| 播放、另存、資料夾、版本及來源比較 | 完成格式列的「成品操作」選單與「成品版本」。同一功能只留一處入口；不再加一排重複播放按鈕 |
| 檢查、忙碌、取消、失敗、保存失敗 | 各格式就地狀態＋底部摘要。執行中停用衝突變更，提供取消。保存失敗顯示「重試保存」；不重新合成／編碼。失敗或取消保留上次成功成品 |
| 同意與網路 | 本頁重用媒體，本機合併；無文字傳送控制。進入批次語音頁仍遵守該頁同意規則 |

只選一格式、缺項、取消、保存失敗與焦點／hover 尚未逐一出圖；後續整合前仍須補核相應狀態，不能用本批主畫面推定整條流程已驗收。

## 檢查證據與界線

執行 `python -B tools/draw_v2_book_merge.py` 產生28張設計圖及58筆來源布局量測；執行 `python -B tools/check_ui_scroll_contract.py docs/ui-review/v2-book-merge-redraw/scroll-contract.json` 通過。所有可溢出 owner 皆有短內容、剛好容納、略微溢出及長內容的設計案例；完全容納的停頓設定不另設捲動區。沒有整頁或水平捲動。

fit 案例的完整內容包含同份繪圖資料指定的尾端內距；content_height 與實際 layer 高一致，不把裁掉的文字當作容納。PIL 滑塊最少1個實體像素；實際原生最小滑塊與 Tk yview 換算留待原生驗證。

[design-checks.json](design-checks.json) 記錄128組繪圖座標尺寸／間距核對。來源版本為 [measurements.json](measurements.json) 的 source_sha256。完整檢查表見 [check-list.md](check-list.md)。這些是設計幾何與畫面證據，不是原生事件、資料保存、功能回歸或正式EXE驗收。本批不宣告UI驗收完成，也不重新封裝。

900×640 的來源清單視口為84px，約兩列；固定格式區142px。此尺寸優先保留輸出狀態及主要操作，不宣稱清單仍是最大內容區。1280×720 的視口164px，至少四列。

先前獨立靜態複核曾判定可送審；本次依使用者指出的既有模組與藍框布局重新核對，判定分組及空間分配未通過。
