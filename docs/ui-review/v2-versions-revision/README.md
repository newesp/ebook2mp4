## 功能契約

版本選擇保留朗讀稿、編輯備份、AI候選，並以目前編輯稿為比較基準。只有朗讀稿顯示刪除；刪除前確認且預設取消。還原前備份現稿，失敗保留現稿；過期AI候選只可還原為人工編輯稿。返回保留編輯狀態。此設計不改變既有歷史AI候選入口與其資料契約。

## 捲動與檢查狀態

[scroll-contract.json](scroll-contract.json) 由同一繪圖程式以視口高度及行數×行高產生；剛好容納含尾部留白。短／剛好容納／溢出／長內容在三個尺寸、列表收合及18pt組合有獨立圖與量測。執行 `python -B tools/check_ui_scroll_contract.py docs/ui-review/v2-versions-revision/scroll-contract.json` 通過。空狀態沒有捲軸；長差異滑塊比例依視口／完整內容計算。這只證明靜態繪圖幾何；滾輪、鍵盤、焦點、保存、原生比例及正式EXE尚未驗收。

[檢查清單記錄](check-list.md) 列出本批設計已檢查與仍待原生驗證的項目；不得以靜態圖或幾何檢查宣稱原生UI驗收通過。
