## 布局對照

- 頂列沿音訊製作：1文稿／2試聽與製作、語音設定與試聽→音訊製做→全書合併、影片製作，右側專案及訊息。
- 第二列左側匯入／管理；右側已存設定或歷史任務選擇與載入。左右工具列上緣一致。
- 文件清單與右側白色工作區上緣一致。服務選擇在右側工作區內，下面聲音設定與試聽內容並列；試聽文字取得主要空間。
- 摘要及頁面操作固定在底部。產生試聽、重播／停止位於試聽區，不混同保存及下一步。
- 全部控制項設計高度37像素，設定欄位沿同欄邊界配置；原生尺寸允差依check-list.md實測。

## 功能與狀態契約

保留載入已存／歷史設定、服務管理、音色ID與語速、自訂節奏、固定範例／帶入選取文字、試聽／播放／停止、設定保存範圍與下一步。線上同意預設勾選，取消禁止送出；本機不顯示線上同意。全書預設的套用既有批次入口、Gemini風格指示／Fish聲音ID等服務特有欄位，實作時依既有功能契約顯示，不從本圖刪除。忙碌時取消取代衝突的試聽操作；失敗保留文字及上一份成功結果。本批主畫面沒有改版服務管理／語音包等子頁。

## 設計檢查

scroll-contract.json與圖使用相同的視口、行高、完整內容高度；涵蓋短、剛好容納、溢出、長內容及聲音設定／文件列表區域。幾何檢查通過。短內容不繪製捲軸；只有超出的試聽文字顯示所屬捲軸，滑塊比例依內容計算。只繪製寬版，不聲稱窄版合規。靜態圖不能證明原生滾輪／鍵盤、保存、播放或正式EXE可用。
