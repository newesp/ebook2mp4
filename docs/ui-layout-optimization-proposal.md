# 元件配置優化提案

日期：2026-10-26（Asia/Taipei）。狀態：主要配置已依 mock 實作；使用者後續核定「儲存共通、確認放確認分頁」，現行結果見 `verification/ui-layout.md` 與 `DESIGN.md`。本文件保留規劃脈絡，未實作的延伸驗收不代表已完成。

依據：使用者提供的逐頁 PDF 截圖、上一輪原生工作台檢視，以及目前 `desktop.py`、`pdf_desktop.py`、`gemini_desktop.py`。沿用 Impeccable Operate 原則及 A 版工作台，保留綠色／紙色、原生 Windows 操作與並排對照。本輪兩個獨立代理分別檢視配置及訊息／來源可行性；未重跑程式或掃描器，未建立測試資料或程序。

## 核心方向

- 文字與頁圖為主體；頂部保留導航，底部保留提交與狀態。
- 常用動作直接可見，低頻命令用具名選單，設定按需開啟；不把所有按鈕等距攤滿。
- 主窗右欄以互斥頁籤取代長捲動工具清單；內容、批次清單與歷史記錄仍可捲動。
- 每個工作視窗有自己的固定訊息區；內容中只保留必要標籤、就近驗證與當前操作提示。

## 一、文件工作視窗與閱讀空間

「逐頁原稿／頁圖」及「預覽換行整理」首次開啟預設最大化，保留 Windows 標題列、工作列與還原按鈕；可還原及記住使用者尺寸。這符合希望全螢幕閱讀的目的，也方便切換外部 PDF 或文字編輯器。

Gemini 差異、TXT 預覽與保存版本也採可最大化的閱讀視窗；小型設定、命名及確認視窗保持精簡。記住各類工作窗的閱讀偏好、分隔線與字級；開啟時檢查目前螢幕工作區，避免多螢幕切換後視窗在螢幕外。

閱讀區設計目標：設定收起時，最大化的文件工作窗約 70% 以上可用客戶區高度留給正文／頁圖。此為後續驗收目標，並非已量測通過。最低支援尺寸仍需另外驗證，不靠縮小文字或按鈕達標。

主窗保留來源／校對並排，可調分隔比例；提供收合兩側欄的專注模式。寬螢幕可限制正文行寬並保留邊距，不將單行文字拉得過長。窄窗可由使用者切換單稿／並排，避免打斷對照時自行切換。

## 二、主工作台

| 區域 | 常駐 | 點選後才開啟 |
|---|---|---|
| 頂部精簡工具列 | 書名／批次、儲存、專注模式 | 「專案」：建立、開啟、位置、開啟資料夾；「版本與檔案」：匯出、重載、保存版本 |
| 工作階段導覽 | 精簡來源／校對階段；語音／影片註明尚未提供 | 操作說明；不再另占一整排長篇教學 |
| 左側批次欄 | 批次清單、每批文字狀態、「新增批次 ▾」 | 新增 TXT／PDF；「批次管理 ▾」：命名、上移、下移、移除 PDF 批次（分隔並保留明確確認） |
| 中央比較區 | 一行來源／版本摘要、原文、校對稿、可調分隔線 | 「原稿工具 ▾」：逐頁原稿／頁圖、預覽換行整理；長路徑等放詳細資訊 |
| 右側工具欄 | 「編輯／AI／確認」三頁籤，只顯示目前一頁 | 每頁的進階設定與說明 |
| 底部固定區 | 稿件狀態、作業訊息 | 訊息詳細記錄／阻擋項目；確認按鈕在右欄確認頁 |

右欄不建議多個可同時展開的手風琴：全部展開後會回到長捲動問題。三個頁籤保持固定尺寸與明確名稱：

- **編輯**：搜尋、下一個、取代文字、取代一處／全部取代、復原。搜尋及取代欄位有持續標籤；Ctrl+F 自動選到此頁並移入搜尋欄。
- **AI**：送出範圍（整批／選取文字）、繁簡統一、全形標點、開始校對、候選審閱入口；金鑰／模型放「AI 設定」。選取範圍先顯示摘要，切頁籤不得丟失原文字選取；沒有選取文字時清楚說明原因。
- **確認**：來源異常摘要、處理異常入口、目前朗讀稿摘要與歷史入口。主要確認按鈕固定於本分頁底部，避免在不同位置重複放置。

操作規則：切頁籤不清空輸入，不自行跳頁、不搶焦點；主區閱讀位置與文字選取保留。原始／校對版本、未存狀態、阻擋數量不因工具頁籤收起而消失。1040×640 與 Windows 縮放下，主要操作不能需要捲動工具欄才能找到；進階內容開獨立設定窗，必要時僅其長內容捲動。

## 三、逐頁原稿／頁圖

目前問題：`navigation` 上方資訊、頁碼、頁面選單、旋轉／OCR、保留／略過、區域重辨逐排堆疊；`retry_options` 以 `sticky='w'` 靠左，欄位沒有依功能分配可伸展空間。放大視窗只擴大右側空白，不能減少上方占高。

建議配置：

```text
文件名／批次摘要                         [OCR 設定] [資訊]
[上一頁] [第 1／9 頁 ▾] [下一頁]   頁面狀態   [旋轉 ▾] [重辨 ▾]
───────────────────────────────────────────────────────
                頁圖 │ 本次文字／原逐頁原稿／原批校對全文
          可縮放／拖移 │ 大面積文字，可調整左右分隔比例
───────────────────────────────────────────────────────
本頁：待檢查       [確認保留] [略過 ▾]     候選勾選（有候選時）
作業／警告／進度                         [關閉] [採用為新批次]
```

- 頁碼輸入、顯示頁面與整列頁面下拉整合為一組可輸入的頁面導航，保留實際 PDF 頁次與範圍限制，支援 Enter 及前後頁。
- 「重辨 ▾」包含本頁 OCR、框選區域、只重試失敗頁；直接顯示目前模式。進入區域模式後，在工具列原位顯示「框選圖片 → 選取原文 → 重辨」及條件完成狀態，執行按鈕直接可見。
- 「OCR 設定」集中範圍、擷取方式、語言、版面、模型狀態與下載。使用緊湊設定窗或可關閉的設定面板，避免永久增加閱讀區上方列數。
- 旋轉與縮放是閱讀操作，放頁圖附近；旋轉如何影響重辨須明示，不能把顯示旋轉和重辨設定混為一談。
- 頁圖初始適合整頁，可切適合寬度／原尺寸／自訂縮放；換頁重設不適用的框選與平移，保留使用者選定的閱讀縮放模式。
- 縮放、平移及旋轉後，框選仍須正確換算為來源區域；這是後續功能驗證重點，不能只改顯示圖大小。
- 「確認保留」「略過」處理來源疑點；「採用本頁候選」是候選勾選；「採用為新批次」才發布新批次。三種語意分開，不合成同一模糊按鈕。
- 略過保留明確意圖及原因／結果說明；需要決策時使用具名選項。關閉且存在候選時使用「捨棄候選並關閉」，不可和採用並列同一綠色主按鈕。
- 執行中顯示真實頁數進度與「取消辨識」；候選狀態才出現候選勾選與採用動作；保存失敗時保留候選，原位置提供「重試保存」。取消與關閉不是同一結果，不可只改一個標籤掩蓋差異。

## 四、換行整理預覽

最大化，預設左右「原始換行／整理候選」並排，可標示差異；窄窗或專注閱讀時改單欄頁籤。原始／候選的切換是檢視模式，放頂部，與取消／套用分開。

固定底部左側顯示短摘要與「規則說明」，右側為「取消／套用整理」。未有實質變更時提示「無需整理」；套用目前候選，不因正在查看原文頁籤而套用原文。保留套用前內容檢查、一次復原、未套用前不改稿等既有保護。

## 六、固定訊息區的規則

不是把所有內容搬進同一個 Label。每個工作窗底部保留穩定區域，分清持續狀態與操作消息；PDF 模態窗的錯誤顯示在 PDF 視窗內，避免使用者必須回主窗找。

| 類型 | 固定位置與呈現 | 消失時機 |
|---|---|---|
| 內容身分 | 頂部一行：書名／批次／頁碼／版本 | 隨正在查看內容更新 |
| 持續狀態／阻擋 | 底部狀態列：未存、未確認、待檢查數、候選過期、保存失敗；可前往處理 | 原因解除才移除；不能被「已儲存」等成功訊息覆蓋 |
| 工作進度 | 底部作業區：執行項目、真實頁數或下載量、取消 | 工作完成後成為結果，保留可讀記錄；無總量時不用假百分比 |
| 短暫結果 | 同一作業區：已儲存、已取代數、已匯出 | 下一個相關結果取代，完整結果可展開查看 |
| 欄位／操作條件 | 靠近錯誤欄位或目前模式的一行提示 | 修正後移除；不只靠顏色，不只放遠端訊息列 |
| 教學／詳細資訊 | 「說明」「詳細資訊」入口 | 使用者展開時顯示；不永久占多行正文高度 |
| 不可逆／外送決策 | 明確確認對話框，列出對象、範圍、後果 | 明確選擇後關閉；固定訊息列不能取代確認 |

最近訊息可展開為記錄窗或面板；預設收起，不增加閱讀區長期占高。摘要可複製，長路徑與全文錯誤可在詳細資訊查看；不在記錄保存 API Key 或未經需要的整份書稿。

## 七、實作順序與驗收

1. 統一工作窗框架：最大化／還原、頂部工具、閱讀主區、底部狀態及主要動作。
2. 先重排 PDF 與換行預覽，處理附圖的多排工具與頁圖適合閱讀。
3. 主窗改三頁籤工具、側欄收合、具名選單及持續狀態；最後統一 Gemini、匯入及版本視窗。

後續至少驗證 1040×640 主窗、740×570 PDF／候選窗、最大化與使用者 DPI；長檔名／長錯誤、中文按鈕、Tab／Escape、頁籤切換、下拉開啟、焦點可見。重要操作固定可見且無裁切；多個警告與成功並存時仍看得到阻擋原因。新排版不能改變取消、保存失敗、候選採用／撤回、未存保護與原稿不覆寫等行為。
