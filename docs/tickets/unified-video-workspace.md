## 目標與範圍

將本批與全書的影片製作整合到同一個主視窗工作區。共用素材、預覽、任務及成品的呈現方式，保留各條製作路徑的來源與保存契約。

| 範圍／方式 | 來源與操作 | 必須保留的差異 |
| --- | --- | --- |
| 本批影片 | 本批 MP3／SRT ＋ 圖片或背景影片 | 使用完整本批音訊；不加全書交接停頓；可先設定素材再補音訊 |
| 全書／統一素材 | 有效總音訊／SRT ＋ 全片素材 | 沿用音訊內的交接停頓，影片不再添加；素材可預先設定 |
| 全書／沿用各批影片 | 各批有效 MP4／SRT、排序、接點、解析度 | 不要求總 MP3 或全片素材；保持批次畫面與原聲，交接停頓處沿用前批末格 |

各批次及兩種全書影片方式分別保留素材、解析度、任務與成功成品。切換範圍不能覆蓋另一範圍設定。整合介面不等於合併底層任務或成品版本。

「音訊製做 → 製作 MP4」、全書合併的影片入口及成品更新入口，開啟同一工作區並帶入正確範圍／方式。返回原入口時保留批次選取、順序、設定、頁籤與捲動位置。影片不新增成必經步驟，音訊仍可直接進全書合併。

語音設定、文稿與音訊頁維持現有版面，僅調整必要入口。全書音訊、獨立 MP3／MP4 輸出、部分完成及只重試未完成格式等既有能力須保留。

## 最新版面要求（優先於舊 mock）

- 參照目前「音訊製做」介面：頂部集中導覽與範圍控制，主內容取得剩餘空間，狀態摘要與底部操作固定。
- 文件列表開關維持窄版 `[>]／[<]` 圖示；提供 hover／focus 提示及展開狀態。收合後釋放欄位與間距，鄰近保留重開入口。
- 「畫面與素材」「來源與順序」「任務與成品」使用真正的 tabs。原生採 `ttk.Notebook` 或等價可存取頁籤，具有明確選取狀態、焦點及鍵盤切換；不是三個一般操作按鈕。
- 移除重複的右上「成品」「來源與製作設定」及「狀態詳情」按鈕。完整訊息與來源資訊放在相應頁籤內；同一畫面不重複放相同操作入口。
- 底部返回在左、製作／更新／重試保存等主要動作在右。播放、停止、另存及資料夾集中在成品操作區；依可用寬度合理重排或具名選單收合。
- 同列控制項使用共用尺寸角色，量測上下邊界與高度，差異遵循元件規範。使用原生下拉指示符，不在標籤再手加箭頭。
- 每個內容區具有明確、受限的捲動範圍；避免整頁或整條設定側欄再包住內部清單。窄尺寸使用頁籤或專用內容檢視保留上下文，不裁切主要操作。
- 圖片／背景影片顯示適用欄位；預覽保留無聲播放、停止、時間定位、16:9 比例。短片保留循環／末格定格，長片按實際契約裁切。不能以示意圖取代真實可檢查的預覽。

## 功能與資料保護

- 保留來源失效／缺項阻擋、頁碼／接點警告、確認機制與可達的修復入口。不要以假資料補齊或直接改有效旗標取代真實驗證。
- 任務使用啟動時的來源與設定快照；拒絕過期非同步結果。跨頁不取消任務，忙碌時阻止會衝突的編輯或重複啟動。
- 明確區分未保存設定、已保存設定、預覽、進行中、成功、部分成功、失敗、取消及等待保存。保存失敗不能顯示成功或提高下游就緒狀態。
- 取消／失敗保留上一份成功成品。重試保存沿用已完成媒體；續作及只重試未完成格式沿用既有恢復機制。
- 保留來源媒體驗證、靜音背景、專案內素材保存、舊專案相容性，以及播放／停止／另存 MP4 與同版 SRT／資料夾／來源比較。
- 共用介面不應新增不必要的 TTS 請求、計費或文字傳送；沿用既有同意與權限契約。

## 驗收與交付

使用隔離合成專案與本機媒體。測試前記錄基線，保留有意改變與功能回歸的區別。

1. 1280×720、1536×864 正常縮放 → 開啟工作區 → 記錄實際 client 尺寸與縮放 → 確認主要動作完整可見。OS 限制尺寸時記錄實際值。
2. 縮小至 900×640 及測試支援的較大文字／125%縮放 → 確認控制項不重疊、沒有非必要水平捲動。不可用80%縮小畫面作為合格條件。
3. 顯示／收合文件列表 → 確認欄寬回收、焦點及重開入口可達。
4. 鍵盤切換三個 tabs → 確認選取與焦點一致 → 返回 → 設定及適當的內容捲動位置保留。
5. 本批選素材 → 真實預覽定位 → 製作 → 播放與另存成品 → 核對 MP4／SRT。
6. 全書統一素材 → 音訊缺項 → 確認阻擋與修復入口 → 補齊 → 確認交接停頓未重複添加。
7. 全書沿用各批影片 → 選批排序 → 處理接點警告 → 製作 → 確認無總 MP3 前置要求，且各批畫面與原聲保留。
8. 製作中切內容頁籤或離開再返回 → 確認任務保留；嘗試衝突操作 → 確認被阻止。
9. 製作失敗／取消 → 確認舊成品可用；保存失敗 → 重試保存 → 確認不重新編碼。涉及獨立格式時驗證部分完成與只重試缺項。
10. 使用超過數個畫面高度的來源清單／訊息 → 滾輪、捲軸、鍵盤到首末端 → 確認僅預期區域移動，固定操作仍可達。
11. 比較同列元件尺寸及單一下拉箭頭 → 先確認回歸測試能攔住缺陷，再核對最終 EXE 的畫面。
