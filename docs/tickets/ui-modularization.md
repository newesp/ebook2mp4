## 問題與完成目標

同一導覽、文件列表、工作區外框與底部操作列，應共用實作及布局規則。切換頁面時只更新內容及狀態，消除相同區塊在不同頁面的非必要差異。沿用現有 Tk／ttk，不另換框架。

附圖紫、紅、橘、藍分別代表頂部導覽、文件列表、主要工作區及底部操作列。顏色僅用於說明模組，不加入正式介面。

重構涵蓋文稿、同窗工具、語音設定與試聽、音訊製做、全書合併、影片與成品版本等相關頁面。各頁功能內容仍由專屬模組提供；共用外框依情境顯示適用區域，不要求所有內容變成同一表單或表格。

## 模組契約

- 主框架持有頂部導覽、文件列表、內容承載區與底部操作列；共用控制項建立一次並留在固定父容器。
- 內容頁只配置自己的內容。頁面提供導覽位置、標題／工具、摘要、操作描述與可用狀態；共用模組管理尺寸、分組、重排及顯隱，不讓各頁取得共用控制項後任意改布局。
- 操作描述至少包含穩定識別、名稱、用途角色、執行動作及可用狀態。返回、次要、刪除與主要動作可辨識；切頁後不得殘留上一頁的按鈕回呼或重複綁定。
- 目前頁面、選取批次及背景任務具有各自清楚的持有者。結果依原專案／批次／任務識別更新；離頁不代表取消工作，隱藏的舊頁不能改寫目前導覽與操作。
- 沿用現有頁面快取；離頁／返回保留草稿、選取、捲動、頁籤與面板狀態。關閉、專案替換及釋放快取時，解除綁定並清理計時器與自建播放資源，不終止使用者程序。
- 共用 UI 不改專案格式，不擴大磁碟保存範圍，不合併不同來源方式的任務或成品版本。

具體類別、檔名及介面型別在實作盤點後決定；不可只拆檔卻保留各頁交叉修改主框架的耦合。

## 功能保留契約

1. 保留匯入、來源核對、文稿編輯、全文 AI 校對、版本、來源工具及原子保存朗讀稿；未存稿、來源異常及過期結果保護繼續生效。
2. 保留全書／本批語音設定、試聽、來源預覽、服務管理與本機套件入口。需同意的雲端 TTS 取消勾選後不得送出，切頁不重設選擇；本機情境隱藏無關控制，文稿 AI 不恢復已移除的同意框。
3. 保留音訊歷史任務、增量重用、開始／續作／取消／重新開始、錯誤詳情及重試保存；失敗保留成功區塊及舊成品。
4. 保留全書批次選取、順序、停頓、MP3／MP4 獨立輸出、部分完成及只重試未完成格式。
5. 保留本批影片、全書統一素材及沿用各批影片的來源差異、素材、設定、預覽與成品版本隔離；不新增 TTS，不重複添加交接停頓。
6. 保留播放／停止／另存／資料夾、成品版本及返回原入口的能力。播放／預覽離頁依原規則停止；製作任務跨頁持續。保存失敗不宣稱成功、不提高下游就緒狀態。

實作前將各項展開為「能力 → 現有入口 → 遷移後入口 → 驗證證據」清單，確認功能仍可到達。

## 遷移順序與檢查點

0. 完成 v1 基準封存 ticket。保存完整來源、成品、雜湊與獨立啟動證據；確認必要的工作區修改已包含後，再開始 v2 產品程式開發。文件與設計準備可先進行。
1. 盤點所有頁面、同窗工具與操作入口。補齊功能清單、狀態持有者及現況尺寸。
2. 提供正常、縮小及工具展開設計圖。依 AGENTS.md 第 12 點取得新增布局確認；已明確指定的模組化需求不重問。附圖的區塊標記不代替完整設計。
3. 建立原生主框架。先接入頂部導覽及文件列表，確認收合、選取與導覽連動。
4. 接入共用底部操作列。逐頁替換原操作列，檢查摘要、忙碌狀態、回呼與入口沒有重複。
5. 建立工作區外框。本輪使用者指定先實作文稿，目前只接入文稿主介面；同窗工具內頁仍沿用 v1，須先依 [內頁交接](v2-inner-pages-handoff.md) 遷移，再接語音、音訊、合併、影片及成品版本。每頁先對照原生主布局，再整合完整功能；新增布局須依既有確認點核准。
6. 跑受影響回歸與原生跨頁驗收。修復所有布局落差後，才進行正式封裝及 EXE 驗收。

## 驗收路徑

使用隔離專案與受控服務，不為 UI 驗收傳送私人書稿或新增計費請求。記錄實際客戶區尺寸、系統縮放、文字大小及各區量測值。至少涵蓋最大化、1360×820、1280×720、900×640，以及既有 18pt 大字情境；各尺寸的重排與可用空間門檻在設計階段確認，不靠縮小字體過關。

1. 文稿 → 語音設定 → 音訊製做 → 全書合併 → 影片 → 成品版本 → 返回。確認頂部、文件列表與底列使用共用規則；同尺寸角色高度差在 2 個 Tk 座標像素內。
2. 輸入未存文字 → 切頁 → 返回。確認文字、選取及捲動位置保留；保存失敗時不丟稿、不前進。
3. 在批次 A 調整設定 → 切至批次 B → 返回 A。確認設定及頁面範圍正確；本批與全書資料互不覆寫。
4. 收合文件列表 → 縮小視窗 → 展開工具。確認空間釋放、主區達設計門檻、主要操作及重開入口可達。
5. 載入數倍於視窗高度的內容 → 用滾輪、捲軸及鍵盤到末端。確認只有目標區移動，末行可達，導覽及主要操作固定。
6. 取消雲端同意 → 切頁 → 返回 → 嘗試開始。確認仍未勾選且請求數為零；本機頁不顯示無關控制，文稿頁沒有新增同意框。
7. 開始製作 → 切頁 → 返回。確認原任務持續、沒有重複工作；忙碌時衝突操作停用。
8. 切換批次或專案 → 讓舊任務回傳。確認結果留在原範圍，目前頁面摘要與操作不被覆寫。
9. 觸發部分失敗／取消 → 返回任務。確認狀態正確、成功區塊及上一版成品保留；重試保存不重做合成。
10. 切換操作列 → 執行主要動作。確認只觸發目前頁面的動作；隱藏頁沒有殘留回呼或重複入口。
11. 關閉程式 → 重開隔離專案。確認既有已保存設定、任務恢復與版本關聯正確；退出後沒有本次遺留程序、計時器或占用資源。

回歸優先沿用 `test_production_pages.py`、`test_batch_step_retention.py`、`test_audio_production_ui.py`、`test_main_workflow_desktop.py`、`test_manuscript_v6.py`、`test_unified_video_workspace.py`、`test_video_layout_revision.py` 及相關保存／退出測試。補充能攔住跨頁布局偏移與狀態遺失的案例；只檢查控制項存在、樣式名稱或未越界不足。
