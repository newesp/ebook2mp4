## 範圍

- 導覽與相關返回入口改名「音訊製做」（保留使用者指定字形）。
- 僅調整音訊工作區及必要相鄰入口文字。語音設定與試聽、影片、全書合併、全書成品不改版。
- 影片流程整合另案處理，本次只保留可達入口。
- 保留既有未提交修改；不以 Git baseline 覆寫檔案。

## 版面與空間預算

```text
語音設定與試聽 → 音訊製做 → 全書合併
任務選擇                         朗讀稿與任務設定
目前狀態／進度（簡短摘要）
┌ 區塊  狀態  嘗試  說明 ──────────────────┐
│ 長清單取得剩餘空間；僅清單垂直捲動       │
└────────────────────────────────────────┘
上一版／目前成品摘要
返回／同意傳送     成品操作／重新開始／主要任務動作
```

- 長文與任務來源按需在同工作區切換，保持父導覽選取與返回入口；不得永久切走清單的大部分高度。
- 同級按鈕一致尺寸；功能相關操作同列，窄尺寸按優先級重排或收進有明確名稱的選單。不可用縮小系統顯示來掩蓋問題。
- 主要動作與導覽固定；不以整頁捲動包住表格，不靠隱藏或裁切控制項解決溢出。
- 文件列表收合後釋放欄寬；如共用殼已有正確行為，避免無關重構。

## 功能保留清單

歷史任務選擇、原設定恢復、來源重檢、送出文字預覽、固定快照、來源失效阻擋、增量重用、雲端同意、本機情境、開始／續作／取消／重新開始、錯誤詳情、重試保存、跨頁保留任務、舊成功成品保留、播放／停止／另存／資料夾／本批影片入口。

不改資料模型、服務呼叫、快照、保存或恢復契約。失敗不得顯示成功；同意取消後不得送出文字。

## 驗收

使用隔離專案與假服務，不傳送真實文字、不修改使用者專案。

1. 1536×864、正常縮放 → 開啟音訊製做 → 至少可見 6 個完整區塊列。
2. 1280×720、正常縮放 → 至少可見 4 個完整區塊列 → 主要操作不裁切。
3. 收合／展開文件列表 → 主區回收欄寬 → 選取與工作狀態保留。
4. 開啟朗讀稿與任務設定 → 父導覽保持選定 → 返回 → 表格選取與捲動位置保留。
5. 長清單 → 滾輪、捲軸及鍵盤到末列 → 最後內容與固定操作可達。
6. 取消雲端同意 → 開始 → 確認不送出；本機情境不出現無關同意要求。
7. 製作 → 切頁 → 返回 → 任務繼續；失敗／取消 → 成功區塊與上一版成品保留。
8. 保存失敗 → 重試保存 → 不重做已完成合成。
