## 必須落實

1. 左上只有「1 文稿」「2 試聽與製作」；專案操作在右上。文件清單區集中匯入與管理，同列呈現。列表、原稿、文稿的主要內容上緣齊頭。
2. 文件列表收合須移除其網格欄及間距，使 PDF／文稿等寬填滿剩餘區域；不能只隱藏內容留下空軌道。附近標頭保留可聚焦的開關，提供「顯示／隱藏文件列表」提示。原稿隱藏、工具頁開啟及窄視窗時仍可恢復列表。
3. PDF 與文稿預設 1:1，可調整並保留狀態。PDF 頁碼、符合頁寬、縮放與「來源」相鄰。「開啟來源 PDF」放來源選單內，不另占正文或工具列。缺檔要有可行提示。
4. 文稿工具順序：顯示／隱藏原稿、編輯、校對、版本、暫存草稿。「AI 全文校對」在校對選單首項，與 AI 設定相鄰。使用一致控制項樣式，合理時同列，較窄時按群組重排而非裁切或縮字。
5. 版本紀錄、AI 設定、來源處理切換同窗完整工作區，返回保留文字、選取及捲動。固定標頭和操作列，中間內容擁有唯一的垂直捲動；不在可捲外框內再嵌編輯器／差異捲動。來源框選若需原頁，採明確並列設定與預覽區，各自指定捲動責任。
6. 共用文件摘要、版本、字元數及保存結果集中底部；頁碼、差異基準、設定錯誤等留所屬區域。底部主要動作依狀態為儲存朗讀稿或前往製作，部分校對的續作／保留原文選項相鄰。

## 原更多工具完整對照

| 新入口 | 必須保留的功能 |
| --- | --- |
| 編輯 | 搜尋與取代（Ctrl+F／Ctrl+H）、整理換行預覽、匯出目前全文 TXT、重載外部稿 |
| 校對 | AI 全文校對、AI 設定、顯示／隱藏差異、還原游標處改動、放棄本次 AI 結果 |
| 版本 | 版本紀錄、開啟歷史 AI 候選 |
| 來源 | 開啟來源 PDF、來源處理、來源異常 |

不要照搬 mock 的提示訊息、假資料或不完整處理作為正式功能。搜尋、版本還原、匯入／重載、來源辨識及 AI 等須接回真實邏輯。保留旋轉、框選重辨、失敗頁重試、TXT 編碼、可自訂模型與安全憑證儲存。不適用的功能依來源及工作狀態隱藏／停用。

## 不變的資料契約

單一全文編輯器、全文 AI 校對、取消／重試／續作、部分結果明確選擇、來源異常阻擋、版本備份、過期結果拒絕、草稿恢復、朗讀快照與畫面全文原子一致、重複儲存不重建版本、舊專案相容均須保留。不要恢復傳送勾選框、額外傳送說明、逐段採用要求或獨立朗讀確認頁。不改版語音與影片流程。

## 驗收及交付

- 收合文件列表 → 確認空欄及間距消失、原稿／文稿等寬填滿；重新展開 → 確認文件選取保留。
- 隱藏原稿／切工具頁／縮小視窗 → 確認列表可重新展開、主要動作可達。
- 開啟各選單 → 逐項完成原功能 → 記錄入口與結果，不以按鈕存在代替功能通過。
- 載入長文及長版本差異 → 捲到兩端 → 確認只有目標內容移動、標頭與操作列固定；返回編輯 → 確認文字、游標及捲動保留。
- 以最大化、還原視窗及適用文字縮放驗收 → 記錄實際客戶區尺寸、DPI、編輯區高度及可見行數 → 確認內容可讀、三區齊頭、控制項不重疊裁切。
- 驗證部分失敗、取消、晚到結果、保存失敗及舊專案恢復；確認資料契約不回歸。

完成相關測試、原生 UI 截圖及操作驗收、封裝啟動檢查，只更新正式成品至 `dist/ebook2mp4`。保留需求文件與最終證據，清理本次測試資料、建置暫存、快取及自有程序，確認無遺留資源。回報實作結果及未驗證範圍；mock 的語法檢查不能當成原生 UI 通過。
