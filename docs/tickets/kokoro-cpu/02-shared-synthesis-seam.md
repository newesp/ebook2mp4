# K02：前置整理：共用語音服務能力與合成接點

## Parent

[規格 #2：Kokoro 官方中文版本機 CPU 語音整合](https://github.com/newesp/ebook2mp4/issues/2)

## What to build

讓現有服務透過共同能力與合成接點完成原有設定、試聽、正式製作及續作，為本機服務接入作準備。以既有公開操作流程證明整理後的使用行為及舊專案相容性。

## Acceptance criteria

- [ ] 沿用 ProjectWorkflow 公開入口；將試聽與正式製作的服務差異集中於共用合成接點，不新增第二套對外製作流程。
- [ ] 能力契約能區分本機／雲端、音色來源、文字限制及載入／合成限時；保留既有服務的既定政策。
- [ ] 以現有服務完成設定 → 試聽 → 正式製作 → 取消及續作 → 確認輸出、進度及舊成品保護維持原行為。
- [ ] 雲端傳送同意取消勾選 → 嘗試產生未快取音訊 → 確認沒有送出文字。
- [ ] 開啟舊專案及舊音訊紀錄 → 確認設定、快取與成品可讀；保存再重開 → 確認選值保留。
- [ ] 測試觀察公開狀態、成品及續作行為，不以私有函式呼叫順序作為主要驗收。
- [ ] 本票不新增 Kokoro 可用宣告、不改 UI 版面、不擴張為通用插件平台；完成後清理測試暫存及程序。
