# K04：在主程式安裝與移除離線語音包

## Parent

[規格 #2：Kokoro 官方中文版本機 CPU 語音整合](https://github.com/newesp/ebook2mp4/issues/2)

## What to build

使用者從已確認的主視窗介面匯入完整離線語音包，檢查後看到可用版本與全部官方中文音色，也能安全移除語音包。此票先交付可驗收的包管理路徑，合成接續下一票。

## Acceptance criteria

- [ ] 交付包含 Python 3.12、CPU 依賴、官方模型／全部官方中文音色及中英前處理完整資源的語音包；保留來源修訂與授權通知。
- [ ] 從主程式匯入語音包 → 檢查完整性、版本與相容性 → 成功後才啟用並顯示中文音色目錄；不依賴系統 Python 或終端機。
- [ ] 只有有品質證據的音色標示已驗證；其餘可用音色不得冒用驗證標示。
- [ ] 匯入損毀、不完整或不相容包 → 確認給出修復指引且沒有半完成安裝；失敗不破壞原有有效安裝。
- [ ] 安裝使用暫存區並驗證目標位置；包內路徑不得寫出指定安裝範圍。
- [ ] 選擇移除 → 確認僅移除所選包，書籍、有效快取及成品保留；使用中資源不得直接刪除。
- [ ] 重開程式 → 確認已安裝／已移除狀態正確；未安裝 Kokoro 仍可校對並使用其他已支援流程。
- [ ] 以公開流程測試安裝、失敗回復及移除；依核准設計驗收還原視窗與狀態保留，清理本次暫存。
