# K06：連續試聽、閒置卸載與程序清理

## Parent

[規格 #2：Kokoro 官方中文版本機 CPU 語音整合](https://github.com/newesp/ebook2mp4/issues/2)

## What to build

連續試聽及同一次製作重用已載入模型，閒置後歸還記憶體；取消、失敗或關閉主程式後不留下推論程序及檔案占用。

## Acceptance criteria

- [ ] 連續產生兩次試聽 → 確認模型可重用且聲音設定各自正確；以實測記錄重載與暖啟動差異。
- [ ] 依可行性量測制定並記錄閒置期限；到期卸載 → 檢查記憶體與模型檔占用 → 確認釋放；再次試聽可重新載入。
- [ ] 工作進行中 → 超過閒置期限 → 確認不卸載執行中的模型。
- [ ] 取消載入／推論或模擬程序失敗 → 確認工作結束且資源回收；下一次明確重試可正常啟動。
- [ ] 關閉主程式 → 檢查其推論子程序及後代程序 → 確認全部結束，模型與音訊暫存檔可解除占用。
- [ ] 使用語音包期間要求移除 → 確認依核准流程阻止衝突或先安全釋放；不得刪除使用中的資源。
- [ ] 使用真實 Windows 程序驗證生命週期，不以 mock 成功代表資源已釋放；保留耗時與占用證據，清理測試程序。
