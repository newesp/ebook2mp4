## Parent

[規格 #2：Kokoro 官方中文版本機 CPU 語音整合](https://github.com/newesp/ebook2mp4/issues/2)

## What to build

使用者在現有語音流程選擇 Kokoro、音色與語速，保存為全書預設或批次設定，離線試聽固定範例或選取文字並播放；失敗或取消保留舊結果。

## Acceptance criteria

- [x] 選擇 Kokoro → 選官方中文音色及語速 → 保存全書語音預設／批次語音設定 → 重開後確認選值保留，既有批次不被新預設回寫。
- [x] 主程式透過包內 Python 3.12 獨立程序指定 CPU 推論；不使用系統 Python、GPU 或可見終端機。
- [x] 既有網路封鎖試聽及真實 CPU 驗證保留於本輪結案紀錄。本輪正式版驗證重播及停止。
- [x] 原文與合成副本分離；必要繁簡／數字前處理不改寫校對稿或朗讀稿；記錄前處理與模型版本。
- [ ] 原生停止、播畢及取消關頁回歸通過，正式版停止已實測。窄版文字、部分 UI 狀態與正式版播畢畫面未全數驗收。
- [x] 在載入或合成期間按取消 → 確認推論停止並回收該工作；失敗及取消保留先前成功試聽。
- [x] 缺少或損毀語音包、音色不存在或推論失敗 → 顯示可執行的修復指引；不套用雲端退避、不自動切服務。
- [x] 原音快取包含模型／引擎／前處理版本、合成文字、音色及語速；音訊可完整解碼為既有共用 PCM 格式。
- [x] 以 ProjectWorkflow 覆蓋選取範圍、設定快照、保存重開、失敗及取消；保留真實 CPU 試聽證據並清理暫存。
