# K01：官方中文版 CPU 可行性驗證

## Parent

[規格 #2：Kokoro 官方中文版本機 CPU 語音整合](https://github.com/newesp/ebook2mp4/issues/2)

## What to build

以官方模型及推論程式，在獨立 Python 3.12 環境產生可供人工試聽的真實音檔，證明純 CPU、完整離線及可釋放資源的可行性，讓使用者決定後續整合範圍。此票不修改正式 UI，也不預設重寫 Kokoro。

## Acceptance criteria

- [ ] 記錄 Windows、CPU、核心／執行緒、RAM、Python、依賴與官方模型修訂；主程式維持 Python 3.14.3。
- [ ] 使用官方中文版權重與音色 → 指定 CPU 合成 → 確認不需 GPU、CUDA 或雲端服務。
- [ ] 準備完整資源 → 使用無既有模型／語言快取的隔離環境 → 封鎖網路 → 確認第一次合成成功且無資源下載。
- [ ] 合成繁中、多音字、數字、日期、中英夾讀及長段落樣本 → 保留原文與音檔 → 列出誤讀、漏句、重複、裁尾及語速異常，交使用者試聽。
- [ ] 量測冷載入、暖試聽、長稿合成、輸出長度、記憶體峰值、取消／卸載時間及完整資源大小；不預填未量測的效能門檻。
- [ ] 取消或結束驗證 → 檢查子程序與檔案占用 → 確認已釋放；保留證據，清理本次測試暫存。
- [ ] 記錄相容性修改及成本、已通過／未通過／未驗證項目；標明少數音色結果不代表全部音色。
- [ ] 交付結果供使用者審閱 → 記錄效能與聽感是否可接受及後續整合範圍；取得決定前，本票不得以技術成功取代審閱而宣告完成。

## Blocked by

None (can start immediately).
