## What to build

使用者取消或遇到程序中斷後，可重開專案並只製作缺少的有效音訊；更換模型、音色或前處理版本時，不將舊聲音誤當新結果。

## Acceptance criteria

- [ ] 完成第一區塊 → 取消 → 重開專案 → 續作 → 確認只合成缺少區塊，原朗讀稿與設定快照可追蹤。
- [ ] 以真實子程序模擬非正常結束 → 重開 → 確認可恢復工作狀態及鎖，不覆蓋其他執行中的工作。
- [ ] 損毀或截斷快取音訊 → 續作 → 確認完整驗證後才可重用，不採用部分輸出。
- [ ] 更換模型內容／版本、引擎或前處理版本、音色或語速 → 確認不重用不相容原音；舊工作不混入新版本。
- [ ] 只更改額外停頓 → 再製作 → 確認重用有效原音並重建音訊與字幕時間軸。
- [ ] 已移除必要語音包或將專案搬至缺包電腦 → 開啟及續作 → 確認提示必要版本，不暗換模型或雲端；有效舊成品仍可使用。
- [ ] 原子發布時模擬空間不足或寫入失敗 → 確認舊成品可讀，續作不重做已驗證區塊。
- [ ] 沿用 ProjectWorkflow 及既有真實中斷測試形式；清理本次鎖、暫存及程序，保留恢復驗證證據。
