# K03：確認 Kokoro 操作流程與介面設計圖

## Parent

[規格 #2：Kokoro 官方中文版本機 CPU 語音整合](https://github.com/newesp/ebook2mp4/issues/2)

## What to build

提供同一主視窗內的完整操作設計，讓使用者在實作前確認語音包管理、音色選擇、試聽與製作狀態，以及視窗縮小後仍可操作的配置。

## Acceptance criteria

- [ ] 提供安裝／移除語音包、選服務／音色／語速、固定範例／選取文字試聽及正式製作的操作路徑與設計圖。
- [ ] 涵蓋未安裝、檢查中、安裝成功、缺少／損毀／不相容、載入中、合成中、完成、失敗及取消狀態。
- [ ] 顯示本機處理及已驗證音色；不要求 API key；技術版本與長說明按需展開。
- [ ] 返回設定或切換內頁 → 確認輸入狀態有明確保留規則；主要下一步、返回及刪除操作清楚區分。
- [ ] 提供最大化與還原／較小視窗配置 → 確認必要操作可見、按鈕不裁切、文字不重疊，避免水平及巢狀整頁捲動。
- [ ] 清楚標示忙碌時停用的衝突操作及可用的取消操作；不以連續新視窗串接主流程。
- [ ] 依可行性結果說明選定的閒置卸載及限時政策；未定數值明列，不捏造效能承諾。
- [ ] 取得使用者對設計圖的明確確認並保存決定；本票的完成不等於已實作畫面。
