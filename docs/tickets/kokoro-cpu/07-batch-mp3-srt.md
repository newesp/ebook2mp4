# K07：由已確認朗讀稿製作批次 MP3／SRT

## Parent

[規格 #2：Kokoro 官方中文版本機 CPU 語音整合](https://github.com/newesp/ebook2mp4/issues/2)

## What to build

使用者確認朗讀稿後，以 Kokoro 離線製作完整批次 MP3／SRT；長稿分塊、停頓、進度與字幕共用既有流程，原文與上次成功成品受到保護。

## Acceptance criteria

- [ ] 未確認或來源異常未處理 → 嘗試正式製作 → 確認阻擋；確認朗讀稿後才可開工。
- [ ] 開始製作 → 固定朗讀稿與設定快照 → 執行中修改設定或校對稿 → 確認當次結果不混入新版本。
- [ ] 使用已量測的本機切分及載入／合成限時政策；長稿逐塊覆蓋原文一次，不靜默截斷，不直接沿用雲端請求限制。
- [ ] 合成副本做必要前處理 → 確認來源、校對稿、朗讀稿與 SRT 仍保留原文字體及內容。
- [ ] 完成所有必要區塊 → 完整解碼 MP3 → 確認單塊 PCM、停頓與實測字幕時間一致，新增停頓不誤顯正文。
- [ ] 顯示目前區塊及整體進度；取消、合成失敗、空間不足或發布失敗 → 確認舊 MP3／SRT 保留且部分結果不宣告完成。
- [ ] 同一次製作重用模型；不與並行試聽、包移除或其他產出工作衝突；關閉或取消採既有安全清理契約。
- [ ] 完成真實繁中與混讀長稿試聽，記錄漏句、重複、裁尾及語速問題；以 ProjectWorkflow 驗證正式製作路徑並清理暫存。
