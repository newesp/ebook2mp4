# 一本書一個專案，以製作批次保存分段成果

2026-10-25，使用者確認專案代表一本書；同一本書可以分次選取內容，例如 PDF 第 21～50 頁，各批次以不同檔案保存成果，首版可將批次 MP4 合併為總影片。這取代每個頁碼範圍另建專案的方案，讓書籍資料與分批製作進度留在同一專案，也避免把長書製作綁成一次不可分割的輸出。

使用者進一步確認各批次獨立保存校對稿、校對進度與朗讀確認；修改一批不取消另一批的確認。全書語音預設供新批次沿用，各批次可個別調整；變更預設不自動修改或重新產生既有批次。

合併時使用者選擇批次與順序，PDF 批次預設依起始頁排序並可手動調整；重疊或缺頁僅提示，由使用者決定是否繼續，不自動刪除或補入內容。每份匯入 TXT 可成為同書專案的獨立批次，也可與 PDF 批次並存；TXT 使用名稱與手動排序，不假造頁碼，首版不自動分章拆檔。

總影片另附總 SRT，字幕依實際接續時間偏移。相鄰批次間預設額外補 0.5 秒靜音，可透過介面調整為 0～5 秒並預覽接點；保留原音訊頭尾，新增停頓期間顯示前一批最後一格並清空字幕，末批後不再補交接停頓。合併前顯示前批結尾與後批開頭供使用者檢查半句銜接，可返回校對調整，不自動跨批搬動或刪改文字。

可統一不同批次解析度，保持比例，不新增 TTS 請求；音色或語速不一致只提醒。總影片追蹤選入批次的版本，這些批次修改校對稿或更新 MP4 後，既有總影片標為待更新但保留可播；重新合併只選取與目前內容一致的有效 MP4，未選入批次的變更不影響這份總影片。

後續增補已加入總音訊 MP3，並允許由完成的總音訊直接搭配視覺素材製作總影片；上段的批次 MP4 依賴適用於「合併批次影片」路徑，不限制「總音訊製片」路徑，詳見總音訊獨立製作決策。
