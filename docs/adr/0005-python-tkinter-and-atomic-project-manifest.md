# Python／Tkinter 桌面與原子發布的專案索引

2026-10-25，T01 選用 Python／Tkinter 原生桌面視窗，搭配 PyInstaller 包含 Python、Tcl／Tk，日常使用不需要終端機或本機網頁伺服器。相較 Electron／WebView，可避免 T01 引入瀏覽器執行環境及橋接層，亦方便後續接本機 OCR／媒體程序；代價是須自行維護原生版面、字型與高 DPI 驗證。完整安裝包與媒體工具的交付仍由 T23 完成。

專案採版本化 UTF-8 project.json 索引，來源與每次儲存的校對稿分開成檔，全部以專案相對路徑及 SHA-256 記錄。相較單一可變文字檔，先寫入獨立內容檔、flush／fsync 後，以同目錄暫存及 os.replace 發布索引，讓失敗時仍可開啟前次成功版本；代價是保留舊稿與未參照的中斷檔案，目前不自動回收。索引格式版本 1 僅定義已實作領域，不預填尚不存在的朗讀確認或成品。

UI 與行為測試共用 ProjectWorkflow。寫入採排他鎖與索引雜湊比對，避免兩個視窗互相覆寫；非協作式的外部編輯仍由開啟／儲存時的雜湊驗證偵測。程序中斷留下的 .write.lock 會提示關閉視窗後移除再重開，不自動猜測安全性。

T03 增補：v1 批次以可選欄位 `readings`、`current_reading`、`draft_copies` 與 `source_issues` 保存已實作的朗讀快照、目前確認、重載副本與來源異常；舊專案缺少欄位時視為無確認／副本／異常。朗讀快照具有識別、校對版本、確認時間、相對路徑與 SHA-256；編輯時立即以索引提交取消目前確認，保存及重載也經同一失效規則，歷史快照不改寫。重載的校對稿與可選未存稿副本在同一次原子索引發布，避免副本保存失敗卻覆蓋編輯器。開啟時驗證歷史快照／副本的檔案與雜湊，以及目前確認與校對稿的一致性。T03 專案應使用 T03 或更新版本續作，舊程式不理解朗讀確認。
