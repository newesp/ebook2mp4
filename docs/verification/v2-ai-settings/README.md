# AI設定 v2 共用內頁

使用者指定依mock重作；補充指定常駐「測試連線／儲存設定」，移除獨立「儲存連線」。本輪以此補充取代舊mock按鈕配置。

## 模組與功能契約

AiSettingsPage（manuscript_settings.py）持有表單、連線展開狀態及呈現資料；InnerPageHost管理固定標頭、返回、範圍及ActionBar。文稿控制器持有偏好、連線與任務生命週期。原生內容固定以host.content為父層，舊工具容器不再承載此頁。

| 能力 | 入口／狀態持有者 | 保留或調整 |
|---|---|---|
| 文字／字級／標點／自訂模型 | 校對→AI設定；文稿控制器／workflow | 偏好變更即保存，錯誤保留輸入 |
| 本機金鑰 | 同頁服務連線設定展開 | 遮罩顯示，只保存於本機，收合保留輸入 |
| 儲存設定 | 常駐操作列 | 保存本機金鑰／模型及專案偏好；驗證字級後才寫入；部分保存失敗不報全部成功 |
| 測試連線 | 常駐操作列 | 先保存再沿用背景工作；忙碌時阻止衝突命令 |
| 返回 | 共用標頭唯一返回 | 保留文稿游標／選取／捲動與本頁輸入 |

## 布局與驗收對照

兩欄欄位對齊，同角色控制項使用Workspace尺寸。連線展開保留上方偏好，收合移除欄位軌道。頁面只有表單Canvas一個捲動擁有者，實際溢出才顯示捲軸。狀態與兩個命令在固定操作列。native.json記錄三尺寸、展開／收合、表單視口與完整內容高度及元件外框；原尺寸png逐張核對。

功能結果見final-tests.txt，包含共用宿主、兩按鈕在展開收合狀態皆可用、失敗保留輸入、合併保存及無效字級阻止連線寫入。測試使用合成專案及受控回呼，沒有實際連線請求或寫入真實金鑰。

正式建置見build.txt；封裝與來源一致性見package.json；隔離啟動／正常退出見exe-startup.json。完整正式EXE逐頁人工、所有DPI與長錯誤操作尚無本輪證據，不宣告完整UI驗收完成。逐項清單見check-list.md。
