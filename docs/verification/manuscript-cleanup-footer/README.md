## 原生操作

使用 `tests/cleanup_visual_fixture.py`。合成內容為 200 段、7,888 字元，含 200 個可整理的單一換行；另有無須整理且已保存朗讀稿、受控 AI 失敗的兩份文件。沒有使用私人書稿或真實服務。

- 編輯 → 整理換行預覽 → 確認任務名稱正確、來源操作不可見。
- 點差異 → Ctrl+End → 確認第 200 段可見，標頭與操作列固定。縮為 900×640 → 重做末端檢查。
- 模擬保存失敗 → 檢查工具底列 → 確認錯誤可讀、原稿雜湊不變。重試套用 → 返回文稿 → Ctrl+Z → 確認原始雜湊恢復。
- 開啟無變更文件 → 整理換行預覽 → 確認只有返回、沒有空文字框／捲軸／套用，朗讀確認保留。
- 模擬未完成 AI 校對 → 確認續作與保留原文相鄰，主要保存停用 → 按保留原文 → 確認選擇已保存，主要保存啟用。

實際客戶區、DPI、按鈕 bounds、內容雜湊及可見／停用狀態存於同名 JSON。Windows 125% 縮放下的 Tk DPI 約 96.095；原生截圖實體像素與 Tk 單位分開記錄。最終變更計數與白色工具內容區以正式封裝截圖為準，初輪截圖保留驗收歷程。
