## 本輪修正

- 中文金額的標準千位分組先移除逗號，讓官方前處理將 `1,280元` 讀成「一千二百八十元」。
- 明確標示的前導零編號逐碼朗讀，`編號是007` 保留「零零七」。
- 明確標示的電話分機逐碼朗讀，`電話分機是1234` 成為「一二三四」。
- 防火牆探測須收到 Windows 錯誤 10013 才繼續驗證。連線逾時或其他錯誤不算確認封鎖。

規則僅在 K01 數字實驗模式啟用。以官方模型重跑同一段固定原文，保留原文雜湊與合成副本供比對。正式語音包採用這套規則會牽涉前處理版本與原音快取身分，本票只完成可行性驗證。
