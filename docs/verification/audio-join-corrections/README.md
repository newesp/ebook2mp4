使用者已核准修正標頭／內容齊頭、首次閱讀位置及實際保存狀態。本批延續已核准接點mock；不重畫或改動製作流程。

## 原因與對照

| 布局／操作分組／空間分配 | 原生實作 | 驗收方式 |
| --- | --- | --- |
| 文件列表與接點標頭共用一帶 | 生產頁持有兩側軌道；停止隱藏文稿工具列覆寫；標頭填滿控制項高度，保留8Tk內容間距 | 外層延遲布局後，比較兩側標頭外框、標題中心與兩側內容外框 |
| 前批結尾／後批開頭 | 新接點在原生布局完成後定位末端／開頭；接點與來源簽章保護延遲回呼 | 首次開啟 → 切換 → 返回 → 詳情切換；核對實際yview |
| 保存狀態固定在操作列中 | 以既有設定契約比對來源版本、順序、停頓與接點確認；失敗保留輸入，提供重試 | 已存 → 修改 → 改回 → 寫入失敗 → 重試 → 重載 |

功能契約維持原MP3／SRT來源驗證、停頓範圍、確認與保存方式。保存狀態放於底部返回與提交之間的彈性欄，避免把整段狀態加到警告列造成窄版溢出。

Skill已有相鄰邊緣對齊及協調標頭帶規則。AGENTS.md不增加重複條文。專案元件規範新增兩條基準線的量測對象；根清單直接引用。
