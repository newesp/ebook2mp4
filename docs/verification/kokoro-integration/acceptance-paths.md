# Kokoro 整合驗收路徑

以下使用 ASD-STE100 風格：短句、單一動作、明確結果。這是操作清單，不代表已通過人工聽感驗收。

1. 啟動主程式 → 檢查主視窗 → 確認視窗最大化。
2. 開啟書籍 → 選取批次 → 進入「語音設定」。
3. 選取「Kokoro 本機 CPU」→ 按下管理語音包 → 確認管理頁出現在同一主視窗。
4. 按下「選擇離線語音包…」→ 選取交付 ZIP → 按下「檢查並匯入」→ 等待「語音包已就緒」。
5. 按下「版本、音色與授權詳情」→ 檢查版本 → 確認顯示 100 個中文音色，且人工品質驗證尚無。
6. 按下「返回語音設定」→ 開啟音色清單 → 選取音色 → 確認原有稿件與輸入保留。
7. 按下「只儲存設定」→ 重開專案 → 檢查服務、音色與語速 → 確認值相同。
8. 封鎖語音包 Python 的對外網路 → 執行首次試聽 → 確認產生可播放音檔。
9. 在試聽文字區按滑鼠右鍵 → 選取固定範例 → 執行試聽 → 檢查中英文字。
10. 在主稿選取文字 → 返回語音設定 → 在試聽文字區按滑鼠右鍵 → 帶入選取文字 → 執行試聽。
11. 選取另一音色 → 執行試聽 → 比較音檔 → 確認音色改變。
12. 執行試聽 → 按下取消 → 確認顯示取消 → 播放上一份音檔 → 確認舊成品可用。
13. 開始首次載入 → 按下取消 → 檢查工作管理員 → 確認該次工作程序結束。
14. 完成試聽 → 等待 120 秒 → 檢查工作管理員 → 確認模型程序卸載。
15. 確認朗讀稿 → 按下「儲存並前往製作」→ 開始製作 → 確認本機工作不要求雲端傳送同意。
16. 等待製作完成 → 播放 MP3 → 開啟 SRT → 比對繁體原稿 → 確認字幕保留原文。
17. 開始長稿製作 → 完成至少一塊 → 取消 → 重開專案 → 續作 → 確認有效區塊重用。
18. 修改音色或語速 → 檢查舊執行紀錄 → 確認不能當成目前版本直接續作。
19. 完成兩個批次 → 選取批次 → 調整順序 → 合併總 MP3／SRT → 檢查交接停頓及字幕起點。
20. 開啟總影片製作 → 選取圖片 → 製作 MP4 → 更換圖片 → 再次製作 → 確認沒有新增 TTS 工作。
21. 返回語音包管理 → 按下「移除語音包…」→ 按下「確認移除」→ 確認書稿與完成成品保留。
22. 語音包缺少時執行新的本機試聽 → 檢查錯誤 → 確認提供重新匯入方法，且沒有改用雲端。
23. 匯入損毀 ZIP → 檢查結果 → 確認原有效安裝保留。
24. 開啟舊雲端專案 → 檢查設定與成品 → 確認既有操作仍可使用。
25. 還原主視窗 → 縮小主視窗 → 檢查必要按鈕與文字 → 確認沒有重疊或裁切。
26. 關閉主程式 → 檢查工作管理員及測試目錄 → 確認沒有本次測試程序與暫存占用。

人工聽感：依序播放女聲、男聲及長稿。每次只檢查一項：漏句、重複、裁尾、數字、英文、語速、自然度、口音。記錄音色、文字、時間點與結果。既知數字與「得」的前處理偏差見 [K01 品質表](../kokoro-k01/quality-review.md)。
