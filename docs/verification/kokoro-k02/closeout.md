# K02 共用語音服務能力與合成接點

2026-11-20。覆核 [GitHub #4](https://github.com/newesp/ebook2mp4/issues/4) 的既有實作，修正舊版合成計畫在重開時被判成損壞的問題。

現行規則加入引文分塊後，既有相容性測試仍將新版規則雜湊與舊值比較。舊 PCM 區塊本身可重用，但用新版規則驗證存檔會使原任務與設定來源無法讀取。用提交 `871b3a9a` 產生的舊版合成計畫實際重現這個錯誤。修正後，讀取與續作依計畫保存的版本驗證文字、規則、音色設定與區塊。新版工作仍用現行引文切分規則。

| 範圍 | 驗證方式 |
| --- | --- |
| 共用接點及能力 | 試聽與正式製作均沿用 ProjectWorkflow，再使用共用區塊合成。程式覆核確認能力資料保留本機／雲端、音色來源、文字上限及逾時設定。 |
| 設定、試聽、製作與舊成品保護 | 模擬 Edge、Gemini 與 Fish 回應。使用內附 FFmpeg 實際處理音訊。核對成功與失敗狀態、取消、重開續作及舊成品內容。 |
| 拒絕傳送 | 對三個雲端服務用無快取文字啟動正式製作，傳入不同意網路。工作報告失敗與同意提示，傳輸介面未被呼叫。 |
| 舊版任務 | 重開帶舊計畫及舊 PCM 的專案。讀取原任務與設定來源。離線續作並重用區塊，再重開確認 MP3／SRT 可讀。 |
