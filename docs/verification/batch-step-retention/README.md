# 切換批次保留目前步驟

## 需求與修正

切換「書籍與製作批次」時，保留目前主步驟及右側製作內頁。
批次內頁顯示新批次的內容；全書內頁維持同一頁面及操作狀態。

原因：`render_step()` 在批次不符時固定開啟語音頁，且僅將合併音訊視為全書頁；`refresh()` 也會將匯入步驟自動改為校對步驟。

修正：依既有頁面快取中的專案、批次範圍及頁面種類切換內容。選取批次時，保留主步驟。首次匯入後自動前往校對的流程維持原有行為。

## 驗證

- `red.txt`：修正前重現四種跳頁，包括製作與成品、總影片、批次影片及匯入來源。
- `green.txt`：`python -m unittest test_batch_step_retention -v`，3 項通過。涵蓋 3 個主步驟、5 個製作內頁、雙向切換及取消未存稿切換。
- `related-tests.txt`：主流程、製作內頁及啟動預設值共 7 項通過。
- `build.txt`：PyInstaller 正式建置成功。唯一輸出位置為 `dist/ebook2mp4`。
- `package.json`、`release-check.txt`：33 個封裝模組與來源一致。正式主視窗成功啟動及關閉。程序已釋放。
- 本次只修改步驟保留行為，未調整版面。

## 操作驗收

1. 選取 book1-ch2 → 按「製作與成品」→ 選取 book1-ch1 → 確認仍顯示「製作與成品」。
2. 按「語音設定與試聽」→ 切換批次 → 確認仍顯示語音頁及新批次內容。
3. 按「全書合併」→ 切換批次 → 確認仍顯示合併音訊頁。
4. 進入全書「製作影片」→ 切換批次 → 確認仍顯示全書影片頁。
5. 進入批次「製作影片」→ 切換批次 → 確認顯示新批次的影片頁。
6. 分別進入「匯入來源」、「校對文字」、「確認朗讀稿」→ 切換批次 → 確認主步驟不變。
7. 修改校對稿 → 選取另一批次 → 按「取消」→ 確認保留原批次及未存文字。
