# 單一文稿工作區：交付與驗收

日期：2026-11-07。依 spec v1.3「2026-11-07 核定增補」、核准提案及第三版設計實作。

正式成品：`dist/ebook2mp4/ebook2mp4.exe`。搬移時保留整個 `ebook2mp4` 資料夾。

## 實作結果

- 主導覽為「1 文稿 → 2 試聽與製作」。TXT 匯入、PDF 擷取、全文編輯及朗讀稿保存使用主視窗。
- 左側 PDF 原頁／TXT 原文可收合。寬視窗維持左右配置。窄視窗切換原稿與文稿。原頁頁碼、欄寬及編輯位置不因 AI 結果更新而重設。
- 搜尋與取代在編輯器上方展開。版本、文稿設定、連線設定及來源處理在右下工具面板切換。底部主要操作固定可見。
- 按「AI 全文校對（Gemini）」才送出目前文件。保留背景切批、進度日誌、取消及未完成範圍續作。候選直接顯示於同一全文編輯器。沒有傳送勾選框、傳送說明、例行確認彈窗或逐段採用要求。
- 「儲存為朗讀稿」以一次索引提交保存畫面全文與一致快照。相同內容及修訂版不重複建版。失敗保留編輯內容，不能前進。再次編輯會取消目前朗讀確認，歷史快照與音訊關聯仍保留。
- 編輯草稿與候選另存為工作區暫存。重開可恢復。版本還原先備份現稿。重新擷取先備份，再預覽差異；PDF 結果套用為新批次，原批次的人工稿保留。
- 來源異常仍阻擋保存。部分 AI 結果須續作，或明確選「保留未完成處原文」。續作只送未完成範圍，保留人工修改。來源修訂檢查會拒絕過期候選。
- PDF 保留旋轉、目前頁、區域、失敗頁與連續局部修正入口。TXT 僅顯示編碼與重新載入。保留 TXT 匯出、復原及朗讀版本刪除。
- 模型可手動輸入並隨文稿設定保存。金鑰仍使用使用者層的 DPAPI 設定，不寫入專案。資料格式保留 `format_version=1`；新增可選工作區欄位，原始來源、歷史候選及舊快照不改寫。

實作模組：`manuscript.py` 管理暫存與原子提交；`manuscript_desktop.py` 管理主工作區及工作生命週期；`manuscript_source.py` 管理來源工具；`manuscript_drop.py` 接收 Windows 檔案拖入。主程式不再匯入舊 PDF／Gemini 工作視窗。舊視窗測試明確使用歷史相容測試入口。

原生回歸中的舊測試原以 Ctrl+S 當成提交來源修訂。新版 Ctrl+S 是工作區暫存。測試改用 `save_draft` 模擬來源修訂，再驗證舊候選阻擋；沒有改回新版保存行為。各日誌依測試名稱去重，以最後一次結果彙整。

執行方式：`python tests/run_suite.py <測試模組>`。依賴在專案內隔離安裝。語音回歸使用受控服務回應及真實 FFmpeg。Windows asyncio 的本機 socket pair 在沙箱內停滯，這組測試改在允許本機連線的環境完成。

[完整型別檢查](typecheck.txt)：48 個來源檔；本次文稿模組沒有錯誤。全專案仍有未修改的 `voice_media.py` 與 `tts_control.py` 共 6 個型別錯誤，因此不宣稱全專案型別檢查通過。

## 原生操作驗收

下列操作使用實際 Tk 視窗、合成 PDF／文字及受控 AI 回應。未使用私人書稿。驗收程式為 `tests/unified_visual_fixture.py`。

1. 匯入 PDF／TXT → 檢查全文 → 確認沒有新增工作視窗。
2. 展開原稿 → 按 AI 全文校對 → 檢查候選 → 確認原頁與編輯器位置保留。
3. 點候選正文 → 輸入人工修改 → 按儲存為朗讀稿 → 確認顯示「已儲存，可朗讀」。
4. 讀取專案 → 比對畫面全文、文稿與朗讀快照 → 確認三者相同。[比對結果](native-equality.json)。
5. 按版本記錄 → 檢查唯讀差異 → 確認編輯器未被覆蓋。
6. 按來源處理 → 檢查頁面、OCR 與範圍欄位 → 確認主要操作固定可見。
7. 還原為 1100×760 → 檢查左右內容 → 確認沒有裁切或重疊。
8. 縮小為 900×640 → 按返回文稿 → 檢查全文與底部操作 → 確認沒有水平捲動。

截圖：[最大化設定](maximized-settings.jpg)、[AI 候選](ai-candidate.jpg)、[保存成功](saved-reading.jpg)、[版本](versions.jpg)、[來源工具](source-tools.jpg)、[還原視窗](restored.jpg)、[窄視窗](narrow-editor.jpg)。

版面驗收找出的原因為初始幾何配置尚未穩定時就計算分隔位置，以及窄寬切換時沿用過大的原稿欄寬。修正為內容容器尺寸改變後重新配置，限制原稿欄寬，並保留編輯器最低高度。沒有以刪除必要按鈕處理空間不足。
