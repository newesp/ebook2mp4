# T09 — Edge-TTS 音色、語速與短文試聽

2026-10-27。票稿 `.scratch/pdf-txt-audiobook-video/v1.1/issues/09-edge-voice-preview.md`；對應 Spec 使用者故事 50～54、需求 §11。主要測試邊界沿用已核定 ProjectWorkflow 與真實 Tk。正式批次 MP3／SRT 屬 T10；自訂節奏屬後續票，不宣稱本次完成。

## 使用方式

開啟書籍專案，選批次，按主窗「語音試聽」。首次按「更新線上音色」取得清單；顯示服務提供的名稱、語系與性別，可篩台灣華語、中國普通話及英文。沒有自動明選第一個音色；從清單選擇後，以「本批次」或「全書預設」儲存。全書預設只給新批次，既有批次不被改動；要套用舊批，明確選本批次儲存。

語速 -20%、-10%、正常、+10%、+20%，初始正常。固定範例或校對稿反白可試聽，介面顯示完整送出文字與字元數，明示 Microsoft Edge 線上服務，須勾選同意後才送出。單次只用明選音色，中英混合不切聲。最多 3,000 字元，不截斷長選取；未存校對文字可試聽，不會被自動存成校對稿或確認朗讀稿。

試聽先固定文字與設定，背景請求與本機音訊處理不鎖住編輯器。語音／網路／工具錯誤僅顯示於試聽窗，不阻擋校對。取消冪等，關閉等待連線與子程序清理；失敗或取消保留上次成功結果。音訊先解碼、組裝及再次完整解碼成功，才可原子保存。播放使用 Windows MCI，停止、播完與關窗關閉 decoder／檔案，沒有留外部播放器。

## 公開流程與持久化

- `voice_catalog()`／`start_voice_refresh()`：本機快取加 UTC 更新時間；明確更新才連網。快取預設 `%LOCALAPPDATA%/ebook2mp4/voice/voices.json`，更新失敗保留舊清單；損壞時可按更新恢復。不是寫死人聲名單。
- `voice_settings(batch_id=None)`／`save_voice_settings(voice, rate, batch_id=...)`：預設與批次獨立保存。舊專案缺欄位時為未選音色及正常語速，不追溯套用後來變更的全書預設。TXT 與 PDF 新批次在共同原子提交邊界繼承當時預設。
- `start_voice_preview(batch_id, start=..., end=..., text=...)`：預設固定範例；範圍為 Python 字元半開區間。提供 text 可試聽未存校對稿的所選範圍。工作提供 `state/cancel/wait`，`finish_voice_preview(job)` 保存成功結果，`discard_voice_preview(job)` 釋放已停止的失敗／取消／未存結果。
- `voice_preview(batch_id)`／`voice_preview_path(batch_id)`：取得上次成功的文字、來源、範圍、校對版本、實際設定、時間及音訊 SHA-256。內容為專案相對路徑；讀取時驗證音訊雜湊。請求中改稿／設定不混入快照。跨視窗索引衝突阻擋保存，可關閉捨棄，舊成功結果不變。
- 處理設定：`provider=edge-tts`、`processing=identity-v1`、固定音色／語速、句尾額外 0 ms／段落額外 500 ms。空白行分隔段落，其內文字與標點原樣送服務；段落之間本機補靜音，末段不補。預覽與未來正式輸出可共用 `voice_media.synthesize` 及同一設定快照；不依賴任意 SSML。T10 仍需做長稿切分、進度、正式字幕與輸出。
- 視窗固定所屬書籍／批次並明示；主窗切換後禁止從舊視窗儲存或新試聽，須關閉後在目前批次重開。
