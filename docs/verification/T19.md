# T19 批次影片合併驗收

核准 UI：`docs/mock-ui/t19-batch-merge-v1/index.html` v2。正式程式固定 `dist/ebook2mp4/ebook2mp4.exe`。

## 行為

全書合併右側可切換「總音訊製片」與「合併既有批次影片」。選取、順序、額外交接停頓及頁碼確認共用；未存草稿跨路徑保留，影片方式保存重開。新路徑只要求有效批次 MP4／SRT，不要求總 MP3、原 MP3 或全片共用素材；音色／語速差異提示但保留原聲。

批次來源版本、朗讀確認、語音與視覺設定須相符。驗證雜湊及完整影音解碼後，以影片實際時間軸合併。保持比例補黑邊，統一 720p／1080p、30 fps、H.264／yuv420p、AAC-LC／48 kHz／立體聲及 faststart。每個相鄰接點補額外靜音，維持前批最後一格，字幕清空；末批不補。原檔不改寫，不呼叫 TTS。

接點頁提供前批最後畫面、後批第一畫面、文字、頁碼警告及 3／5／10 秒影音預覽。預覽與正式合併使用相同處理核心，可返回前／後批校對。接點確認沿用來源、頁範圍及朗讀／音訊版本綁定。預覽結束、取消與離頁會停止程序並釋放暫存。

任務保存固定快照及進度；每個媒體命令最多 3 次嘗試。取消／失敗保留舊總影片、批次成品及成功總音訊。發布前再次檢查索引、來源版本及檔案簽章；索引保存失敗可明確重試同一結果。成品可內建播放、另存 MP4／SRT 或開啟資料夾。

## 公開流程

- `save_total_video_method('total-audio'/'batch-videos')` 保存入口方式。
- `inspect_video_merge()`、`save_video_merge_settings(batch_ids, pause_ms=500, resolution='1080p', accepted_joins=...)`、`start_video_merge()`。
- 完成／捨棄、歷史、播放路徑與另存沿用 `finish_total_video`／`discard_total_video`、`total_video`／`total_video_runs`／`total_video_path`／`export_total_video`。
- `inspect_video_merge_joins`、`start_video_join_preview`／`finish_video_join_preview`；釋放沿用 `discard_assembly_join_preview`。

批次影片仍保存於各批次，總影片保存於全書。兩種總影片方式共用目前總影片欄位，快照以 method 區分，保留各次任務及舊檔案。

## 操作驗收

1. 開啟有批次 MP4／SRT 的專案 → 按「全書合併」。
2. 在右側選「合併既有批次影片」→ 檢查來源狀態。
3. 勾選批次 → 按「上移」或「下移」→ 確認順序。
4. 輸入 0～5 秒交接停頓 → 選解析度 → 檢查新增停頓摘要。
5. 按「檢查接點」→ 對照前後畫面與文字 → 確認每個頁碼警告。
6. 按「播放影音接點」→ 確認靜音維持前批最後一格，字幕清空。
7. 按「停止並返回」→ 返回全書合併 → 確認輸入保留。
8. 按「合併 MP4／SRT」→ 等待完成 → 確認成品摘要。
9. 開啟「成品操作」→ 播放或另存 → 確認影片與同版字幕可取用。
10. 改解析度 → 檢查摘要 → 確認顯示待更新。
11. 切到總音訊製片，再切回影片合併 → 確認共用順序與停頓保留。
12. 開始更新 → 按「取消任務」→ 確認舊成品保留，進度顯示已取消。
