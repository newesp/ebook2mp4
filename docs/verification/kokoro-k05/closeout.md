# K05 Kokoro 試聽覆核

2026-11-20。對照 [GitHub #7](https://github.com/newesp/ebook2mp4/issues/7)，修正試聽狀態與取消後關頁的兩個可重現問題。

- 播放中按下「停止」會顯示已停止並保留成功試聽；自然播畢有獨立提示。
- 取消試聽後關閉內頁，清除目前頁面及外框登記，延遲回呼不再嘗試更新已銷毀的試聽頁。

## 正式 EXE

以標準建置入口更新固定目錄。53 個封裝應用模組逐一比對來源一致，內附 FFmpeg 及 FFprobe 可執行。[封裝](build.txt) · [來源及成品雜湊](package.json)

1. 在隔離的測試專案開啟「語音設定與試聽」。確認 Kokoro 與已存音色 `zf_001` 可見。使用既有真實 Kokoro 試聽音訊作為重播資料，這次沒有啟動模型推論。
2. 按「重播」→ 顯示正在播放。按「停止」→ 顯示已停止，上次成功試聽仍可重播。[播放](exe-playing.jpg) · [停止](exe-stopped.jpg)
3. 選語速 −10% → 儲存本批次設定 → 重新讀取隔離專案，確認音色及語速保留，原試聽檔雜湊一致。[儲存畫面](exe-settings-saved.jpg) · [讀回](exe-persistence.json)
4. 還原視窗至 1702×1065 → 確認試聽與停止操作仍可達。[還原](exe-restored.jpg)
5. 還原視窗重新播放後，Computer Use 工具連線中止，未取得正式版自然播畢畫面。原生播畢回歸已通過。測試 EXE 收到正常關閉請求後已退出，測試及建置暫存已清理。[最終占用檢查](final-preflight.txt)
