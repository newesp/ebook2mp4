本機測試使用真實 Windows 子程序及內附 FFmpeg，worker 產生測試 PCM，不能當成真實 Kokoro 發音或 CPU 品質驗收。真實推論、中斷與 18 塊長稿續作見 [既有整合證據](../kokoro-integration/README.md)，目前正式語音包離線流程見 [K09](../kokoro-k09/README.md)。

## 不處理項目

- 不追加另一版本真實模型、多小時全書推論、跨電腦缺包或新的模型品質驗收。沒有可重現的程式缺陷可據此修改；保留上述測試邊界。
- 乾淨 Windows 依使用者決定不測。K09 人工聽感已由使用者回報完成且沒有問題。
- 本輪沒有修改 UI，不宣告新一輪正式 EXE 畫面驗收完成。

正式程式以標準入口更新固定 `dist/ebook2mp4`。封裝、來源比對及最後資源檢查記錄於 [剩餘工單結案](../remaining-tickets/README.md)。下一步為 #1、#2、#12 規格總票的證據對照與結案。
