# 全書製片步驟按鈕尺寸一致

2026-11-05。使用者要求「① 合併音訊」「② 製作影片」與上方導覽按鈕大小一致，已明確核准此局部調整。

原因：未選中步驟使用預設 TButton 的 `(10, 7)` 內距，選中步驟及上方導覽使用緊湊樣式 `(10, 3)`，因此高度不同。

修正：合併音訊頁與製作影片頁的未選中步驟均指定既有 `Compact.TButton`。選中步驟保留 `CompactActive.TButton`。操作、文字及選中配色不變。

原生幾何檢查：以本次空白專案建立實際主視窗，分別開啟兩個頁面，在 1040×640 與 1360×800 下量測。8 個步驟控制項觀察值均為 **114×29**，與上方「全書合併」導覽按鈕寬高完全相同，未越出視窗邊界；無 Tk 回呼例外。數值為目前 Windows 縮放設定下的 Tk 座標。詳見 `geometry.json`。未另做其他 DPI 的目視驗收。

驗收路徑：開啟書籍 → 按「4 試聽與製作」→ 按「全書合併」→ 檢查「① 合併音訊」「② 製作影片」的寬高 → 切換至「② 製作影片」→ 確認按鈕大小一致，選中項目維持綠底。

正式成品固定更新至 `dist/ebook2mp4`。本次依賴、建置、空白測試專案與程序清理見 `cleanup.json`。使用者原本執行中的程式由使用者確認關閉後才更新；不讀取或修改使用者書籍。
