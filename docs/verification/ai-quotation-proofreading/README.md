# AI 引號校稿

Gemini 系統校稿規則新增引號檢查：混用直引號／彎引號、開閉方向、明確缺漏、多餘引號及巢狀層級。中文外層使用「」，內層使用『』。

跨段引文、選取邊界及請求切分可能造成局部不成對，指示 AI 不得強迫逐段配對。上下文不足時保留原樣並寫入 notes。英文所有格、縮寫、字串、網址、Email 與程式碼維持原樣。

修正仍走原有候選採用流程。已確認的朗讀稿須重新校稿、採用及確認，才會套用新的內容。程式的超長引文分段容錯維持有效。

驗證使用模擬服務，檢查請求確實攜帶完整系統規則及既有候選流程；未呼叫線上模型，因此不宣稱模型對每個歧義引號都能正確判斷。

操作：「1. 文稿」→ 選取校稿範圍 → 執行 AI 校稿 → 檢查引號修改 → 採用候選 → 存成朗讀稿。
