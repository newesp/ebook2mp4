## 本次驗證

本機正式製作測試採小型協定包與真實 Windows 子程序，使用內附 FFmpeg 處理 PCM、MP3 及字幕。協定 worker 只產生測試音訊，真實 Kokoro 推論結果沿用歷史證據。

| 工單範圍 | 結果 |
| --- | --- |
| 未確認稿阻擋 | 公開正式製作入口拒絕未確認的稿件。來源異常的確認規則沿用現有 ProjectWorkflow。 |
| 固定稿件及設定 | 製作期間修改校對稿與語速，完成的成品仍對應開工時的確認稿及設定，重開後可讀取。 |
| 本機分塊 | 本機每塊上限 240 escaped UTF-8 bytes，測試逐塊拼回原文，繁中與英文內容各出現一次。模型載入與合成逾時仍為 300／180 秒。 |
| 字幕及音訊 | UTF-8 字幕保留繁體，實際解碼 MP3 長度與記錄時長相符。第一塊為 0～200 ms，第二塊從 700 ms 開始，額外停頓沒有字幕。 |
| 進度、取消及失敗 | 共用回歸涵蓋取消、重試、發布與磁碟寫入失敗、歷史成品保護。本輪加入完成後暫存檔損毀及重試保存的案例。 |
| 同次製作及衝突 | 本機工作程序載入次數維持 1，製作期間拒絕並行試聽和移除語音包。 |

23 項回歸全部通過，包含本機子程序正式製作、共用保存、取消續作及停頓字幕。[回歸紀錄](regression.txt)

## 既有真實推論證據

- 約 1,109 字繁中長稿經本機 CPU 合成，輸出 260.75 秒，原文與每塊音素／起訖時間皆保留。[K01 長稿](../kokoro-k01/README.md)
- 整合流程完成 18 塊真實本機長稿，輸出約 230.075 秒，包含中斷、重開及重用有效區塊。[整合結果](../kokoro-integration/acceptance.json)
- K09 以目前交付語音包完成真實離線批次 MP3／SRT，合併時間軸、500 ms 停頓及字幕偏移均有實測。[K09 結果及音檔](../kokoro-k09/README.md)
