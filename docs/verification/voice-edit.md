# 可編輯試聽與視窗位置調整

## 行為

- 語音設定預設最大化（保留標題列）。一般主窗與彈出視窗首次顯示置中；最大化視窗不重排，提示泡泡與通知維持貼附位置。原生 Windows 檔案／訊息對話框由系統及既有 parent 管理。
- Edge 試聽與正式合成的同意欄預設勾選；按產生前可手動取消。正式合成送出前若發現稿件或設定變更，仍重讀並要求重新核對，不自動送出。
- 移除「固定範例／校對稿選取文字」。改為預填範例的可編輯文字框，可直接貼上或修改；字數即時更新，上限3000字元，空白及超長會阻擋，不截斷。編輯區與音色清單按父層grid伸展，底部操作列保留。
- 原「儲存本批設定並試聽」確實會啟動合成，但合成後須另按播放，容易被誤認只有儲存。現改為「產生並播放試聽」，合成成功後自動播放。使用畫面當下的文字、音色、語速與節奏，不必先儲存，試聽不會回寫校對稿或批次設定。「儲存設定」獨立保存目前所選範圍的設定。「播放上次結果」仍播放先前成功結果。
- 切換音色或編輯文字本身不會發送請求；按「產生並播放試聽」才送出。有可重用音訊時仍可重用。取消與關閉不自動播放；錯誤保留上次成功結果。

## 驗收路徑

1. 開啟新版 → 開啟專案 → 選擇批次 → 按「語音試聽」→ 檢查視窗最大化、同意欄已勾選。
2. 選擇音色 → 直接修改「試聽文字」→ 按「產生並播放試聽」→ 等待合成 → 確認自動讀出輸入內容 → 按「停止播放」。
3. 改用另一個音色 → 再按「產生並播放試聽」→ 比較聲音 → 確認滿意後按「儲存設定」。
4. 輸入空白或超過3000字元 → 按試聽 → 確認提示錯誤且沒有開始合成。
5. 開啟一般設定或其他非最大化視窗 → 檢查彈出時置中。確認通知仍貼附所屬視窗。
6. 關閉試聽 → 檢查原校對稿未變 → 重新開啟設定 → 確認僅明確儲存的值保留。
