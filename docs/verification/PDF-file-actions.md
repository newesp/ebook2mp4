# PDF 文件新增與移除操作

2026-10-26，基線 `75d37ea`。依使用者要求將「新增 PDF 範圍」改為「新增 PDF 文件」，並在同一工具區新增「移除 PDF 文件」。

移除作用於清單選取的一個 PDF 製作批次。確認提示列出名稱、來源檔名、頁碼與未存編輯影響，預設「否」。確認後原子發布移除批次參照的專案索引；不可變歷史檔案沿用現有保留規則，外部 PDF、其他批次及匯出檔案保留。取消／寫入失敗保留選取與未存編輯；成功後選取相鄰批次，最後一批移除則清空編輯區並停用移除。TXT 批次與空專案均停用移除操作。

## 驗證

新增三個公開行為測試：ProjectWorkflow 驗證同來源的兩個 PDF 批次只移除所選項、另一批朗讀確認及 TXT 保留、原檔不變、舊視窗更新被阻擋；故障注入驗證發布失敗保留前次成功專案；真實 Tk 驗證取消、保存失敗、未存編輯保留、成功切換及最後一批空狀態。目標測試 3／3 通過。

完整套件 53 個案例：**48 通過、5 跳過，42.845 秒**，無失敗。跳過的是需另設模型／實際來源環境的五個 OCR 整合案例，這次未變更 OCR 引擎；此前 T05 的三語與使用者書稿真實結果保留於 T05.md。詳見 [測試原始結果](PDF-file-actions-tests.txt)。mypy 檢查 7 個來源檔案通過，語法編譯通過，見 [型別檢查](PDF-file-actions-typecheck.txt)。新版 Windows onedir 重建見 [建置紀錄](PDF-file-actions-build.txt)。
