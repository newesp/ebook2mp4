# 採用本段後繼續編輯與儲存回饋

2026-10-27

原因：候選可編輯條件排除了 accepted 段落，採用後主動停用 Text；成功回饋只有「已保存決定」，未明說本段已儲存並採用。

修正：移除採用後鎖定條件，在既有 footer 狀態列顯示「已儲存並採用本段。可繼續編輯候選，再次採用才更新校對稿。」保留現有可伸縮配置，沒有增加新控制項。

採用後再次修改並保存候選，該段回到待確認；applied_candidate 保存上次採用的內容，校對稿維持上次成功採用文字。採用其他段落時亦維持該內容，直到再次採用更新候選。拒絕移除該段採用，撤回移除全部採用快照並恢復送出前全文。既有無快照的校對記錄仍能讀取與編輯。

驗證：原生 Tk 測試涵蓋採用→繼續編輯→保存→關閉重開→採用另一段→再次採用本段→重開→撤回，以及成功訊息在事件迴圈更新後仍可見。相關 27 項測試分模組執行，另執行 mypy 檢查。

使用 Windows Computer Use 目視檢查 740×570 邏輯視窗（125% DPI）：採用後候選保持可編輯、已採用計數與儲存成功訊息可見，按鈕及文字無重疊或裁切。未測所有系統 DPI，未送出真實 Gemini 請求。
