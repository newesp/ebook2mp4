# T13：全書語音預設與局部改稿增量合成

使用者在看過功能示意後更新指示：依目前版面延伸，不重新設計，直接實作。實際沿用服務列、左右聲音／試聽區、底部範圍與操作列。全書預設模式以「套用到既有批次…」取代原本不適用的製作按鈕，不增加語音頁高度。

## 行為

- 新批次複製當時全書預設。舊批次獨立保存；修改預設不自動更新舊批。
- 全書預設先儲存，再進入同視窗套用頁。批次預設均未勾選；可逐列按滑鼠或空白鍵選取。返回保留有效選取；重開刷新摘要、目前設定及影響。沒有選取時停用套用。
- 套用以一次原子專案保存更新明確選取的批次，不合成、不傳送文字。同專案正式任務執行時停用套用；後端另用製作鎖保護跨視窗競爭。選入批次有未存語音表單時阻止套用，避免返回後覆寫新設定。
- 修改校對稿沿用既有取消確認規則；只影響該批。舊 MP3／SRT 保留可播，製作頁標「待更新 · 上一版」，並顯示來源時間、音色、語速。
- 重新確認後，製作頁背景檢查目前計畫與原音，顯示可重用／需合成區塊。檢查未完成時停用開始。相同快照的中斷續作維持 T12；新版本另建任務，但重用符合內容及相關設定的原音。
- 快取依實際文字、服務、模型、設定檔、音色、語速、文字處理與 PCM 解碼規則辨識。稿件整體版本、區塊編號與位置不控制原音重用。停頓不改原音；切分改變才更新必要原音。
- 全重用時明示本機組裝並強制禁止網路，即使同意仍為預設勾選。缺目錄／憑證不阻擋本機組裝。檢查後缺塊則失敗，不能暗中回退送字。需要合成時取消同意會阻擋。

公開流程新增 `apply_voice_defaults(batch_ids)`、`inspect_narration(batch_id)`，`start_narration` 新增 `allow_network`。未改專案格式或刪除歷史成品。

## 操作驗收

以下為 ASD-STE100 風格中文程序：短句、單一動作、可觀察結果；不宣稱符合英文受控詞彙標準。使用合成文字測試書籍，不在使用者原書進行破壞測試。

| ID | 操作路徑 | 檢查結果 |
| --- | --- | --- |
| 1 | 選批次 → 按「試聽與製作」→ 底部選「全書預設」→ 修改設定 → 按「儲存全書預設」→ 新增批次 | 新批採新預設。舊批設定不變。重開結果相同。 |
| 2 | 底部選「本批次」→ 修改設定 → 按「只儲存設定」→ 重開專案 | 該批保留個別設定。全書預設與其他批不變。 |
| 3 | 選「全書預設」→ 按「套用到既有批次…」→ 勾 A、C → 檢查影響 → 按「套用至 2 個批次」 | 只更新 A、C。B 不變。未開始 TTS。舊成品保留。 |
| 4 | 勾 A → 按返回 → 重開套用頁 → 點表頭及空白區 | A 保持勾選。表頭及空白區不切換勾選。預設／批次設定變更後摘要與影響更新。 |
| 5 | 開始正式製作 → 返回語音設定 → 檢查套用入口 → 取消任務 → 等待停止 | 忙碌時停用套用。停止後恢復。鎖已釋放。 |
| 6 | 修改 A 一段 → 儲存 → 檢查確認狀態 → 開製作頁 → 播放舊成品 | A 需重新確認。舊成品標待更新且可播。B 不變。 |
| 7 | 重新確認 A → 前往製作 → 檢查重用摘要 → 按「更新 MP3／SRT →」→ 檢查外部請求及 SRT | 只請求失效原音。插入段落不使後面相同原音失效。最終內容完整、順序正確。 |
| 8 | 只改段落停頓 → 儲存並前往製作 → 按「重新組裝 MP3／SRT →」 | 新增 TTS 請求為 0。音訊與字幕按實測重組。末段不補停頓。 |
| 9 | 保留全重用計畫 → 保持同意勾選 → 移除測試音色目錄 → 開始重組 | 本機可完成。若檢查後刪原音，明確失敗且不送字。舊成品完整。 |
| 10 | 修改音色或語速 → 更新 → 檢查請求及成品 | 不混用其他音色／語速原音。 |
| 11 | 更新中按取消 → 等待已取消 → 播放舊成品 → 重開續作 | 舊 MP3／SRT 雜湊不變。有效原音保留。失效原音才重請。 |
| 12 | 啟動 → 還原到 1040×640 → 操作新入口 → 最大化 → 關閉 | 啟動最大化。沒有裁切、文字重疊、外層或水平捲動。正常退出後沒有本次殘留程序或占用。 |
