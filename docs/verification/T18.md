## 已實作

「製作與成品」新增「加入素材，製作 MP4」。批次與全書均使用 `TotalVideoPage` 與同一份素材、預覽、編碼、完整驗證、取消、重試、發布與成品操作。頁面依入口顯示本批／全書來源並返回原頁。批次頁依書籍、批次分開快取，返回保留未存設定；背景任務返回原批次。

`ProjectWorkflow.batch_video_target(batch_id)` 是批次公開入口，回傳目標對象；對象提供既有 `total_video_settings`／`save_total_video_settings`、`inspect_total_video`、`start_total_video`／`finish_total_video`／`discard_total_video`、`total_video`／`total_video_runs`／`total_video_path`／`export_total_video` 操作。這些方法共用既有工作流程，並將影片設定、任務、成品投影至所屬批次的 `video` 記錄；不覆寫全書同名欄位。素材使用專案內內容雜湊副本，設定與成品歸屬各自獨立。

批次來源檢查沿用有效朗讀版本、語音設定、完整區塊及 MP3／SRT 雜湊檢查。任務快照帶批次 ID，背景工作重開專案後檢查該批來源；拒絕由其他批次或全書對象發布／捨棄。共用專案產出鎖。舊專案無批次 `video` 欄位仍可開啟，舊總影片保存格式與公開入口保留。

圖片、透明黑底、比例補黑邊、720p／1080p、30 fps、短背景循環／定格、長背景裁切、背景靜音、編碼與字幕行為沿用 T16／T17 核心。批次只使用自己的完整音訊，不加全書交接停頓、不新增 TTS。

## 操作驗收

1. 開啟有有效批次 MP3／SRT 的 TXT 專案 → 選該批次 → 按「4 試聽與製作」。
2. 按「製作與成品」→ 按「加入素材，製作 MP4」→ 確認來源為本批音訊。
3. 選圖片或背景 MP4 → 檢查預覽 → 選解析度。
4. 按「製作本批 MP4」→ 等待完成 → 確認成品列顯示本批影片。
5. 按「成品操作」→ 選播放、另存或開啟資料夾 → 確認取用本批成品。
6. 改解析度 → 檢查成品列 → 確認上一版待更新。
7. 返回製作與成品 → 重新進入影片 → 確認當次設定保留。
8. 切換另一批次 → 開啟影片頁 → 確認沒有沿用前批設定。
9. 按「全書合併」→ 開啟製作影片 → 確認顯示全書來源，且批次設定不變。
10. 修改原批朗讀稿 → 返回批次影片 → 確認製片停用，上一版可取用。
