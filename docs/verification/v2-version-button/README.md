# 版本紀錄直接入口

依使用者要求：文稿工具列的「版本」選單改為「版本紀錄」直接按鈕，移除「開啟歷史 AI 候選」選項。歷史AI候選仍由版本紀錄的版本選擇提供，原候選資料及還原契約保留。

本輪只調整入口，使用Workspace.TButton與原工具列換列規則。沿用版本紀錄頁面布局，不新增頁內功能。功能與原生證據見native.json／native.png，相關回歸見tests.txt。正式建置、封裝比對、隔離啟動結果分別見build.txt、package.json、exe-startup.json。

檢查範圍：直接按鈕可開啟同一共用內頁、沒有下拉箭頭或重複選項、900與1360工具列可達性及高度一致。頁內捲動與還原操作本輪未修改，完整逐頁EXE人工及其他DPI不列為本輪通過。
