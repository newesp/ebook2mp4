## 行為

「檢視保存版本與副本」新增「刪除所選朗讀稿」及關閉按鈕。刪除前顯示所選版本／時間及不可復原提示，預設否；若仍是目前確認版本，提示刪除後須重新確認。重載保留的未存稿副本不提供此按鈕。

`ProjectWorkflow.delete_reading(batch_id, snapshot_id)` 原子移除版本參照，刪目前版本時清除 current_reading，其他版本／批次、原始來源及校對稿均保留；不修改校對版本號。索引提交失敗不刪內容，跨視窗版本檢查及寫入鎖沿用既有規則。提交成功後才刪除不再被參照的朗讀快照檔；如檔案被占用／無權限，版本仍已移除，回傳明確警告及相對檔名供解鎖後手動清理，不把物理刪檔失敗誤報成成功。共用的內容檔保留。

UI 成功後更新版本選單與朗讀狀態，最後一筆刪完顯示空狀態並停用刪除；取消及失敗保持原清單。只更新狀態，不 refresh 編輯器，保留未儲存人工文字。原 PDF 批次從主視窗移除時，仍開著的版本窗會提示關閉，不再執行刪除。
