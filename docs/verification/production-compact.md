# 製作與成品：精簡固定版面

2026-10-30。依使用者核准圖，移除多餘標頭、重新分配底部空間，並禁止外層包內層的雙層捲動。

## 行為

製作頁由 ScrollPage 改為固定 ttk.Frame grid：一列標頭 → 朗讀稿預覽 → 任務選擇／摘要 → 可擴展區塊清單 → 固定橫向操作 → 成品操作。頁面沒有外層 Canvas 或整頁捲軸；文字及清單是彼此並列的獨立捲動區，不是巢狀捲動。語音設定頁保持原樣。

書名／批次重複資訊不再占用製作頁標頭。任務識別、音色、語速及停頓收進「任務與設定詳情」，展開時取代預覽，不向下增加頁高。歷史任務選單用「第 N 次」分辨任務，不再常駐顯示技術識別。

狀態與主要按鈕橫向分布；返回、傳送同意及重新開始在下一列。進度與取消僅在工作執行時顯示。已過期任務（包含已發布成品）可按「核對稿件與設定」重載目前版本，但不直接合成，且清除傳送同意。失敗列提供「查看原因」，選取後在既有狀態區顯示原因；過期時保留核對提示。原任務快照、取消續作、舊成品及發布規則不變。

## 驗收路徑

1. 開啟專案 → 按「試聽與製作」→ 按「製作與成品」→ 檢查沒有整頁捲軸。
2. 在朗讀稿區捲動 → 檢查操作列位置不變。再在區塊清單捲動 → 檢查朗讀稿位置不變。
3. 按「任務與設定詳情」→ 檢查預覽區改為詳情 → 再按返回朗讀稿 → 檢查清單及操作列未被推離視窗。
4. 選取失敗任務 → 選失敗區塊 → 檢查狀態區顯示該區塊原因。
5. 修改設定後選取舊成功任務 → 按「核對稿件與設定」→ 檢查重載目前版本、同意取消勾選，且沒有開始合成。
6. 開始製作 → 檢查出現取消與進度 → 取消並等待停止 → 檢查閒置時隱藏這兩項，舊成品仍可操作。
