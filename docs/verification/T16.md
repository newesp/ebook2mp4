## 已驗證

- 公開 ProjectWorkflow：圖片副本、解析度及重開、音訊失效與損壞、影片待更新、取消、排他鎖、失敗、另存、重試、磁碟不足及跨視窗發布衝突。舊影片與總音訊保留。
- 真實 FFmpeg：720p 直式 JPEG、1080p 透明 PNG、1080p 橫式 PNG，皆由兩批各 1,200 ms 的合成音調加 500 ms 交接停頓製片。三個總 MP4 均為 2,900 ms，沒有再加 500 ms；SRT 位元組與總字幕一致，新增 TTS 為 0。
- FFprobe 與完整解碼：H.264、yuv420p、30 fps、AAC-LC、48 kHz、雙聲道、faststart；總 MP3 與影片時長差 ≤200 ms。取出成品首格檢查黑邊與透明區，透明紅色的黑底合成值約為 128，透明空區為黑。

## 驗收操作

下列為 ASD-STE100 風格中文短句，不宣稱符合英文受控詞彙標準。使用測試書籍，保留目前正式成品。

| ID | 操作路徑 | 確認結果 |
| --- | --- | --- |
| 1 | 按「試聽與製作」→ 按「全書合併」→ 勾選批次 → 點選一列 → 按「上移」或「下移」 | 合併順序改變。左側批次順序不變。 |
| 2 | 按「合併設定」→ 開「交接停頓與儲存」→ 輸入 0.5 秒 → 儲存 | 設定保留。末批不補停頓。 |
| 3 | 按「檢查接點」→ 檢查前後文字 → 播放試聽 → 逐個確認頁碼警告 → 返回 | 未確認警告時不能合併。確認後解除阻擋。 |
| 4 | 按「合併 MP3／SRT」→ 等待完成 → 開「成品操作」 | 可播放及另存總音訊。右側出現「加入圖片，製作 MP4」。 |
| 5 | 按「加入圖片，製作 MP4」→ 選直式 JPEG → 檢查預覽 | 同主視窗進入第二步。圖片完整。黑邊補齊。 |
| 6 | 改選透明 PNG → 檢查畫面 → 選 720p → 返回音訊 → 再進影片 | 透明區為黑底。圖片與 720p 保留。 |
| 7 | 開「成品操作」→ 按「儲存視覺設定」→ 關閉專案 → 移動原圖 → 離線重開 | 圖片副本與解析度保留。總音訊有效時可直接製片。 |
| 8 | 按「製作總 MP4」→ 等待完成 → 開「成品操作」→ 播放總影片 | 顯示成品畫面。播放成品音軌。播放結束有狀態回饋。 |
| 9 | 播放影片 → 按「停止播放」或返回音訊 | 播放停止。預覽暫存釋放。沒有延後自動播放。 |
| 10 | 更換圖片或解析度 → 儲存視覺設定 → 檢查摘要與播放選單 | 影片仍標待更新。播放標示上一版。總 MP3／SRT 不變。 |
| 11 | 修改已選來源稿件 → 開影片頁 → 嘗試製片 → 按「更新總音訊」 | 來源失效提示可見。不能使用舊音訊製作目前版本。 |
| 12 | 開始製片 → 檢查選圖與解析度 → 按「取消任務」→ 等待取消 | 衝突操作停用。舊影片與總音訊保留。程序釋放。 |
| 13 | 模擬磁碟不足或工具失敗 → 檢查原因 → 排除問題 → 按「重試製片」 | 失敗原因可見。重試成功後才替換成品。 |
| 14 | 模擬發布寫入失敗 → 等待「重試保存」→ 恢復寫入 → 按「重試保存」 | 不持續自動重試。可保存已完成的本次結果。 |
| 15 | 開「成品操作」→ 另存 MP4／SRT → 開啟資料夾 → 完整解碼成品 | 兩檔可讀。資料夾正確。時長與字幕符合規格。 |
| 16 | 啟動程式 → 還原至 1040×640 → 切換兩步驟與選單 → 調至 1360×800 | 啟動最大化。主要操作可見。沒有水平捲動或按鈕裁切。 |
| 17 | 關閉程式 → 檢查程序、任務鎖及成品檔案 | 沒有本次殘留程序或播放暫存。成品可獨占開啟並釋放。 |

## 範圍及限制

圖片目前上限為 25 MB、四千萬像素。支援可解碼 JPEG／PNG；不支援的格式或損壞圖片不會取代原設定。

測試語音為服務替身提供的合成音調，真實工具是 FFmpeg／FFprobe。本輪未呼叫線上 TTS，未做真人書稿長時間聽感或其他 DPI 驗收。既有未提交的 TTS 控制／冷卻／重試變更保留，封裝包含目前工作區版本，未把它們提交為 T16。

此版本僅製作單張圖片影片，內建播放是從已驗證 MP4 取出實際固定畫面及音軌，透過既有 Windows 音訊播放。SRT 保持獨立，未燒錄字幕。背景影片與合併批次 MP4 不屬 T16。

編碼參數依 [FFmpeg 官方文件](https://ffmpeg.org/ffmpeg-all.html)。原生播放曾驗證 Windows MCI 的 MP4 開啟失敗；現在由 FFmpeg 解碼成品音軌後播放，不依賴該舊介面的 MP4 解碼能力。MCI 介面參考 [Microsoft 文件](https://learn.microsoft.com/en-us/windows/win32/multimedia/mci-reference)。

清理明細與最終機器可讀摘要見 `T16/cleanup.json`、`T16/final-summary.json`。保留正式封裝、需求、核准草圖與最終證據；正式書籍、模型及 voice-blocks 不清除。
