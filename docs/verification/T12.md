# T12：單一主視窗與語音中斷續作

2026-10-29。需求：本機 T12 票稿、Spec v1.1 需求 17／18，以及使用者核准的 [v2 單一主視窗提案](../T12-ui-proposal.md)。

## 交付

正式程式：`dist/T12/ebook2mp4/ebook2mp4.exe`。搬移時請搬整個 `ebook2mp4` 資料夾。最終 SHA-256 與九個模組的封裝／來源逐一比對結果見 [T12-package-source.json](T12-package-source.json)。

「4 試聽與製作」直接顯示主視窗內頁。「語音設定與試聽 → 製作與成品」與服務管理共用主視窗；原生選檔與明確確認仍使用對話框。左側書籍／批次及上方四步驟保留。設定區依可用寬度改成三欄、兩欄或單欄，內容垂直捲動，底部儲存／前進操作固定可見。選中步驟的 hover 狀態維持文字對比。

返回保留試聽文字與未存設定；每本書／每批次的頁面分開保存，不能把 A 批次的輸入寫入 B。切頁停止播放；背景完成的隱藏試聽不自動播放。正式製作在切頁後繼續，底部顯示所屬批次、階段與完成數，可返回原任務。關閉程式先取消、等工作停止、保存有效進度，再釋放資源；拒絕捨棄試聽會中止關閉。等待關閉期間又改稿，仍須處理未存稿。

重開「製作與成品」會在背景檢查保存任務及有效音訊。可選任務、核對原始朗讀稿與設定，檢查取消／失敗／中斷、可重用及待處理數後續作。「重新開始…」另建任務，保留舊進度與成功成品。設定或確認稿改變時，舊任務不直接續作，必須核對新版本。執行中的任務始終使用啟動時的快照。

公開新增 `resume_narration(batch_id, run_id, allow_network=True)`；`narration_runs(batch_id)` 提供 snapshot、progress、stale、published、reusable、remaining。完整區塊以內容／服務／模型／音色／語速／處理指紋、SHA-256、PCM 格式及宣告資料長度驗證。缺少、截斷或損壞的區塊不能重用。每塊每次執行最多 3 次網路嘗試，前次錯誤與進度保留於 `resume_history`。進度中的總區塊數不是整體工作百分比，不提供虛構 ETA。

同專案的製作使用 Windows 核心 mutex；程序硬中斷後由作業系統釋放。另保留 PID 標記，兼容舊版正在執行的製作，避免搶走任務。恢復不要求使用者手動刪鎖。無法判定的舊鎖採保守錯誤提示。有效語音原音仍保存在批次 `voice-blocks`，它是續作資料，不能當暫存刪除。

未勾選傳送同意時，只有全部區塊有效的任務可本機組裝。`allow_network=False` 一路傳到背景合成邊界；即使掃描後快取又遭刪除或損壞，也會停止並要求重新同意，不暗中改成線上請求。全部有效時不需要音色目錄或服務憑證。組裝與發布沿用原子索引，取消、失敗或空間不足均保護上一份 MP3／SRT。

## 驗收路徑

以下採 ASD-STE100 的短句、命令句及單一步驟原則，用繁體中文表達。完整案例見提案 A01～A15、S01～S07。

| 項目 | 操作路徑 | 檢查結果 |
| --- | --- | --- |
| 單一主視窗 | 開啟專案 → 選擇批次 → 按「4 試聽與製作」→ 按「製作與成品」 | 內容在同一主視窗切換。沒有新增流程視窗。 |
| 設定與返回 | 修改試聽文字 → 儲存設定並前往製作 → 按「返回語音設定」 | 原文字與設定保留。設定儲存失敗時不前進。 |
| 服務管理 | 按「新增／管理服務…」→ 檢查欄位 → 按「取消」 | 在主視窗返回試聽頁。原輸入保留。 |
| 背景製作 | 開始製作 → 返回校對頁 → 選另一批次 → 按底部「返回任務」 | 原任務持續。所屬批次正確。沒有重複啟動。 |
| 取消續作 | 開始製作 → 等部分區塊完成 → 按「取消任務」→ 等待停止 → 關閉 → 重開 → 選原任務 → 按「繼續未完成區塊」 | 只重做缺少、失敗或驗證不通過的區塊。 |
| 硬中斷恢復 | 在測試專案製作 → 結束測試程序 → 重開專案 → 檢查中斷狀態 → 續作 | 無須手動刪鎖。最後有效區塊保留。 |
| 改稿隔離 | 開始製作 → 修改稿件或設定 → 回製作頁核對 | 原任務快照不變。新稿不能混入舊任務。 |
| 成品保護 | 保留成功成品 → 在新任務組裝時取消或注入磁碟不足 → 播放舊成品 | 舊 MP3／SRT 內容完整。半成品不標完成。 |
| 離線組裝 | 選全部區塊有效的未發布任務 → 取消傳送同意 → 續作 | 本機完成組裝。新增 TTS 請求數為 0。 |
| 關閉與清理 | 製作中關閉程式 → 等待退出 → 重開 → 檢查任務 | 有效進度保存。本次程序、鎖、連線與播放資源釋放。 |

- 完整分模組回歸：33 模組、196 案例、564.171 秒、0 跳過。首輪 `test_rhythm_desktop` 與 `test_tts_providers` 共 3 項仍假設舊彈出視窗；改驗核准的內頁／捲動後，相關 9 項重跑通過。其餘模組首輪通過。原始失敗保留，不以重跑覆蓋。見 [完整紀錄](T12-full-suite.txt)、[首輪摘要](T12-full-summary.json)、[相關重跑](T12-final-targeted.txt)、[彙整](T12-final-summary.json)。
- 最後 11 項續作／Tk／節奏回歸通過；另補實際媒體子程序在組裝時取消的案例，確認 kill／等待退出、舊成品不變、零新增 TTS 續作。最終 6 項續作全過，合計 197 個不同案例。服務管理跨批次返回另由原 3 項內頁測試重驗。見 [最後回歸](T12-final-recovery.txt)、[續作收尾](T12-resume-final.txt)、[內頁收尾](T12-pages-final.txt)。
- 真實測試子程序在第二區塊硬退出，重開辨識中斷、恢復 OS 鎖並只請求第二區塊。網路服務替身配真實 FFmpeg，另外覆蓋截斷快取、磁碟發布失敗、舊成品雜湊保留、缺少音色目錄時離線組裝，以及掃描後快取改變仍不得繞過同意。
- 真實 Edge TTS 7.3.1 只送三段合成範例。第一塊成功後取消，重開顯示可重用 1 塊；續作只送兩塊。共 4 次請求，其中第二塊為中斷後重送；第一塊不重送。最後 3 塊、16,096 ms、重用 1 塊，鎖已移除。見 [真實紀錄](T12-real.json)、[MP3](T12-real.mp3)、[SRT](T12-real.srt)。人工聽感仍待驗收；Gemini／Fish 沿用 HTTP 替身驗證，沒有付費真實合成。
- 全部 22 來源模組一般 mypy 通過；9 個相關來源另以 `--check-untyped-defs` 通過。見 [全部型別](T12-typecheck-all.txt)、[相關完整檢查](T12-typecheck.txt)。
- 兩軸獨立審查及原作者複查最終 0 項未解決，見 [審查紀錄](T12-review.md)。

## 視覺與封裝

原生 Tk 在 1040×640 的測試檢查固定操作區、控制項邊界、捲動可及性、返回保留內容及背景任務歸屬。封裝亦已從原生選檔開啟合成專案，直接進入主視窗語音頁與中斷任務頁，確認可重用數與續作入口。較早來源 fixture 的截圖工具曾無法綁定程序；改用工具直接啟動正式封裝後已能擷取畫面，不把失敗當作通過。其他 DPI 及長篇人工操作仍待驗。

新增 Tk 測試曾漏設音色快取隔離，測試清單寫入本機音色快取。已修正為每案隔離目錄，並透過正式程式重新取得真實 Edge 清單。沒有修改既有服務憑證、音色選擇或使用者書籍。
