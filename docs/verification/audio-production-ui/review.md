# 音訊製做 UI 驗收

日期：2026-11-09。實作：GPT-6.1 Sol，高推理；主 agent 獨立審查與原生操作驗收。

## 範圍與結果

僅改音訊工作區及相關入口文字。語音、影片、全書合併與成品頁不重排。共用文稿頁下一步按鈕只在音訊工作區隱藏，離開後恢復。

基線問題：朗讀稿預覽與清單分占彈性高度，多列任務／成品控制壓縮清單；收合文件列表後，製作頁缺少重開入口。

修正：清單獨占剩餘高度；稿件、任務設定與完整錯誤在同工作區切換；主操作固定，成品功能依可用寬度直接顯示或收進「成品操作」。同源返回保留選取與捲動，換任務／來源才重設。

審查期間發現並修正：無音訊成品時仍需允許進影片設定；直接選錯誤分頁不可空白；音訊頁不可顯示無關的「前往試聽與製作」主要按鈕；Home／End 首末列鍵盤操作。

## 原生視覺與操作

使用真實 Tk 控制項、173 個合成區塊、模擬 429 失敗及上一版成功成品。未更改系統顯示縮放；Tk scaling=1.334646962233169。

| 實際 client 尺寸 | 清單高度 | 完整列數 | 結果 |
| --- | --- | --- | --- |
| 1280×720 | 388 px | 14 | 主 agent 畫面與互動檢查通過 |
| 1536×845 | 513 px | 19 | 主 agent 最終畫面與互動檢查通過 |

第二筆請求為 1536×864，但 OS 工作區限制成 1536×845，依實際值記錄。900×640 忙碌／恢復設定控制項以原生測試檢查邊界，未另作人工截圖驗收。

- 開啟來源詳情 → 父導覽「音訊製做」保持選定 → 返回清單。
- 滾輪移動清單 → 頂部與底部操作不移動。
- 拖曳捲軸到末端 → 第 173 列完整可見。
- 收合文件列表 → 主內容取得左側空間 → 保留末端捲動位置及重新開啟入口。
- 最終版直接選「狀態與錯誤詳情」 → 顯示完整錯誤。
- 選取清單 → End → 第 173 列可見且選定 → Home → 第 1 列可見且選定。

`native-final.png`、`native-final-error.png`、`native-final-keyboard-end.png` 為修正後證據。其他 `native-*` 圖為第一輪審查證據，可能仍含當時已指出的問題。
