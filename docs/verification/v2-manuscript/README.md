# v2 共用模組與「1 文稿」交付

2026-11-11。主 agent 執行，沒有啟動子 agent。正式成品固定 `dist/ebook2mp4`；v1 保存於 `archives/v1`，兩版都已用獨立合成專案啟動及正常退出。

## 實作範圍

完成範圍澄清：只有「1 文稿」主介面接入 v2 共用模組。下文「同窗工具」指既有功能及操作回歸保留，工具內頁本身尚未套用 v2 共用模組；詳見 [內頁接續交接](../../tickets/v2-inner-pages-handoff.md)。

`desktop_shell.py` 建立共用導覽、文件列表、內容承載區與底列。文稿透過框架控制列表顯隱與導覽選取，底列以 ActionSpec／PagePresentation 提供狀態、主要動作、可用狀態與回呼。每個按鈕重用單一 Tcl dispatcher；切換動作後不保留上一頁回呼。

`workspace_layout.py` 集中工具群間隔及換列。PDF 頁碼與總頁數保持同一群組；上一頁、頁碼群、下一頁、縮放、來源各組間距一致。來源切為 TXT 時隱藏 PDF 控制，返回 PDF 時恢復間距。文稿沿用 v1 的完整布局、功能入口、1:1 對照與同窗工具；沒有修改資料格式、語音或影片任務契約。視窗標題標示 v2。

完整盤點、介面及設計見 [模組計畫](../../v2-ui-module-plan.md) 與 [全頁布局設計](../../v2-page-layouts.md)。其他製作頁沿用 v1，尚未完整遷移共用呈現介面；`production_desktop.py`／`narration_desktop.py` 的舊 chrome 操作與 `grid(in_=...)` 仍屬後續階段。不能把本輪文稿完成當成全 APP 模組化完成。

操作路徑：

1. 文稿正文 → Ctrl+End → 確認第400段可見，導覽及底列固定。

3. 返回文稿 → 檢查文字及捲動 → 確認內容保留。改18pt → 收合／展開列表 → 確認主要操作可達。

## 限制與清理

本輪沒有呼叫真實Gemini／OCR／TTS，沒有驗收付費服務、真實人聲聽感、其他DPI或乾淨Windows安裝。v1封存媒體驗收使用受控音調TTS及真實本機FFmpeg；v2相關媒體任務由回歸替身與本機工具驗證，不宣稱全部產品功能重驗。

清理只移除本輪合成專案、隔離依賴、建置／型別快取、暫存及自建測試程序；保留v1完整封存、正式v2成品、需求／設計與最終證據。原先兩個2026-11-02測試目錄及使用者outputs保留。程序與兩版檔案占用結果見 cleanup.json；原有必要來源保留檢查見 preserved-sources.json。沒有Git提交、推送或子agent。
