## 共用介面與功能

`WorkspaceFrame` 的 `InnerPageHost` 持有固定標頭、唯一返回、文件範圍、內容 port、區域結果與 ActionBar。內容頁提供 page id、PagePresentation、ActionSpec 與命令；`LineBreakPreview` 只建立差異／空狀態並管理預覽快照及套用。全域底列直接呈現預覽適用動作，不再先發文稿提交再對頁名特判隱藏。沒有以相容控制項別名宣稱本頁接入完成。

`align_inner_header()` 統一左列表與內頁的標頭帶，從目前可見標頭計算；不再用隱藏文稿工具列造成高低錯位。套用與返回、重開列表都由共用 active 規則管理；切到製作頁時暫停命令，回來保留預覽。ActionBar 重用每個按鈕的 Tcl dispatcher；隱藏頁不能提交或改動列表。重開圖示沿用共用 hover／focus 提示與清理。

保留有變更才提交、先備份再保存、保存成功才更新編輯器、保存失敗保留、過期拒絕、一次復原、AI 未完成選擇與來源阻擋。返回保留未存全文、游標、選取、捲動與搜尋。無變更不建立整理備份／版本或取消朗讀確認。文稿、來源及任務格式未變。

操作路徑：

1. 編輯 → 整理換行預覽 → 確認左右工具列及白色內容外框齊頭。
2. 點差異 → Ctrl+End → 確認第400段完整可達。用滾輪向上 → 確認只有差異移動。
3. 縮為900×640 → 設18pt → 重做末端檢查。收合／重開列表 → 確認選取保留且空間回收。
4. 注入保存失敗 → 確認留在預覽、現稿保留、返回及重試可達。排除後套用 → Ctrl+Z → 確認一次恢復原稿。

圖中長文及差異是合成資料。mock使用短例逐段展示增刪；正式頁沿用既有 unified_diff 分組，因此長差異可先列整組刪除再列新增，不改差異演算法以模仿示意文字。這不改變核准的父布局、操作分組與空間分配。平台字形／邊框依原生主題呈現；沒有尚未解決的結構或齊頭落差。`native-save-failure.png`為主布局輪的原生失敗畫面；最後狀態介面另加入錯誤文字色彩，最終EXE未另注入保存失敗。
