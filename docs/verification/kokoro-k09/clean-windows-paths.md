# K09 乾淨 Windows 驗收路徑（留存參考）

2026-11-19，使用者確認目前沒有乾淨 Windows 電腦或虛擬機，先完成本機可做部分。2026-11-20，使用者確認不做這項測試。本檔保留原操作步驟供參考。

## 環境與交付

使用未安裝 Python、開發依賴，且沒有模型／語言資源快取的新 Windows 使用者環境。保留作業系統版本、顯示縮放、CPU／記憶體及安裝軟體清單的證據。

複製完整 `dist/ebook2mp4` 目錄。複製 `dist/kokoro/kokoro-zh-cpu-78fb4b82d084294e.zip`。不要只複製 EXE。兩個成品的 SHA-256 及大小見 [package.json](package.json) 與 [main-distribution.json](main-distribution.json)。

主程式內附 Python 3.14.3。語音 ZIP 內附獨立 Python 3.12.15、CPU 引擎、固定模型修訂、100 個中文音色與授權通知。使用者不需安裝 Python、開啟終端機或啟動服務。

## 首次離線操作

1. 中斷測試機的對外網路 → 確認無法連上網路 → 保存網路狀態證據。
2. 啟動 `ebook2mp4.exe` → 確認主視窗最大化。
3. 建立測試書籍 → 匯入第一份繁體 TXT → 保存校對稿。
4. 進入「語音設定與試聽」→ 選取「Kokoro 本機 CPU」。
5. 進入「管理本機語音包」→ 選取交付 ZIP → 按下「檢查並匯入」。
6. 等待匯入完成 → 展開「版本、音色與授權詳情」→ 核對語音包識別與 100 個音色。
7. 返回語音設定 → 選取 `zf_001` → 使用固定試聽範例 → 開始首次試聽。
8. 等待完成 → 播放音檔 → 記錄耗時、可見狀態及人工聽感。可播放只能算技術結果。
9. 確認朗讀稿 → 前往音訊製做 → 開始製作 → 核對 MP3 與繁體原文 SRT。
10. 匯入第二份 TXT → 完成第二批音訊 → 記錄兩個批次的成品版本。
11. 開啟全書合併音訊 → 選取兩批 → 反轉順序 → 設定 500 ms 交接停頓 → 製作總 MP3／SRT。
12. 核對解碼後音長及每段字幕偏移 → 確認只加入一次交接停頓。
13. 使用總音訊製作 MP4 → 更換圖片 → 再次製作 → 確認總音訊及兩版影片音軌一致，且沒有新增 TTS。

## 異常與清理

1. 開始新試聽 → 按下取消 → 確認工作程序結束且上一份試聽保留。
2. 開始正式製作 → 按下取消 → 確認上一份成品仍可播放。
3. 匯入錯版或損毀 ZIP → 確認錯誤提供恢復方法，原有效安裝保留。
4. 移除語音包 → 確認書稿與完成成品保留 → 新的本機合成顯示缺包，沒有雲端備援。
5. 重開舊雲端專案 → 確認原服務設定及既有成品可讀。
6. 在最大化、1360×820、1280×720、900×640 與適用字級重驗 → 逐項填寫根目錄 `check-list.md`，保存畫面及量測。
7. 關閉主程式 → 核對本次子程序、安裝暫存及檔案占用 → 清除本次測試資料並保留證據。

完成全部必要條件後，才可關閉 [#11](https://github.com/newesp/ebook2mp4/issues/11)。
