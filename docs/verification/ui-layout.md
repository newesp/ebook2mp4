## 實作

- 儲存留在共通上方工具列，正常樣式、已儲存停用、Ctrl+S 保留；確認只在「確認」頁底部，髒稿顯示「儲存並確認朗讀稿」。
- 右側改互斥「編輯／AI 校對／確認」Notebook，沒有長捲動 Canvas；Ctrl+F 揭露搜尋、F6 專注模式、可調字級，編輯器保留跨分頁選取。
- 低頻專案／版本／來源／批次命令集中具名原生選單；MenuAction 保留真實禁用及 invoke 語意，呼叫原有業務方法。
- 批次名稱與狀態分欄，長檔名不再擠掉待檢查／已確認狀態。來源資訊精簡，完整路徑與細節可另開查看。
- 底部固定稿件狀態與最近消息，完整操作結果可開記錄複製；來源阻擋數與確認頁持續可見，不被成功消息取代。異常改清單核對，可前往頁面、確認處理或明確略過。
- PDF 標準 Toplevel 最大化且可還原，頂部精簡頁次與重辨命令，設定獨立小窗；底部固定來源狀態、作業進度、候選選擇與提交。縮放只處理預覽，normalized 框選座標隨縮放／平移正確換算，換頁清除選區；OCR 輸入品質與原始逐頁資料不變。
- 換行預覽最大化原稿／候選並排與差異標色，可只看候選；套用固定使用計算候選，不受檢視模式影響，保留改稿檢查與單次復原。
- Gemini 候選維持原有請求與保存規則，加段落導航、下一待確認、決定計數、可展開疑點、獨立阻擋資訊；原文／候選雙欄可調，整批操作收進具名選單，Esc 與關閉資源規則一致。
