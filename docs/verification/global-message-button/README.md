## 正式 EXE 畫面驗收

1. 開啟正式 EXE → 檢查右上角 → 確認「訊息記錄」位於「專案」右側。見 `package-start.png`。
2. 按下「訊息記錄」→ 檢查紀錄內容 → 確認可查看完整操作訊息。見 `package-messages.png`。
3. 縮小正式視窗 → 檢查右上角及底部 → 確認按鈕完整顯示，底部僅保留主要動作。見 `package-reduced.png`。外框實測 1145×850 實體像素，顯示倍率 125%；截圖不含部分非用戶端邊框。
4. 檢查控制項 → 確認「專案」只有一個下拉箭頭，訊息按鈕名稱及焦點框清楚可辨。
5. 正常關閉驗收程式 → 檢查退出結果 → 確認 exit code 0，沒有強制結束。

正式 EXE 以隔離的合成專案與設定啟動，未使用使用者專案或線上服務。`package.json` 保存 EXE 雜湊、來源模組比對及正常退出結果。封裝內文稿模組與本次來源一致。`build.txt` 保存建置結果；`prebuild-locks.txt` 保存建置前 1,905 檔的獨占開啟檢查。最終資源及暫存清理結果見 `cleanup.json`。

本次分別完成原生回歸與正式封裝畫面驗收。未重跑全專案媒體生成或其他顯示倍率。
