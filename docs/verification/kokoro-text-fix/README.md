# 段內換行試聽錯誤修正

日期：2026-11-05。使用者原稿、三種音色及正式輸出已完成真實 CPU 驗證。

## 原因

Misaki 將段內單換行保留在音素字串中，模型字典沒有 LF／CR／Tab。工作程序的嚴格音素檢查因此拋出 `Unsupported phonemes`，主程式顯示「本機語音合成失敗」。失敗在音色推論前發生，因此切換音色沒有用。

[縮小重現](red-g2p-ascii.txt)：整段的未知音素只有 `\n`；逐行及「2. 矛盾」均沒有未知音素。首份診斷另遇到 cp950 輸出編碼錯誤，已以 ASCII 跳脫輸出重跑；不將該診斷輸出錯誤當成語音錯誤。

修正只將音素副本的空白字元轉成模型支援的 ASCII 空格。沒有刪除未知音素、改寫原稿或字幕，也沒有關閉音素與長度檢查。新版包 ID 納入工作程序雜湊，因此不會誤用舊版合成快取。

## 更新與驗收路徑

1. 解壓新版主程式 ZIP → 啟動其中的 `ebook2mp4.exe`。
2. 開啟原專案 → 在服務選單選取 Kokoro → 按「管理本機語音包…」。
3. 匯入 `kokoro-zh-cpu-78fb4b82d084294e.zip` → 等待語音包就緒 → 返回語音設定。
4. 重新選取 Kokoro 及音色 → 儲存設定 → 貼上原稿（保留四行與「2. 矛盾」）。
5. 產生試聽 → 確認可播放 → 檢查最後「矛盾」及各行文字。
6. 切換另一音色 → 再次試聽 → 確認沒有合成錯誤。

只更新主程式、不匯入新版語音包，無法取得這次修正。既有 UI／服務修改保留，見 [原有差異快照](preserved-user-changes.patch)。
