# K04 離線語音包管理覆核

2026-11-20。修正 [#6](https://github.com/newesp/ebook2mp4/issues/6) 的兩個重匯入問題。原有安裝完整時，舊流程可能略過所選 ZIP 的資源雜湊，將同大小但內容不符的 ZIP 回報成功。原有資源完整但安裝清單遺失或無法讀取時，舊流程也可能回報成功，目錄卻仍未恢復可用。

重匯入會逐檔查驗所選 ZIP。安裝資源仍完整時，使用通過驗證的 ZIP 恢復安裝清單，原資源留在原處。原資源受損時沿用暫存安裝流程，完整驗證後才替換。移除在取得語音包鎖後再次確認目標。

| 驗收範圍 | 證據 |
| --- | --- |
| 正式包內容與版本 | 交付 ZIP 內含 Python 3.12.15、CPU 依賴、官方模型及 100 個中文音色，含授權通知和固定來源。[正式包清單](../kokoro-k09/package.json) |
| 新裝、重匯入及清單修復 | 對正式 ZIP 以隔離的包目錄與書籍執行公開工作流程，核對安裝、重開、清單修復、原資源保留及移除。[正式包操作紀錄](real-package.txt) |
| 損毀與目錄保護 | 回歸以合成 ZIP 檢查不合規路徑、同大小的錯誤檔案、清單遺失及損毀，核對狀態及已安裝檔案。 |
| 移除與資源使用 | 保有語音包鎖時拒絕移除；釋放鎖後可移除，重開仍顯示未安裝。已交付作品、既有 Edge 設定與播放相容性沿用先前正式版操作證據。[K09 正式操作](../kokoro-k09/README.md#正式-exe-操作) |
| 音色品質 | 100 個音色均可辨識，沒有將個別樣本或 K09 整體聽感結果外推為全音色已驗證。 |

回歸共 5 項，4 項通過，包含正式推論的舊案例在此測試組因未設定語音包參數而跳過。正式 ZIP 的包管理另有獨立操作紀錄。[回歸](regression.txt)

這台電腦單次首次匯入為 85.07 秒，重匯入並修復清單為 493.15 秒。重匯入包含現有資源及 ZIP 各自的完整校驗。在這次測試中，worker 的雜湊與修改時間一致，移除後重開的清單為空，隔離測試目錄也已刪除。
