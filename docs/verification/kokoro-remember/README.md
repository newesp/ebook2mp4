# 記住語音包 ZIP 路徑

匯入成功後，管理頁將 ZIP 的絕對路徑保存在本機語音設定目錄。重開管理頁或主程式時，只有檔案仍存在才帶入路徑。匯入失敗或取消不會覆蓋前次成功的路徑；使用者仍可手動選擇或輸入其他路徑。若設定無法保存，頁面會顯示提示。

舊版沒有保存已匯入 ZIP 的來源路徑，因此無法還原更新前的選擇。更新後首次成功匯入一次，後續才會記住；已安裝語音包本身不受影響。

[原生介面測試](tests.txt)：成功記錄、失敗不覆蓋、重開還原、檔案消失後清空及再次重開；另驗證既有介面結構。共 2 個案例通過。[首次測試](initial-tests.txt) 未隔離電腦上既有語音包，既有案例的「未安裝」前提不成立；隔離後重跑通過。[本次修改的兩個來源檔型別檢查](typecheck.txt)通過。

主程式建置於 `dist\ebook2mp4`。[建置紀錄](build.txt)、[封裝來源核對](package.json)、[啟動檢查](startup.json)。既有工作區變更與語音包保留。
