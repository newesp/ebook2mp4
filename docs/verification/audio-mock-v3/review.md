# 音訊製做與內頁：Mock v3 實作驗收

日期：2026-11-10。依使用者確認的 `docs/mock-ui/production-inner-v3` 與前一輪主頁排列實作。正式成品位於 `dist/ebook2mp4/ebook2mp4.exe`。

## 原因與修正

原流程導覽使用 Compact 尺寸，與工作區控制項存在 8 個 Tk 座標像素的高度差。三個流程控制項改用既有 Workspace／Primary 樣式，正常狀態及選取狀態維持相同尺寸。

音訊流程導覽在一般視窗移至頂列，與主步驟間保留垂直分隔線。窄視窗將整組導覽換列。任務列與左側匯入、管理對齊；修正左側父層置中造成的 4 像素偏差。其他製作頁保留原本工作區配置。

音訊操作移至全寬固定底部。文件摘要與操作訊息使用同一列，返回與重新開始置左，成品及下一步置右。依實際控制項需求寬度分列，避免裁切。成品操作仍保有播放、停止、匯出、開啟資料夾及製作 MP4 的入口。

內頁沿用 `ttk.Notebook`，啟用鍵盤頁籤切換。移除重複返回與多餘工具列；右上只顯示「← 返回區塊清單」。同意欄位、重新檢查、狀態詳情依此順序成組排列。移除獨立的同意列，釋放高度給文稿。成品詳細資料在內頁及狀態詳情中可讀取。

播放成功後，同位置按鈕改為「停止播放」。停止、自然結束及播放失敗會恢復「播放成品」。即使製作任務仍在執行，也會檢查播放結束。切換製作頁沿用既有停止契約；切換內頁頁籤則保留實際播放狀態。已發布且未過期的任務提供「全書合併 →」下一步。

## 正式 EXE 畫面與操作

使用隔離專案、合成音訊及隔離音色快取；未使用使用者書稿合成。正式啟動最大化，並以同一 EXE 還原、縮小至最小尺寸。`package.json` 記錄 EXE SHA-256 及正常結束狀態。

1. 按下「2 試聽與製作」→ 按下「音訊製做」→ 確認流程移至頂列、任務列與左側對齊、底部操作完整。證據：`package-main.png`。
2. 按下「朗讀稿與任務設定」→ 檢查右上與內頁→ 確認返回只有一個、沒有下拉箭頭，且文稿延伸至狀態列。證據：`package-inner.png`。
3. 按下「播放成品」→ 確認按鈕變為「停止播放」；快速連續啟動與停止→ 確認恢復「播放成品」。另觀察八秒合成音訊自然結束後恢復原按鈕。證據：`package-playing.png`、`package-stopped.png`。
4. 還原並拖曳縮至最小視窗→ 檢查文稿、同意欄與必要按鈕→ 確認未裁切。證據：`package-minimum.png`，外框截圖為 1128×840 實體像素。
5. 點入文稿→ 按下 Ctrl+End → 確認可讀到第 173 段，底部操作不移動。證據：`package-text-end.png`。
6. 按下 Ctrl+Tab → 確認切至狀態與錯誤詳情並顯示完整模擬 429 訊息。證據：`package-error-tab.png`。
7. 按下 Ctrl+Shift+Tab → 確認回到文稿仍停在第 169–173 段。證據：`package-retained-scroll.png`。
8. 正常關閉 EXE → 確認程序結束碼為 0。證據：`package.json`。

測試通過與正式畫面驗收分開記錄。此工作驗收 UI、資料保留與本機播放；未驗證真實雲端語音服務的可用性、配額或合成品質。
