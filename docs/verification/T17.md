# T17：總音訊搭配背景影片

2026-11-05。使用者確認 `docs/mock-ui/t17-background-video-v1/index.html` 後實作。正式程式固定在 `dist/ebook2mp4/ebook2mp4.exe`；請搬移整個資料夾。

## 交付行為

- 沿用「全書合併 → ① 合併音訊 → ② 製作影片」。素材選單保留 JPEG／PNG，新增背景 MP4。音訊完成後入口改為「加入視覺素材，製作 MP4」。
- 先檢查 MP4 串流，再完整解碼背景視訊。驗證雜湊與檢查期間的檔案變更。素材以串流複製到專案，不將整支影片載入記憶體。副本、來源類型、模式與解析度可保存、重開與離線使用。
- 長背景從開頭裁切至總音訊結束。短背景預設循環，可選最後一格定格。保持比例、補黑邊。預覽提供無聲播放與總影片位置滑桿；定格位置擷取真正最後一格。
- 編碼只選背景視訊與總 MP3 音訊。背景原聲完全排除。沿用總 SRT 的原始位元組，不新增 TTS、不重複交接停頓、不重排旁白。H.264／yuv420p、AAC-LC／48 kHz／雙聲道、16:9、30 fps、faststart。
- 視覺變更只使總影片待更新。失敗、取消與重試保留有效總音訊和舊影片。任務沿用固定快照、來源雜湊、輸出驗證、發布前變更保護及明確發布重試。
- 成品播放改為實際影片的動態畫面與音軌。只保留最新預覽幀，不累積完整影片；離頁、停止與結束會關閉解碼程序、播放器及暫存。
- 舊 T16 圖片專案以預設值補齊新欄位，不因增加欄位而自動失效。

## UI 驗收路徑

1. 開啟已有有效總 MP3／SRT 的書籍 → 按「4 試聽與製作」→ 按「全書合併」。
2. 按「加入視覺素材，製作 MP4」→ 選「背景影片（MP4）」→ 選擇可讀的 MP4。
3. 等待檢查完成 → 檢查預覽 → 確認畫面比例與黑邊。
4. 選短背景 → 選「循環播放」→ 按「播放預覽」→ 確認背景回到開頭。
5. 選「最後一格定格」→ 移動滑桿至背景結束之後 → 確認尾格保持。
6. 選長背景 → 檢查素材區 → 確認短背景模式隱藏，說明顯示裁切。
7. 按「更新總 MP4」→ 檢查完成狀態 → 確認總音訊仍有效。
8. 按「成品操作 → 播放總影片」→ 等待結束 → 確認顯示「影片播放已結束」。
9. 改模式或解析度 → 檢查成品摘要 → 確認顯示「待更新 · 上一版總影片」。
10. 開始更新 → 按「取消任務」→ 確認舊成品保留。
11. 返回音訊頁 → 重開製片頁 → 確認未存輸入保留。保存設定 → 重開書籍 → 確認素材與模式保留。

最小視窗初輪發現左側長說明裁切。修正於父容器層：長說明移至既有固定說明列與來源詳情，素材摘要維持單列，控制項區不再承擔說明高度。`native-1040.png`／`native-1360.png` 已目視確認無重疊、主要按鈕可見。其他 DPI 未驗。

## 驗證結果與證據

- 9 個相關測試模組，累計 **46 個不同案例通過，0 剩餘失敗、0 跳過**。涵蓋 T17、既有圖片製片、總音訊、接點與製作頁。首次回歸缺 reportlab 的兩個模組已補依賴重跑全過。沙箱非同步工作曾停滯；相同測試改目前 Windows 使用者環境通過。原失敗與重跑記錄均保留。見 `T17/test-summary.json`、`regression.txt`、`final-tests.txt`、`entry-final-tests.txt`。
- 4 個變更應用來源通過完整函式型別檢查，見 `T17/typecheck.txt`。
- 真實含 1600 Hz 原聲的紅／綠／藍短背景驗證循環及尾格；長背景驗證裁切。輸出音訊中 440 Hz 旁白頻率幅度超過背景頻率 30 倍，既有交接中段峰值低於 40／32768。此為合成音調與自動量測，非真人朗讀或人工聽感驗收。
- 額外驗證 300 ms 畫面搭配 1,200 ms 原聲：正式製片與無聲預覽均先以獨立視訊軌循環，避免容器音軌尾段造成畫面停頓。350 ms 已回到紅色首段，輸出為 900 ms。見 `loop-tail-tests.txt`、`loop-long-sound.json`、`media/loop-long-sound/`。
- 保存的 720p 循環、1080p 直式定格、720p 長片裁切，總音訊與輸出影片皆 **2,900 ms**，SRT 位元組一致，零新 TTS。見 `T17/real-media.json` 與 `T17/media/`。原聲排除、黑邊像素、編碼、時長與快啟動另由公共流程測試驗證。
- 正式 exe 使用不含系統 Python／FFmpeg 的 PATH 啟動。已走原生選檔 → 開啟合成書籍 → 全書合併 → 更新背景影片 → 播放結束 → 正常退出。重讀專案：2,900 ms、音訊版本未變、每批語音任務仍 1、SRT 一致、零播放暫存與製作鎖。見 `package-flow.json`、`package-completed.png`、`package-playback-ended.png`、`media/packaged/`。
- 最後封裝另外收齊素材用語與入口文字。`T17/package.json` 記錄最終 SHA-256、內附工具及 32 個已收錄應用模組與工作區編譯碼一致；獨立 CLI、Kokoro 推論 worker 與舊 mock 不屬桌面封裝。正式 FFmpeg／FFprobe 均有校驗，工具來源及授權紀錄在 `packaging/VOICE-NOTICES.md`。
- 程式碼由本次執行者檢查；沒有宣稱完成獨立雙軸審查。未重跑與本次變更無關的全專案測試、私人 PDF、線上 TTS 或長篇真人書稿。

## 公開流程與相容性

新增 `inspect_total_video_background(path)`；`save_total_video_settings` 新增 `background`、`source_type`、`background_mode` 關鍵字。`source_type` 為 `image`／`video`，`background_mode` 為 `loop`／`hold`。既有 image／resolution 呼叫仍可使用。總影片、匯出、版本、取消及重試沿用 T16 公開入口。
