# T21 驗收：逐格式完成及續作

2026-11-06。使用者明確要求在同一 session 直接實作，已核准原 HTML mock 的範圍。正式成品固定為 `dist/ebook2mp4/ebook2mp4.exe`，請搬移整個資料夾。最終 SHA-256 與全部封裝模組／工具雜湊見 [package.json](T21/package.json)。

## 完成行為

- 「試聽與製作 → 全書合併」可選總 MP3／SRT、總 MP4／SRT 或兩者。選擇保存在專案，切換內頁、影片路徑與重開後重載。
- 同一主視窗顯示各格式準備、執行、完成、缺項、失敗、取消或待更新。只有所有要求格式均有效才顯示全部完成；成功與失敗同時存在時顯示部分完成。
- 缺項依路徑分開檢查。總音訊製片不要求批次 MP4；批次影片合併不要求總 MP3、原批次 MP3 或全片素材。缺影片素材仍可先保存有效總 MP3／SRT。
- MP4 單選時可循序準備前置總音訊；已有有效總音訊就重用。整個排程持有同一把專案製作鎖，每格式成功立即獨立發布，沒有整批回滾或新增 TTS。
- 補素材、取消後重試及重開續作只處理未完成格式。來源／設定變更顯示待更新，不把舊成果冒充目前完成。失敗的發布保留已驗證媒體，等待明確「重試保存」或取消。
- 成品操作連至 T20 既有版本頁並選取正確路徑。素材頁新增「儲存素材並返回」，返回全書合併續作。

新增公開入口：`output_formats()`、`save_output_formats()`、`save_output_plan()`、`inspect_outputs()`、`start_outputs()`、`finish_outputs()`。開始、輪詢／等待與完成在同一呼叫執行緒執行；既有媒體工作仍在背景。舊音訊、製片與影片合併公開入口相容。

## 操作驗收

1. 開啟書籍 → 按「4 試聽與製作 → 全書合併」→ 選取批次與順序。
2. 勾選 MP3 及 MP4 → 保持全片素材空白 → 按「先製作可用的 MP3」→ 確認 MP3 完成、MP4 缺項及整體部分完成。
3. 按 MP4 列「補齊缺項」→ 選素材 → 按「儲存素材並返回」→ 確認 MP3 仍完成。
4. 按「只重試未完成輸出」→ 確認 MP4 完成 → 確認顯示 2／2 完成，開始按鈕停用並顯示「輸出均已完成」。
5. 按 MP4 列「成品操作」→ 確認選中總音訊製片路徑 → 按播放 → 確認畫面、字幕及播放結束。
6. 只勾 MP4 並選「合併既有批次影片」→ 使用有效批次 MP4／SRT → 確認沒有總 MP3 仍可完成。
7. 取消或模擬單格式失敗 → 確認成功格式保留 → 重開或補齊來源 → 確認只重試未完成格式。
8. 還原視窗 → 檢查格式、結果列及主要操作 → 確認無重疊或裁切。

## 證據與檢查範圍

相關範圍共 **51 個不同案例最終通過，0 未解決失敗**：10 個 T21 公開流程、1 個 T21 原生 UI 及 40 個既有音訊／影片／合併／版本案例。首輪 [regression.txt](T21/regression.txt) 的 48 案例含兩項已過時的舊入口斷言失敗；依核准 UI 改驗新入口後在 [final-tests.txt](T21/final-tests.txt) 的 15 案例全部通過。最後僅提示文字更新，另以 [final-copy-check.txt](T21/final-copy-check.txt) 補驗通過。初輪原生取消測試的舊任務假設錯誤亦已改驗公開可觀察的取消狀態並補驗，紀錄保留。

涵蓋三種輸出選擇、兩種影片方式、缺素材／批次影片、音訊與影片各自失敗、工作中故障、發布失敗及明確保存重試、取消、模擬磁碟不足、製作中改稿、重開、舊成品及正確路徑操作。10 個變更應用來源完整函式型別檢查通過，見 [typecheck-final.txt](T21/typecheck-final.txt)。

使用合成書籍、合成音調 TTS 替身及真實隨包 FFmpeg／FFprobe。未讀使用者私人書稿，未呼叫線上 TTS。既有媒體回歸驗證實際聲軌、靜音、畫面、SRT 偏移與編碼；T21 驗證兩批各 200 ms、交接 500 ms，總音訊 900 ms，字幕不重複交接。未執行無關全專案套件、私人 OCR、真實語音聽感、長篇真書或 T23 乾淨機驗收。

原生 Tk 測試檢查 1040×640、1360×800 控制項可見性、邊界及按鈕文字。正式 exe 另經 computer-use 目視最大化／還原、原生選檔、素材保存返回、只做 MP4、正確結果與成品播放。最終 exe 在只有 Windows 系統路徑、沒有系統 Python／FFmpeg PATH 的環境自動載入隔離合成專案，確認 2／2 完成、正確完成提示與停用按鈕，從新結果列開啟正確版本並播放紅色畫面與字幕至結束，正常退出。其他 DPI 未獨立驗證。

41 個封裝應用模組與目前工作區一致，兩個媒體工具可執行。正式 UI 產出前後，MP3 版本與 SHA-256 不變；總音訊任務仍 1、影片任務新增 1、各批 TTS 任務仍 1，同版 SRT 完全一致。見 [packaged-journey.json](T21/packaged-journey.json) 與 [合成媒體證據](T21/media/total.mp4)。
