## 完成內容

- PDF 預覽選「全部強制 OCR」，所選範圍逐頁轉圖／辨識，保留順序與實際頁次。語言獨立於 TTS，對應 `chi_tra+eng`、`chi_sim+eng`、`eng`。T04 文字層與 TXT 入口保留。
- 初次載入顯示預設模型大小，快速切換語言會補查目前選擇；資訊一致前禁止下載。背景下載顯示位元組進度、驗證／安裝階段與可行錯誤；模型固定官方 tessdata_fast 4.1.0 commit，檢查大小與 SHA-256 後逐檔原子發布。預設使用者可寫模型目錄，不寫 Program Files；部分下載、暫存及鎖檔在結束時釋放，已安裝模型保留。中斷程序遺留鎖須關閉所有視窗後手動移除，避免跨視窗併發。
- OCR 在本機執行，不上傳書稿／頁圖。引擎使用無視窗子程序、參數陣列、不經 shell；每頁 300 DPI，頁圖上限 25,000,000 pixels，逐頁關閉 PDFium 文件／頁／bitmap／Pillow 影像。單頁逾 120 秒列失敗，取消會終止並等待目前 OCR 子程序，清除頁圖暫存。
- 成功、失敗、空白／無文字待確認分開保存。空白／無文字、失敗與取消頁均列來源異常並阻擋朗讀確認，須處理或明確略過。OCR 方法、語言、模型版本、引擎、DPI／圖素上限及分段設定逐頁保存。
- 完成後先顯示可逐頁比較的 OCR 候選；明確採用才建立新批次，或關閉捨棄。取消擷取並保留完整頁的操作會發布獨立取消批次；未完成頁不報成功。新候選及重做均不覆寫既有校對稿、朗讀快照或另一批確認。候選與保存共用完整逐頁資料；保存失敗保留候選重試。
- 缺引擎／模型只阻擋 OCR，TXT 人工校對、保存與確認仍可使用。混合頁自動模式、旋轉與只重試失敗頁屬 T06。

真實網路：Windows UI 點擊下載繁中＋英文 6,479,730 位元組並完成；另透過公開工作流程補裝簡中 2,469,156 位元組（英文已存在）。[網路紀錄](T05-network.txt) 與下方截圖分開保存。原生 Windows 工具只用於本次合成書稿。
