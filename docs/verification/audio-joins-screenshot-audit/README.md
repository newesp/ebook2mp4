齊頭問題的程式原因仍需原生重現才能定案。現行 assembly_join_workspace.resized 與 manuscript_desktop.layout_workspace 都會寫入文件區的標頭列高，且左右標頭屬不同容器；這是父層布局持有者不一致的線索，不能僅憑截圖把原因定為某一個 padding。

## 不誤判的項目

左右文字區在圖中等高且上緣一致；設定／試聽操作同列；播放群組從右文字區起點開始，兩群組之間的留白有對齊用途。返回在左、保存在右也符合固定操作列規則。文字區底部出現半行本身不是捲動缺陷，必須實際到末端後才能判斷最後一行是否可達。

只有一個接點時，上一個／下一個均停用，可作簡化建議，但不是本輪主要齊頭缺陷，也不把它冒充成按鈕尺寸違規。捲軸比例、鍵盤路由、忙碌狀態、縮小視窗及保存結果都不能僅由此圖宣告通過。
