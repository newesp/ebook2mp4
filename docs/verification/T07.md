# T07 Gemini 設定、指定範圍校對與差異採用

2026-10-26，起點 `3226d3f`，主要實作 `7eae065`，審查修正 `acbd711`；目前 master，無推送遠端。T07 使用既有 ProjectWorkflow／真實 Tk 核定測試邊界，TXT 與 PDF 共用文字校對流程。

## 行為與保存

- 公開設定操作：`gemini_settings`、`save_gemini_settings`、`test_gemini_connection`。金鑰以 Windows DPAPI current-user 加密，保存於 `%LOCALAPPDATA%/ebook2mp4/gemini.json`，也可讀 `GEMINI_API_KEY`。金鑰不進專案、命令列或錯誤；設定損壞可由介面修復。測試以隔離 LOCALAPPDATA 驗證保存／讀回／清空及非明文資料。
- `gemini_scope(batch_id, start=0, end=None)` 顯示服務／模型／版本／半開字元範圍。UI 顯示為 1-based 含尾字元，送出前明確確認，只傳選定文字、校對規則與輸出結構，不上傳 PDF／頁圖／素材。未存文字先詢問保存成送出版本。
- `start_gemini_review` → job `state`／`cancel`／`wait` → `finish_gemini_review`。單次完整請求回傳與選取範圍空白行段落一對一的候選；不完整、截斷、空候選、格式不符、服務失敗不改稿。長稿分請求、部分成功／續作與只重試失敗由 T08 接續。
- `gemini_reviews` 可讀校對前參照、來源版本／範圍、模型、原文／候選／疑點、逐段決定、採用後版本歷史。內容檔及 review JSON 以相對路徑、SHA-256 參照，原子發布索引；重開驗證所有參照。來源與歷史朗讀快照不改寫。
- `decide_gemini(batch_id, review_id, paragraph, 'accepted'|'rejected')`；`paragraph=None` 只操作待確認段落。從不可變校對前版本重建已採用內容，保留選外、分段分隔符與已拒絕段落。`undo_gemini` 撤回本次採用、保留歷史版本。
- 每次採用／撤回比對候選預期校對版本及完整參照；等待期間改稿、改回相同內容但版本已變更，均不能跨版本覆蓋。UI 也阻擋覆蓋未存人工稿。文字改變才新增校對版本、失效該批目前朗讀確認及 PDF 精確映射；舊快照及其他批次保留。
- 非主執行緒發送 HTTPS 請求；socket timeout 30 秒、連線於 finally 關閉。取消不自動套用；視窗等待工作停止及保存後關閉。保存失敗保留候選可重試，關閉時可明確捨棄；`discard_gemini_review` 僅接受所屬已停止工作。沒有對模型輸出的忠實度作自動保證，仍須人工對照。

## 真實服務與替身

[真實 Gemini 結果](T07-real-gemini.json)：只送固定連線測試與合成短文，未送使用者書稿。`gemini-3.8-flash` 連線 4.052 秒；選取校對 5.206 秒，模型將「公圜」提出為「公園」，疑點另列。從 ProjectWorkflow 明確採用、重開、選外不變及撤回均通過。初次舊預設 `gemini-2.5-flash` 雖列在帳號官方清單，實際生成回 404，因此預設改為經真實驗證的模型，並提供自行調整 ID。模型清單不代表該帳號可成功生成。

API 契約依 Google 官方 [generateContent 文件](https://ai.google.dev/api/generate-content)，使用 `systemInstruction`、文字 `contents`、JSON `responseSchema` 及 `x-goog-api-key` header，固定 HTTPS 官方主機，不把金鑰放 URL。線上驗證腳本 `tests/gemini_real_check.py` 不納入預設套件，避免測試默默送出文字或花用服務額度。

替身控制外部 Gemini 回應／HTTP 邊界／原生確認與儲存失敗，驗證指定範圍請求、採用／拒絕／全部待確認、選外不變、取消、失敗、原稿變更衝突、未設定可人工、DPAPI 設定、PDF 共用、搬移／重開、原子失敗、舊候選身分、設定損壞修復及無法保存的明確捨棄。這些不能代替真實模型品質驗收。
