## 實作

語音設定新增「自然」0／500、「舒緩」200／800 與「自訂」。句尾範圍 0～1500 ms，段落範圍 0～3000 ms，必須是整數。全書預設僅供新批次沿用；現有批次設定獨立保存。重新開啟專案後保留設定；儲存失敗顯示實際原因。主窗切換批次後，舊語音視窗不能儲存或啟動工作。

試聽與正式輸出共用同一文字切分與音訊接收／解碼路徑。原文不改、不轉字、不改標點；空白行分段。非零句尾在安全句界逐句合成；成對引文／括號內保留整組，不逐句拆分。英文縮寫、小數、網址、省略號保護沿用 T10。連續句末標點、閉引號及尾隨空白只算一個句界；不產生純空白或標點專用請求。服務請求仍最多 3000 escaped UTF-8 bytes；沒有安全切點則在送出前提示修稿。

以實測 24 kHz PCM frames 建立時間軸，額外停頓是實際零值 PCM，不使用自訂 SSML。相同句尾／段落邊界取較長值。工程切分不額外加停頓。最後一塊不補尾靜音。字幕只涵蓋完整區塊實測時間，新增靜音期間無字幕；不宣稱逐字精度。

原始 PCM 保存在批次 `voice-blocks`，是可重用製作資料，不是應刪的建置快取。每塊用文字、服務、音色、語速、前處理及解碼版本建立識別，保存音訊 SHA-256 並在重用前驗證格式與雜湊。停頓不進入原始語音識別。只改非零停頓時重組 MP3／SRT；自然與非零互換若切分改變，僅重合成無法重用的文字塊。換音色／語速、改文字或損壞區塊須重新合成。失敗／取消保留成功原始塊與上次成品，移除本次組裝暫存；沒有宣稱完成 T12 跨次進度續作。

`save_voice_settings(..., sentence_pause_ms=..., paragraph_pause_ms=...)` 新增可選參數；省略則保留目前停頓設定。既有專案的 0／500 設定仍有效。計畫保存實際設定及規則。正式結果的 chunks 提供 `reused` 與真實 start/end/duration；命中快取 attempts 為 0。試聽快照也保存共用規則與文字計畫。

## 人工驗收路徑

以下採 ASD-STE100 的簡短命令、單步操作與可觀察結果格式；使用繁體中文，不宣稱符合英文受控詞彙認證。

1. 開啟 `dist/T11/ebook2mp4/ebook2mp4.exe` → 開啟測試專案 → 選擇批次 → 按「語音試聽」。
2. 選擇音色 → 選擇「自然」→ 檢查句尾為 0、段落為 500 → 按「儲存設定」。
3. 選擇「舒緩」→ 檢查句尾為 200、段落為 800 → 選取三句、兩段短稿 → 勾選同意 → 按「儲存本批設定並試聽」→ 按「播放上次結果」→ 檢查尾音完整及停頓自然 → 按「停止播放」。
4. 輸入句尾 600、段落 1000 → 按「儲存本批設定並試聽」→ 播放 → 比較舒緩版本 → 確認停頓較長、句末沒有重複或漏字。末句後不得多補一段靜音。
5. 輸入句尾 1501 → 按「儲存設定」→ 檢查範圍錯誤 → 重新開啟設定 → 檢查上次有效值仍保留。恢復有效值。
6. 儲存校對稿 → 確認朗讀稿 → 按「批次 MP3／SRT…」→ 檢查顯示的句尾與段落數值 → 勾選同意 → 按「產生 MP3／SRT」→ 播放成品 → 確認與試聽節奏一致。
7. 按「另存 MP3／SRT」→ 選擇新的資料夾 → 在字幕播放器同時開啟兩檔 → 檢查字幕依語音出現 → 檢查新增停頓期間沒有字幕 → 檢查後段沒有累積偏移。
8. 關閉所有本次測試視窗 → 重新開啟專案 → 檢查設定與上次成品可讀 → 播放 → 按「停止播放」→ 關閉程式。
