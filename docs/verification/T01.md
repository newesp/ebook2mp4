# T01 實作與驗證

日期：2026-10-25（Asia/Taipei）。依據 Spec v1.1、GLOSSARY、ADR 0001～0004、v1.1/issues/01-desktop-book-project.md。專案與上層路徑未發現 AGENTS.md；原目錄沒有 Git checkout 或正式應用程式，未建立提交或 PR，既有原型檔案保持原狀。

## 交付

Python／Tkinter 正式桌面程式、供 UI 與測試共用的 ProjectWorkflow、本機專案格式 v1，以及 Windows onedir 執行檔。必要選型記入 ADR 0005；README 說明啟動、操作、錯誤恢復及建置。T01 僅開放第一個 TXT 製作批次；其餘功能依 ticket 顯示尚缺原因，不回傳假成功。

啟動位置：`dist/ebook2mp4/ebook2mp4.exe`，必須保留同資料夾 `_internal`。總配布大小約 29.4 MB／993 個檔案，包含 Python／Tcl／Tk。開發啟動為 `python -m ebook2mp4` 或雙擊 `run.pyw`。

## 執行結果

環境為 Windows 11 10.0.26200、Python 3.14.3、Tk 8.6。命令：

```powershell
python -m unittest discover -s tests -v
python -m compileall -q ebook2mp4 tests
python packaging/build.py
```

14／14 tests 通過，其中 12 項為公開工作流程、2 項為真實 Tk 控制項連接。最後一次行為測試約 6.9 秒。涵蓋 UTF-8／BOM、CRLF、繁簡中英文、中文空白括號路徑、原始來源不變、空檔、119,000 字元稿件、搬移重開、缺檔、雜湊變更、未來格式版本、越界路徑、既有資料夾保護、寫入鎖、兩視窗版本衝突、取消關閉及寫入重試。

PyInstaller 6.22.3／hooks 2026.9 建置成功，`packaging/build.py` 可從 spec 重建。已從 onedir 的真正 ebook2mp4.exe 啟動並查看空工作台與原生開檔對話框。建置缺模組清單含跨平台條件匯入，未見啟動錯誤；啟動成功不視為全部配布功能驗收。

自動測試最初受沙箱系統暫存目錄權限影響，改在專案 `.scratch/test-runs` 建立與清理測試專案後通過。建置時工具安裝於 `.scratch/build-tools`，不改產品的執行依賴；驗證結束後已清除工具、建置暫存、測試專案及 Python 快取，需重建時執行 `python packaging/build.py --install-tools`。PowerShell 本機腳本原受執行原則阻擋，建置入口改用 Python，不調整系統安全設定。

## 真實處理與替身的界線

- 真實：Tk 視窗與事件、專案讀寫、UTF-8 解碼、SHA-256、同目錄原子替換、資料夾搬移、重開、Windows 封裝與啟動。
- 替身：自動 UI 測試中的檔案選擇／書名／保存提示對話框；以固定本機路徑及回答驅動真正工作流程。故障測試控制檔案 API 或磁碟容量回應，並實際重開驗證已提交資料。
- 未完成：桌面自動化工具無法可靠地將檔名輸入封裝程式的原生開檔對話框，因此未宣稱「封裝版經原生對話框重開專案」已通過。完整流程已由來源執行的真實 Tk 控制項測試驗證，原生檔案對話框仍需人工補驗。
- T01 無線上服務、OCR 或媒體整合，不將後續服務測試記為已通過。

## 視覺驗證

使用 Windows Computer Use 實際擷取 1360×820 及 1040×680 的邏輯視窗（系統約 125% 縮放，影像含標題列）。原生桌面未執行 HTML／CSS detector，也無網頁瀏覽器驗證需求。

根因是右側工具採固定垂直堆疊，縮小高度後超出容器；修正為獨立 Canvas／Scrollbar，文字欄維持各自捲動。批次按鈕使用固定動作名稱，完整來源檔名放在換行資訊列，避免長名稱撐寬側欄。最終截圖控制項無水平裁切或重疊；較窄時原文自然換行。

最終證據位於 `.impeccable/review/desktop.png`、`narrow.png`、`packaged-empty.png`；修正前的暫存截圖已清除。獨立審查結果為 **ship（靜態視覺範圍）**，詳見 [視覺審查](T01-visual-review.md)。

## 明確限制

- T23 的乾淨 Windows 安裝、解除安裝、簽章與內附媒體／OCR 工具尚未驗收；Inno Setup 配方已提供，但本次未編譯安裝程式。
- 未驗證所有 DPI／螢幕、螢幕閱讀器、極長書名或完整斷電一致性。原子替換保護本次測試的寫入失敗，不等同硬體斷電保證。
- 程序中斷的寫入鎖需要依提示人工移除；歷史版本及中斷殘留內容尚無回收功能。
- 119,000 字元案例驗證內容往返，不作 T24 的長篇效能或完整媒體品質驗收。
