# 音訊頁按鈕順序調整

2026-11-10。此輪使用者指示取代前一版 mock 中的操作順序。正式程式更新於 `dist/ebook2mp4`。

## 結果

- 「繼續未完成區塊」移除右箭頭。
- 底部順序為「播放成品」、「繼續未完成區塊」、「成品操作」、「製作 MP4 →」。播放時第一顆仍切換為「停止播放」。製作任務忙碌時仍提供取消操作。
- 狀態工具改為「同意傳送待處理文字」、「狀態詳情」、「重新檢查目前稿件與設定」。狀態詳情與重新檢查僅對調位置，指令各自保留。
- 將製作操作群組放入同一個成品操作列，使一般、縮小與分列狀態使用同一順序，避免兩個獨立靠右群組造成排序不同。

## 驗證

`native-tests.txt`：15 項回歸通過。包含 1360×820／900×640 控制項實際順序、邊界、高度、頁籤、播放停止、同意阻擋、舊任務及保存失敗重試。

`native-minimum.png`、`native-metrics.json`：原生 900×640 視窗，173 塊驗收內容，完整可見 11 列。任務選擇與相鄰按鈕皆 37 個 Tk 座標像素，成品選單只有一個原生指示符；四項底部操作及對調後狀態工具均完整可見。

正式 EXE 使用隔離專案及本機合成成品：

1. 按下「2 試聽與製作」→ 按下「音訊製做」→ 確認底部四項順序及繼續按鈕沒有箭頭。證據：`package-main.png`。
2. 按下左側「狀態詳情」→ 確認內頁顯示完整模擬 429 訊息。證據：`package-status.png`。
3. 按下右側「重新檢查目前稿件與設定」→ 確認任務選擇改為目前確認稿、檢查完成且舊成品保留。證據：`package-recheck.png`。
4. 正常關閉 EXE → 確認結束碼為 0。證據：`package.json`。

本次未送出書稿至雲端。尺寸測試與正式畫面驗收分別記錄。
