# 最終EXE操作驗收

固定dist/ebook2mp4/ebook2mp4.exe，以隔離APP_HOME及合成專案「UI間距驗收」啟動。使用computer-use（sky）選取該EXE的唯一視窗並切到前景後檢查，沒有操作其他應用。

路徑：開啟隔離專案→2試聽與製作→語音設定與試聽→觀察三處修正→返回文稿→再次進入→觀察布局保留→按視窗關閉。

結果：兩個帶入文字按鈕等寬等高；下方保存／下一步有一致淨距；操作列與Text有可見垂直間距，首行不貼按鈕。exe-voice.png與exe-reentered.png為該EXE實際畫面。精確Tk數值見native.json，與封裝來源一致性分開記錄；實體像素受Windows縮放影響，不混為Tk單位。

未按產生試聽／儲存設定；沒有網路合成、真實音訊或私人稿件。視窗關閉後程序檢查確認沒有ebook2mp4程序。此為三處UI修正驗收，不擴張為全頁播放與保存流程重驗。
