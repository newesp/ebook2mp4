# 來源頁捲動修正

使用者指定：無來源異常時左側顯示空狀態、移除無用途捲動；來源處理表單改為雙欄。沿用既有布局核准並執行指定修正。

原因：前輪沿用表單Canvas處理異常空狀態，隱藏內容後仍可能保留先前尺寸／捲動範圍；表單又依過高的寬度門檻轉單欄，導致左側過長。只依yscrollcommand隱藏軌道沒有消除不適用的捲動擁有者。

修正：空狀態改為main內的Label，表單Canvas整體退出布局；有異常時回復清單。表單改為固定雙欄並縮小欄位間距，維持控制項字級與高度。原頁內容溢出時仍保留有效捲軸。

驗證：test_source_issue_view三項通過，包含處理→無異常→處理切換及1360×820、1280×720、900×640表單實際yview=(0,1)。processing.png、empty.png為指定原生視窗的合成PDF畫面；已逐張目視核對。功能回歸結果另見regression.txt。正式建置結果見build.txt；封裝一致性與啟動檢查另記package.json、exe-startup.json。不將啟動檢查視為完整EXE逐頁人工驗收。
