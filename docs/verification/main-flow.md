# 主介面四步驟與可編輯確認頁

使用者需求：依主介面模擬圖，從左到右、由上到下操作。主要按鈕明示「儲存並前往確認朗讀稿」。確認頁全文可直接編輯。保留多服務語音設定與既有來源／候選／版本保護。

實作：1 匯入來源 → 2 校對文字 → 3 確認朗讀稿 → 4 試聽與製作。匯入頁提供建立／開啟專案及 PDF／TXT 入口；校對頁為來源與可編輯校對稿左右對照，搜尋／AI 側欄按需展開；確認頁收起來源欄，全文仍可編輯。兩頁共用同一編輯器，直接切頁不重載、不暗存、不清除復原紀錄。「儲存並前往」保存成功才切頁；「確認朗讀稿並前往語音設定」先詢問確認，再保存最新文字及建立不可變快照，成功才開語音設定。改稿後須重新確認。來源異常未處理時可進確認頁核對，但不能確認。儲存或確認失敗不開語音設定、不丟失編輯。

根因：固定三欄與同時呈現的工具頁籤缺乏順序提示，壓縮校對內容。改為步驟導覽、按需側欄，以及靠近內容底部的下一步操作。沿用本機 Tk、既有工作流程與專案格式。

## 驗收路徑

以下採 ASD-STE100 的短句及單一步驟原則，以繁體中文表達。

1. 開啟新版。按「建立書籍專案」。輸入名稱及位置。按「加入 TXT 批次」。選擇測試文字檔。按「確認匯入」。檢查步驟 2 顯示原文與可編輯校對稿。
2. 在右側新增「校對頁測試」。按「儲存並前往確認朗讀稿 →」。檢查步驟 3 啟用。檢查全文包含新增文字。檢查狀態為已儲存。
3. 在確認頁新增「確認頁測試」。按「返回校對文字」。檢查新增文字仍在。按頂端「3 確認朗讀稿」。檢查內容相同。
4. 按「確認朗讀稿並前往語音設定 →」。在確認視窗按「是」。檢查語音設定開啟。關閉語音設定。開啟「朗讀稿與重載備份」。檢查新朗讀稿包含兩次修改。
5. 關閉備份視窗。在全文新增文字。檢查狀態回到未確認。檢查舊朗讀稿仍可查閱。重新確認目前文字後再製作。
6. 返回步驟 2。按「校對工具」→「搜尋與取代」。尋找一個詞。按「AI 校對（選用）」。檢查原本選取文字仍保留。按「收起工具」。檢查左右對照恢復寬度。
7. 選擇有待檢查異常的批次。前往步驟 3。檢查確認按鈕停用。按「檢查來源異常」。處理各項異常。檢查確認按鈕恢復可用。
