# T04：PDF 預覽選頁，擷取文字成為校對批次

2026-10-25（Asia/Taipei）。依據核定 Spec v1.1、T04 票稿、GLOSSARY 及 ADRs；實作起點 `0831c2c`，主要實作 `579ccf6`、審查修正 `b487034`。

## 完成內容

- PDF 來源檢查與頁圖預覽在背景執行，顯示檔名、大小、可讀性、總頁數、專案位置與來源副本大小；預設整份，第一頁為 1，兩端包含，提示與印刷頁碼可能不同。起訖必須為合法整數；損毀、不可讀與密碼來源顯示原因並可更換，不提供解密。
- 逐頁文字層擷取保留原始頁次、原文字、方法、設定、成功／待檢查／失敗／取消狀態與錯誤。每次建立新批次，按 PDF 起始頁插入；可手動排序，可與 TXT 批次共存。來源 PDF 副本、逐頁 JSON 與 UTF-8 校對稿各自保存並記錄 SHA-256，最後原子發布索引。
- 背景擷取可取消，完成頁保留，未處理頁明列取消並阻擋確認；取消候選保存失敗會留在視窗供重試或明確捨棄，既有校對稿及其他批次確認不變。
- 空白、文字稀少、替代符號／異常控制字元與失敗頁列入既有 `source_issues`／`confirmation_blockers` 規則，須處理或明確略過才能確認朗讀稿。T04 沒有執行 OCR；掃描或不足文字頁不能當完整成功。
- 逐頁唯讀原稿可與原頁圖對照，顯示方法、狀態、錯誤與略過結果。頁圖保持比例並提供雙向捲動；換頁前清空舊圖，渲染失敗不顯示錯配的舊頁。
- 換行整理先預覽，可切回原始換行、取消，套用後一次復原。只將非段落的單行斷行換成空格，保留空白行（含僅空格／Tab 的空白行）、既有空格、數字、小數、縮寫、標點與連字號，不刪頁首頁尾。
- 全文編輯、保存變更與外部重載使精確對應失效，UI 明示，重開仍保留狀態；逐頁擷取原稿不改寫。朗讀／匯出正文不插入人工頁碼標籤。

## 選型與封裝

執行依賴固定為 pypdfium2 5.14.0、Pillow 13.0.0。依 [PDFium Python API](https://pypdfium2.readthedocs.io/en/stable/python_api.html) 使用 Unicode bounded-text 擷取及頁面渲染；原生呼叫序列化，每次操作明確關閉文件、頁面、文字頁、bitmap 與影像，不保留 PDF 原生 handle。TXT 入口惰性載入 PDF 元件，缺元件仍可使用 TXT。

PyInstaller onedir 包含 PDFium DLL、pypdfium2／PDFium 相依授權及 Pillow 授權資料；排除未使用的可選 NumPy adapter。ReportLab 5.1.0 僅用於產生合成測試 PDF。版本見 packaging/requirements-runtime.txt／requirements-dev.txt。T04 專案含 `kind=pdf`、`pdf` 與逐頁擷取參照，應使用 T04 或更新程式續作。

## TDD 與驗證

沿用已確認的 `ProjectWorkflow` 公開工作流程與真實 Tk UI 兩個邊界。先重現缺少 PDF 入口、換行預覽、UI 連接、空白行整理破壞段落、取消保存失敗丟棄候選與渲染失敗沿用舊頁圖，再逐項實作／修正。

最終命令（工具隔離於 `.scratch/build-tools`）：

```powershell

python -m unittest discover -s tests -v
python -m mypy ebook2mp4 --check-untyped-defs --cache-dir .mypy_cache
python -m compileall -q ebook2mp4 tests packaging/build.py
python packaging/build.py
```
