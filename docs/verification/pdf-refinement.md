# PDF 命名與連續局部辨識驗證

日期：2026-10-27。本次接續已核定的 native UI 配置，處理使用者回報的命名、模型零位元組及同頁多段修正問題。正式 UI 使用原有 Tkinter／ttk 元件。

## 行為與用語

| 原畫面／問題 | 本次調整 |
| --- | --- |
| 保存版本與副本 | **朗讀稿與重載備份**；分清已確認朗讀版本與重載前未存編輯，不當作每次儲存的校對稿歷史。 |
| 逐頁原稿／頁圖 | **PDF 原頁與文字對照**；來源頁圖與單頁文字對照。 |
| 本次文字／原逐頁原稿 | **目前頁面文字／本批次擷取原文**。前者包含尚未保存的辨識修正，後者固定於本批次建立時；尚未重辨時兩者可以相同。人工全文另列 **本批次校對稿**，可能無精確頁次對應。 |
| 候選、批次、PDF 文件混用 | 來源 PDF 是檔案，批次是保存的工作單位；辨識修正先預覽，按 **存成新批次** 才保存。移除命令改為 **移除 PDF 批次**，來源 PDF 保留。 |
| 確認保留／略過本頁 | **本頁已核對／略過本頁警告**，只在有待處理來源警告時啟用；略過會再次說明並確認，保留頁面文字。 |
| 安裝完成 0／0 位元組 | 所選語言模型完整時顯示 **模型已就緒，不需下載** 並停用下載；缺少時為 **下載缺少的模型**。下載錯誤持續顯示供重試。 |
| X 採用本頁候選 | 改為單選列 **這頁存入新批次：使用辨識修正／保留擷取原文**，清楚表示保存內容。 |
| 只能修正一段 | 可逐段框圖、選字、辨識、保留選擇並繼續；最後合為一個新批次。辨識中有活動進度條，完成／關閉後停止。 |

同頁流程：**重辨 → 框選區域重辨… → 框一段圖＋反白對應文字 → 辨識框選區 → 核對結果 → 保留選擇，繼續修正 → 下一段 → 存成新批次**。每次仍是一個區域，並非同時排入多個框。下一段位移以目前保留的文字計算；選擇保留擷取原文時，該頁回到這次操作前的原始基準，再選下一段。失敗／取消下一段會保留先前完成修正。結果僅供新批次重建，原批人工校對全文不自動合併進新批次。

局部修正不代表整頁已核對，新批次仍保留待檢查狀態；需檢查整頁警告後才可確認朗讀。原始 PDF、原批次擷取原文、人工稿與朗讀快照保留。
