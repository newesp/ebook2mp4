# 版本紀錄 v2 交付

依使用者附圖實作。VersionPage以InnerPageHost.content為固定父層，提供版本選擇／唯讀比較、呈現資料及ActionSpec；共用宿主管理唯一返回、標頭及固定操作列。本頁指定不顯示文件摘要帶，其他頁切入時恢復摘要與分隔線。文稿控制器保留版本查詢、備份、還原及任務契約。

## 功能契約

版本選擇保留朗讀稿、編輯備份及AI候選。只有朗讀稿顯示刪除；刪除前確認且取消為預設。還原先備份現稿；備份失敗不替換現稿，過期候選仍依既有契約還原為人工稿。返回保留編輯器游標、選取及捲動。遷移同時保留原有版本選取策略，不強制預選朗讀稿。

## 布局對照

版本選擇固定在內容頂端、比較基準置於其下，唯讀差異佔剩餘高度。差異用紅／綠底標示刪／增。短內容與無版本沒有捲軸，長內容只捲差異區。選單與其他操作沿用Workspace尺寸；底部刪除／還原沿用ActionBar的刪除／主要樣式。

native.json與原尺寸png為1360×820、1280×720及900×640的短／長差異合成資料；對照附圖保留父布局及固定操作分組。原生統一diff可能按整組刪除與新增顯示，與mock逐行示意不同；不改比較演算法。平台字形／主題邊框沿用既有樣式。

## 驗證與範圍

final-tests.txt：版本及文稿／AI／換行宿主相關回歸。針對空→短→長→短、備份無刪除、取消刪除、還原前備份失敗、編輯狀態返回及隱藏頁回呼均有測試。native.json量測長差異到末端時標頭及操作列不動。逐項check-list見同目錄。

build.txt為固定dist/ebook2mp4正式建置；package.json核對封裝與來源；exe-startup.json為隔離啟動與正常退出。完整EXE逐頁人工、其他DPI／最大化／18pt／所有輸入裝置尚無本輪證據，不宣告完整UI驗收完成。
