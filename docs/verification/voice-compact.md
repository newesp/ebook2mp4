# 語音設定與試聽：固定版面

2026-10-30。依 [核准設計](../mock-ui/voice-compact-v1/README.md) 更新。模型保留可編輯的下拉選單，可選既有候選，也可手動輸入；服務端與專案的既有型號驗證維持不變。Gemini 可保存有效格式的新模型 ID；Fish 沿用已支援的兩個型號檢查。

## 變更與原因

原頁面由外層 Canvas 包住三個高面板，底部另占兩列。改為固定 Frame：服務／模型單列、左側聲音與節奏、右側可編輯試聽文字、底部單列操作。試聽文字框是頁面中唯一的捲動區，左側書籍批次清單仍獨立捲動。沒有外層或水平捲軸。

Edge 顯示語系篩選、音色下拉選單與更新按鈕；Gemini 顯示內建音色候選；Fish 顯示聲音 ID 欄，移除不適用的空白表格。非 Edge 服務除隱藏更新按鈕外，執行入口也阻止 Edge 更新。模型欄位在 Gemini／Fish 可下拉及手動輸入，Edge 不需模型設定。

句尾與段落停頓、試聽操作均橫向排列。取消與進度只在忙碌時顯示；忙碌時停用保存、前往製作及設定控制。原本的試聽、保存、返回、取消及釋放流程保留。左右面板依自身實際寬度調整說明文字換行，避免先讀到舊尺寸。

## 驗收路徑

以下依受控語言原則使用短句、單一動作及明確結果。

1. 開啟新版程式 → 開啟專案 → 按「4 試聽與製作」 → 檢查語音頁沒有整頁捲軸。
2. 選擇「Edge-TTS」 → 檢查語系與音色選單 → 按「更新線上音色」 → 檢查更新後可選音色。
3. 選擇「Google Gemini TTS」 → 檢查內建音色候選 → 確認未顯示 Edge 更新按鈕。
4. 展開模型選單 → 選擇候選 → 直接輸入模型 ID → 按「只儲存設定」 → 切換儲存範圍後切回 → 檢查已保存的模型 ID。
5. 選擇「Fish Audio」 → 輸入聲音 ID → 檢查沒有空白音色表或 Edge 更新按鈕。
6. 在試聽框貼入長文 → 捲動文字 → 檢查底部操作列位置不變。超過 3,000 字元時，先縮短文字再產生試聽。
7. 檢查底部操作列 → 確認返回、儲存範圍、只儲存設定及前往製作位於同一列。
8. 使用有效服務、模型與音色 → 按「產生並播放試聽」 → 檢查出現進度與取消 → 按「取消」 → 等待停止 → 檢查上一份成功結果仍可重播。
9. 手動取消傳送同意 → 按「產生並播放試聽」 → 檢查顯示同意提示且未啟動合成。
10. 儲存有效的本批次設定 → 按「儲存並前往製作」 → 檢查在同一主視窗切換至製作頁。正式合成仍需確認朗讀稿。
