# T10 — 已確認朗讀稿產生批次 MP3／SRT

## Parent

[Spec #1：首版 PDF／TXT 書籍校對、總 MP3 與 MP4 製作](https://github.com/newesp/ebook2mp4/issues/1)，核定版本 1.1。

## What to build

將已確認批次朗讀稿依自然節奏完整合成，顯示進度並輸出可播放的 MP3 與正確時間軸 SRT。

## Acceptance criteria

對應 Spec 使用者故事：55、56、59、61、62、63、64、84、85、87、89。對應需求驗收：AC-06、AC-09、AC-10、AC-16、AC-18。

- [ ] 未確認稿不能正式合成；開始時固定文字、音色、語速與規則快照，進行中編輯不混入結果，同專案只執行一個產生成品任務。
- [ ] 保留段落上下文，必要時依句尾／合理分句切塊，不固定短字數硬切；保證內容守恆、順序正確，不切開詞、縮寫、小數、網址、引號／括號或省略號情境。
- [ ] 以自然預設句尾 0／段落 500 毫秒組裝，同邊界不累加、末段無段落尾靜音；保留尾音、呼吸與原標點，不暗改稿或依賴任意自訂 SSML。
- [ ] 區塊保存穩定識別、順序、實際送出文字、內容／設定／規則雜湊、狀態及實測時長；網路錯誤每塊預設最多 3 次嘗試，未全成功不能報完成。
- [ ] 輸出非空可解碼 MP3 與 UTF-8 SRT，採提供者時間或實測完整區塊時間，不虛構逐字；靜音偏移正確、段落新增靜音不維持前段字幕。
- [ ] UI 顯示階段、目前區塊及完成／失敗數，可取消、播放、另存與開啟資料夾；未知時長不捏造百分比。
- [ ] 新成品暫存且驗證後才發布，失敗／取消保護舊成品；TXT 無 PDF／OCR 也能從校對走到真實 MP3／SRT。

- [ ] 本張的 UI、專案保存及公開專案工作流程連接完整，新增必要的行為驗證；檢查可觀察結果而不綁內部類別或函式結構。真實服務／工具的驗證與替身測試分別記錄。
