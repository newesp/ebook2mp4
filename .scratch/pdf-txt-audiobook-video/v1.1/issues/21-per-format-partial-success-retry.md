# T21 — 逐格式完成、列缺項與只重試未完成輸出

## Parent

[Spec #1：首版 PDF／TXT 書籍校對、總 MP3 與 MP4 製作](https://github.com/newesp/ebook2mp4/issues/1)，核定版本 1.1。

## What to build

選擇總 MP3、總 MP4 或兩者；一種缺項或失敗時保留另一種成功成果，整體顯示部分完成並只重試未完成格式。

## Acceptance criteria

對應 Spec 使用者故事：85、86、87、97、100、101。對應需求驗收：AC-18、AC-37、AC-39、AC-40。

- [ ] 全書合併介面可選 MP3／MP4／兩者，保存選擇並逐格式顯示準備、執行、完成、缺項、失敗或取消；全部要求均成功才顯示整體完成，否則標部分完成或相應未完成狀態。
- [ ] 按所選路徑檢查必要輸入：總音訊需要有效批次音訊，總音訊製片需要有效總音訊及全片素材，批次影片合併需要有效批次影片；缺任何批次 MP4 不得阻擋預設製片路徑。
- [ ] 同時要求兩格式但缺全片素材或替代路徑的批次影片時，仍先完成可行總 MP3／SRT，列明影片缺項，保留成功成果，不回滾。
- [ ] 總音訊製片選 MP4 時可重用已有效的總音訊；若需先準備總音訊，依共用設定循序完成，沒有有效音訊時明示前置，不以批次影片代替。兩格式任務遵守單專案一個產出任務。
- [ ] 模擬 MP3 失敗但既有批次影片可合併，以及 MP3 成功但 MP4 失敗；每格式成功即獨立保存其成品與 SRT，不將另一格式狀態當成功或刪除已發布成果。
- [ ] 重開、補素材或重試時，對相同有效來源與設定僅執行未完成格式；若其來源已失效則明示需要更新，禁止為了重試影片而重做仍有效的總 MP3 或呼叫 TTS。
- [ ] 驗證每種輸出選擇、兩條影片路徑、缺項、取消、磁碟不足及部分失敗；對實際成功格式檢查時間軸／檔案，確保沒有成功假象或重複交接。

- [ ] 本張的 UI、專案保存及公開專案工作流程連接完整，新增必要的行為驗證；檢查可觀察結果而不綁內部類別或函式結構。真實服務／工具的驗證與替身測試分別記錄。

## Blocked by

- T19 — 切換合併既有批次影片，產生總 MP4／SRT
