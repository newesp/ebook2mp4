# T20 — 依來源路徑追蹤總音訊與總影片版本

## Parent

[Spec #1：首版 PDF／TXT 書籍校對、總 MP3 與 MP4 製作](https://github.com/newesp/ebook2mp4/issues/1)，核定版本 1.1。

## What to build

針對總 MP3、總音訊製片及批次影片合併分別標示來源版本與待更新狀態，避免無關修改使有效成果失效。

## Acceptance criteria

對應 Spec 使用者故事：49、65、78、82、83、84、99。對應需求驗收：AC-17、AC-29、AC-38。

- [ ] 沿用各產出切片已落實的基本來源／快照／失效資訊，完成跨路徑的連動檢視及重開一致性；每份成品可看到使用的選入批次、設定及來源版本，舊成果保留可播。
- [ ] 總音訊只追蹤已選音訊內容／文字／語音設定及共用選取／順序／停頓；修改未選 C 或任何視覺素材／影片解析度不失效 A／B 的總 MP3。
- [ ] 總音訊製片追蹤總 MP3／SRT 版本及全片視覺設定；總音訊失效或更新使衍生總影片待更新，更換全片視覺僅失效這條總影片。
- [ ] 批次影片合併追蹤選入批次 MP4／SRT 版本及合併設定；選入批次改稿、改音訊或改批次畫面影響相關總影片，未選批次與無關全片背景不影響它。
- [ ] 更改合併選取／順序／停頓使相關總音訊及總影片待更新，不改任何批次成品；改影片解析度只影響相應影片，不重新 TTS。
- [ ] 任務中編輯仍以啟動快照產出並標明是否已非目前版本，不能混入新設定；重新產出拒絕失效來源，更新有效來源後可重建，局部音訊重用不混音色／語速快取。
- [ ] 透過公開工作流程覆蓋 A／B 已選、C 未選、全片與批次背景分開變更、排序／停頓、執行中修改及重開，驗證每條來源的失效範圍。

- [ ] 本張的 UI、專案保存及公開專案工作流程連接完整，新增必要的行為驗證；檢查可觀察結果而不綁內部類別或函式結構。真實服務／工具的驗證與替身測試分別記錄。

## Blocked by

- T13 — 全書語音預設與局部改稿增量合成
- T19 — 切換合併既有批次影片，產生總 MP4／SRT
