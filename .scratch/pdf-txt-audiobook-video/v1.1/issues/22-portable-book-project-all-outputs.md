# T22 — 搬移書籍專案後保留校對、進度與各路徑成果

## Parent

[Spec #1：首版 PDF／TXT 書籍校對、總 MP3 與 MP4 製作](https://github.com/newesp/ebook2mp4/issues/1)，核定版本 1.1。

## What to build

將整個專案資料夾搬移後，繼續校對、合併總音訊或從既有總 MP3 製片，仍保留版本關係與逐格式進度。

## Acceptance criteria

對應 Spec 使用者故事：82、86、87、89、90、91、93、100、101。對應需求驗收：AC-18、AC-19、AC-27、AC-38、AC-39、AC-40。

- [ ] 來源、原稿、校對稿、Gemini 候選、朗讀稿、語音區塊、批次素材、全片素材、批次成品、總 MP3／SRT、兩路徑影片來源及合併設定均以專案相對路徑保存。
- [ ] 來源原檔搬走後仍使用專案副本；整個資料夾搬移重開可讀取內容、來源版本、待更新狀態及各格式成功／失敗進度，重用的快取必須驗證完整及設定一致。
- [ ] 搬移後可離線以已有總 MP3／SRT 及素材繼續製作總 MP4，無須批次影片或新的 TTS；另一個只含有效批次影片的專案也可使用替代合併。
- [ ] 缺檔列明實際缺項及受影響路徑，不報完整成功；缺全片背景不阻擋純音訊，缺批次影片不阻擋總音訊製片，無關批次仍可操作。
- [ ] Gemini API Key 留在本機設定而不入專案，缺金鑰仍可人工校對／使用既有成品；日誌不預設保存全文。
- [ ] 驗證中文／空白／標點路徑、來源已移走、取消／中斷後搬移、不可寫及空間不足，保護舊成品並只重試仍需完成的工作。

- [ ] 本張的 UI、專案保存及公開專案工作流程連接完整，新增必要的行為驗證；檢查可觀察結果而不綁內部類別或函式結構。真實服務／工具的驗證與替身測試分別記錄。

## Blocked by

- T20 — 依來源路徑追蹤總音訊與總影片版本
- T21 — 逐格式完成、列缺項與只重試未完成輸出
