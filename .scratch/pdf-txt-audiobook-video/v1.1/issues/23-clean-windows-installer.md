# T23 — 乾淨 Windows 安裝與內附媒體、OCR 工具

## Parent

[Spec #1：首版 PDF／TXT 書籍校對、總 MP3 與 MP4 製作](https://github.com/newesp/ebook2mp4/issues/1)，核定版本 1.1。

## What to build

在沒有開發工具的 Windows 安裝後，從介面準備 OCR 模型並完成音訊與影片製作，不需輸入命令。

## Acceptance criteria

對應 Spec 使用者故事：3、27、88、89、95。對應需求驗收：AC-06、AC-31。

- [ ] 提供可安裝 Windows 桌面程式，內附 FFmpeg／FFprobe、OCR 引擎與語音／媒體所需執行元件；正常使用無須終端機、自行啟動網頁服務或參考原型正在執行。
- [ ] OCR 模型首次需要時顯示下載大小並提供介面下載／安裝／失敗重試；實際使用隨包工具及模型位置，不借用開發機絕對路徑。
- [ ] 依階段檢查依賴並顯示可採取的處理方式，只阻擋受影響功能；沒有 OCR 模型仍可走 TXT，離線仍可人工校對、保存及利用既有音訊製片。
- [ ] 乾淨 Windows 實測安裝→TXT→確認→TTS→總 MP3／SRT→圖片／背景總 MP4，以及批次 MP4；另驗證模型下載→掃描 PDF→校對稿。
- [ ] 保留環境、套件版本、安裝及實際產出驗證結果，證明無開發環境、系統 FFmpeg 或既裝 OCR 引擎仍可使用。

- [ ] 本張的 UI、專案保存及公開專案工作流程連接完整，新增必要的行為驗證；檢查可觀察結果而不綁內部類別或函式結構。真實服務／工具的驗證與替身測試分別記錄。

## Blocked by

- T05 — OCR 語言模型安裝與掃描 PDF 轉 TXT
- T18 — 以批次 MP3／SRT 製作批次 MP4
