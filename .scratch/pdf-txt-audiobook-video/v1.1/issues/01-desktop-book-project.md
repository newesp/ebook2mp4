# T01 — 桌面建立書籍專案，匯入 TXT 並儲存重開

## Parent

[Spec #1：首版 PDF／TXT 書籍校對、總 MP3 與 MP4 製作](https://github.com/newesp/ebook2mp4/issues/1)，核定版本 1.1。

## What to build

啟動 Windows 桌面程式，建立一本書的專案，匯入 UTF-8 TXT 成為第一個製作批次，查看內容與儲存位置，關閉後重新開啟仍可繼續。

## Acceptance criteria

對應 Spec 使用者故事：1、2、3、5、6、27、88、90、91、93。本張為後續完整流程的可操作起點。

- [ ] 可啟動繁體中文 Windows 桌面程式，依已選 A 版工作台呈現左側書籍／批次、中間來源對照與編輯、右側 Gemini／朗讀確認；TXT 不假造 PDF 頁面。四步驟可返回，尚缺功能顯示原因。
- [ ] UTF-8／UTF-8 BOM TXT 匯入後可查看原文，顯示檔名、大小、可讀狀態、專案位置及來源副本所需空間，不改來源檔。
- [ ] 建立一本書及第一個製作批次的保存格式，來源副本與批次資料採專案相對路徑，記錄格式版本及內容雜湊。
- [ ] 基本校對內容可編輯、儲存並重開；來源原文與工作文字分離，寫入失敗保留前次成功資料並顯示可行錯誤。
- [ ] 不要求 PDF／OCR／Gemini／TTS／FFmpeg 可用才能建立、查看或儲存 TXT 專案。
- [ ] 落實供 UI 呼叫的專案工作流程測試入口，驗證建專案→匯入→保存→重開；具體桌面框架、儲存格式等必要選型在此切片內決定並記錄必要決策。
- [ ] 原型只作互動與版面參考；正式流程使用真實保存及狀態，必要選型遵守 Windows 可安裝及本機處理決策。

- [ ] 本張的 UI、專案保存及公開專案工作流程連接完整，新增必要的行為驗證；檢查可觀察結果而不綁內部類別或函式結構。真實服務／工具的驗證與替身測試分別記錄。

## Blocked by

None (can start immediately).
