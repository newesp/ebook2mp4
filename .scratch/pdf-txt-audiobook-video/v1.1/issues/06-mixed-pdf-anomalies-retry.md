# T06 — 混合 PDF 自動辨識、異常頁確認與旋轉重試

## Parent

[Spec #1：首版 PDF／TXT 書籍校對、總 MP3 與 MP4 製作](https://github.com/newesp/ebook2mp4/issues/1)，核定版本 1.1。

## What to build

混合 PDF 逐頁判斷文字層或 OCR，檢查疑似漏正文的頁面，旋轉或重試，確認異常後才允許朗讀。

## Acceptance criteria

對應 Spec 使用者故事：19、20、21、22、23、24、25、26。對應需求驗收：AC-04、AC-05。

- [ ] 自動模式逐頁判斷，無可用文字層走 OCR，僅有頁碼／少量文字且疑似圖片正文者列待檢查，不報正文完整。
- [ ] 可指定頁強制 OCR、90／180／270 度旋轉後重試，也可只重試失敗頁。
- [ ] 重辨識先產候選並可比較採用，不直接覆蓋已校對內容；成功與失敗頁進度保留。
- [ ] 異常清單包含失敗、空白／無文字及待檢查頁；使用者處理或明確確認保留／略過後才能確認相關批次。
- [ ] 含一頁文字、掃描頁、僅頁碼為文字的圖片正文與空白頁之樣本可走完對照→重試／確認→朗讀稿確認。
- [ ] 修改 PDF 範圍或 OCR 語言／模式產生新候選，不直接取代既有校對稿或成功成品。

- [ ] 本張的 UI、專案保存及公開專案工作流程連接完整，新增必要的行為驗證；檢查可觀察結果而不綁內部類別或函式結構。真實服務／工具的驗證與替身測試分別記錄。
