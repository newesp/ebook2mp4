# T19 — 切換合併既有批次影片，產生總 MP4／SRT

## Parent

[Spec #1：首版 PDF／TXT 書籍校對、總 MP3 與 MP4 製作](https://github.com/newesp/ebook2mp4/issues/1)，核定版本 1.1。

## What to build

切換到「合併既有批次影片」，沿用全書合併設定，將含不同畫面的有效批次 MP4 接成總影片。

## Acceptance criteria

對應 Spec 使用者故事：75、76、77、79、80、81、97、98。對應需求驗收：AC-23、AC-26、AC-30、AC-32、AC-33、AC-37、AC-40。

- [ ] 可從預設總音訊製片切換至合併既有批次影片，共用批次選取／順序／交接停頓；此路徑只要求選入的有效批次 MP4／SRT，不要求先產生總 MP3 或全片共用背景。
- [ ] 拒絕失效／缺漏／不可解碼的選入批次影片並列缺項；混合 720p／1080p 可保持比例統一輸出，音色／語速不同只提示，不重配音、不呼叫 TTS。
- [ ] 按設定在每個相鄰接點額外補靜音，保留原頭尾，新增靜音期間維持前批最後一格且清空字幕；末批後不補停頓，不修改批次原檔。
- [ ] 接點畫面／音訊預覽與正式合併一致，可對照相鄰文字、沿用頁碼警示及返回校對；總字幕依批次影片實際時間軸與新增靜音偏移，不假定與另一條輸出路徑位元相同。
- [ ] 一／二／三批於預設值新增 0／500／1,000 毫秒；可調 0～5 秒，總影片與批次實測長度加停頓差不超過 200 毫秒，字幕不超出結尾 200 毫秒，採既定編碼。
- [ ] 進度、取消、有限重試、播放／另存／開啟資料夾、任務快照與安全發布齊備；離線可合併，失敗保留先前總影片及已成功總音訊。

- [ ] 本張的 UI、專案保存及公開專案工作流程連接完整，新增必要的行為驗證；檢查可觀察結果而不綁內部類別或函式結構。真實服務／工具的驗證與替身測試分別記錄。
