# T07 — Gemini 設定、指定範圍校對與差異採用

## Parent

[Spec #1：首版 PDF／TXT 書籍校對、總 MP3 與 MP4 製作](https://github.com/newesp/ebook2mp4/issues/1)，核定版本 1.1。

## What to build

在工具內設定 Gemini，對批次全文或所選文字提出忠於原文的校對候選，逐段採用或拒絕並保留原稿。

## Acceptance criteria

對應 Spec 使用者故事：38、39、40、41、42、43、44、45、46。對應需求驗收：AC-20、AC-21、AC-27、AC-34。

- [ ] 可保存本機 API Key、選擇／調整模型及測試連線，金鑰不進書籍專案或預設日誌。
- [ ] 啟動前顯示服務、模型與送出範圍，只送選定文字，不自動上傳 PDF／視覺素材。
- [ ] 整批或選取範圍可校對；只修 OCR／轉錄錯字、標點與明顯斷行，不潤飾、翻譯、摘要、刪減或轉繁簡，不確定處保留疑點。
- [ ] 逐段比較原文及候選，提供採用、拒絕與全部採用；保存校對前、候選與採用後版本，可撤回，採用後須重新確認朗讀稿。
- [ ] 失敗、取消、不可用模型或未設定不改原稿、不阻擋人工；候選附原版本，原稿變更時提示差異而不直接覆蓋。
- [ ] 從共用批次文字流程測試，不綁 PDF 入口；PDF 批次可接入後採同一功能，驗證選外內容不變及真實 Gemini 連線。

- [ ] 本張的 UI、專案保存及公開專案工作流程連接完整，新增必要的行為驗證；檢查可觀察結果而不綁內部類別或函式結構。真實服務／工具的驗證與替身測試分別記錄。
