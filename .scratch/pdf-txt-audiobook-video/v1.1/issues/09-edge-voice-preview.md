# T09 — Edge-TTS 音色、語速與短文試聽

## Parent

[Spec #1：首版 PDF／TXT 書籍校對、總 MP3 與 MP4 製作](https://github.com/newesp/ebook2mp4/issues/1)，核定版本 1.1。

## What to build

選擇實際可用音色及語速，播放固定範例或所選校對內容，清楚知道文字將送到線上語音服務。

## Acceptance criteria

對應 Spec 使用者故事：50、51、52、53、54。對應需求驗收：AC-09。

- [ ] 取得並快取可用音色，可手動更新，顯示名稱、語系及服務提供的性別資訊，不靠永久寫死清單。
- [ ] 支援 -20%、-10%、正常、+10%、+20%，預設正常；每次只用明選音色，混合語言不自行切聲。
- [ ] 固定範例及選取文字可試聽，保存實際音色／語速與使用的處理設定供正式合成共用。
- [ ] 音色不可用、網路錯誤及依賴缺項有清楚錯誤，不暗換人聲、不阻擋校對。
- [ ] 試聽可取消並播放成功結果，不需本機 GPU；以服務替身檢查請求設定並執行真實 Edge-TTS 試聽。

- [ ] 本張的 UI、專案保存及公開專案工作流程連接完整，新增必要的行為驗證；檢查可觀察結果而不綁內部類別或函式結構。真實服務／工具的驗證與替身測試分別記錄。
