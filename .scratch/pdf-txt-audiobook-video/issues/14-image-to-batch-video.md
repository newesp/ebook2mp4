# T14：圖片預覽與批次 MP4 輸出

## Parent

[首版規格 #1](https://github.com/newesp/ebook2mp4/issues/1)

## What to build

選擇一張 JPEG／PNG，預覽畫面，以已有有效音訊輸出批次 MP4 與同時間軸 SRT。

## Acceptance criteria

對應核定 spec User Stories：66、67、68、69、72、73、74、87、89。驗收條件：AC-13、AC-14、AC-16、AC-18。

- [ ] 檢查圖片可解碼，複製素材並顯示來源資訊；保持比例、黑邊補齊，透明圖預設黑底，提供畫面預覽。
- [ ] 預設 1080p，可選 720p，16:9、30 fps；圖片持續到該批音訊結束，不重新呼叫 TTS。
- [ ] 只使用與目前朗讀稿／語音設定一致且已完成的音訊，舊成品可播但不能冒充當前來源。
- [ ] 輸出實際 H.264／yuv420p 視訊與 AAC-LC／48 kHz／立體聲音訊，具 faststart，附相同時間軸 SRT。
- [ ] 批次 MP4 與音訊長度差不超過 200 毫秒，字幕順序不重疊且不超出結尾 200 毫秒。
- [ ] 顯示進度、取消、重試、播放、另存及開啟資料夾；執行固定素材／設定快照，取消／錯誤／空間不足不破壞既有成功 MP4。
- [ ] 換圖片／解析度只更新影片；實測為零次 TTS，離線有完整音訊仍可輸出。
- [ ] 本切片的 UI、公開專案工作流程、保存資料及行為測試一併完成；以真實操作及可觀察結果驗證，不以只有內部函式或替身回傳成功代替交付。
