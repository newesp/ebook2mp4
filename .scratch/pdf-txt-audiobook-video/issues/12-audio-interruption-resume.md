# T12：語音斷網、取消及重開後重用有效區塊

## Parent

[首版規格 #1](https://github.com/newesp/ebook2mp4/issues/1)

## What to build

長篇語音途中斷網或取消，重開專案能看到中斷狀態，續作只處理尚未成功的區塊。

## Acceptance criteria

對應核定 spec User Stories：59、60、84、85、86、87、92。驗收條件：AC-12、AC-18。

- [ ] 任務狀態涵蓋等待、執行中、取消中、已取消、失敗、完成；停止後保留已驗證區塊與來源快照。
- [ ] 每塊最多 3 次網路嘗試，耗盡保留錯誤與進度；不無限重試、略過失敗或宣告完整成功。
- [ ] 重開辨識中斷並可續作／重新開始，續作只重做缺少、失敗或驗證不通過的區塊，不重請成功且設定一致的區塊。
- [ ] 不完整／損壞音訊不能重用；組裝取消或磁碟不足不破壞前一份成功 MP3／SRT。
- [ ] 驗證中段斷網→取消→關閉→重開→續作，及執行時修改稿件的快照隔離，介面可回應。
- [ ] 本切片的 UI、公開專案工作流程、保存資料及行為測試一併完成；以真實操作及可觀察結果驗證，不以只有內部函式或替身回傳成功代替交付。

## Blocked by
