# T20：乾淨 Windows 安裝與內附處理工具

## Parent

[首版規格 #1](https://github.com/newesp/ebook2mp4/issues/1)

## What to build

在沒有開發環境、FFmpeg 或 OCR 引擎的 Windows 電腦安裝後，從介面準備模型並完成製作，不需輸入命令。

## Acceptance criteria

對應核定 spec User Stories：3、27、88、89、95。驗收條件：AC-06、AC-31。

- [ ] 交付可安裝桌面程式及必要執行需求，內附 FFmpeg／FFprobe、OCR 引擎與所選語音／媒體實作需用的執行元件，日常不需命令列或自行啟動網頁伺服器。
- [ ] OCR 語言模型首次使用顯示大小並可於介面下載／安裝，失敗可重試；模型管理及依賴檢查使用實際隨附工具。
- [ ] 依階段顯示工具／模型／服務缺項，只阻擋受影響功能；無 OCR 模型仍可走 TXT，離線可人工校對及用既有音訊製片。
- [ ] 乾淨 Windows 實際驗證安裝→TXT 匯入／保存→語音→圖片／背景影片輸出，及模型安裝→掃描 PDF 擷取，保存驗證環境與結果。
- [ ] 安裝包不依賴開發機絕對路徑、開發工具或參考專案正在執行，避免把本機已有工具誤判為已隨包提供。
- [ ] 本切片的 UI、公開專案工作流程、保存資料及行為測試一併完成；以真實操作及可觀察結果驗證，不以只有內部函式或替身回傳成功代替交付。

## Blocked by

- T05：OCR 語言模型安裝與掃描 PDF 轉 TXT
- T15：背景 MP4 裁切、循環與最後一格定格
