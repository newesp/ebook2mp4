# T08：Gemini 長稿分段、取消與部分失敗續作

## Parent

[首版規格 #1](https://github.com/newesp/ebook2mp4/issues/1)

## What to build

長稿分段校對時能看到完成與失敗範圍，取消或重開後保留已完成候選，只重試失敗部分。

## Acceptance criteria

對應核定 spec User Stories：47、86、92。驗收條件：AC-35。

- [ ] 長稿分段請求保留每段來源版本與範圍，順序／全文覆蓋可檢查，不漏段、不重複。
- [ ] 顯示完成、失敗及未完成範圍；成功候選保存，部分結果不報整批完成、不自動改稿。
- [ ] 支援取消、保存重開、重試失敗部分；成功候選不因重試或取消遺失。
- [ ] 原稿已變更時舊候選保留原來源版本並提示衝突，不跨版本套用或覆蓋新編輯。
- [ ] 注入中段網路錯誤、取消與重開，驗證僅失敗範圍重試、候選可逐段採用，介面保持可回應。
- [ ] 本切片的 UI、公開專案工作流程、保存資料及行為測試一併完成；以真實操作及可觀察結果驗證，不以只有內部函式或替身回傳成功代替交付。
