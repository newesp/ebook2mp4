# T17：交接停頓調整、接點預覽與頁碼銜接檢查

## Parent

[首版規格 #1](https://github.com/newesp/ebook2mp4/issues/1)

## What to build

在合併畫面調整交接停頓並預覽接點，檢查 PDF 頁碼重疊／缺口及跨批半句，再決定排序或返回校對。

## Acceptance criteria

對應核定 spec User Stories：76、77、80、81。驗收條件：AC-26、AC-32、AC-33。

- [ ] 批次交接額外停頓預設 0.5 秒，介面可調 0～5 秒並預覽接點，保留原頭尾音訊，不聲稱總間隔恰等於新增值。
- [ ] 預覽維持前批最後一格並清空新增靜音區間字幕，後批字幕依實際停頓偏移；末批後不加停頓。
- [ ] PDF 批次預設起始頁排序、可手動調整；重疊／缺頁明示且允許使用者明確繼續，不自動去重／補頁，TXT 不假造頁碼。
- [ ] 顯示前批結尾與後批開頭文字，能回校對調整半句銜接，不自動跨批移字。
- [ ] 更改停頓／順序只重做總 MP4／SRT，不重做任何批次或 TTS，數值、字幕、畫面及時長可驗證。
- [ ] 本切片的 UI、公開專案工作流程、保存資料及行為測試一併完成；以真實操作及可觀察結果驗證，不以只有內部函式或替身回傳成功代替交付。

- T16：選取批次合併總 MP4／SRT，預設交接 0.5 秒
