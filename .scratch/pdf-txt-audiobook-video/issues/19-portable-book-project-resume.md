# T19：搬移完整書籍專案後繼續製作

## Parent

[首版規格 #1](https://github.com/newesp/ebook2mp4/issues/1)

## What to build

完成多批次與總影片後，將整個專案資料夾搬到新位置，仍可檢查、校對、續作或重建成品；缺少檔案會被明確列出。

## Acceptance criteria

對應核定 spec User Stories：82、86、87、89、90、91、93。驗收條件：AC-18、AC-19、AC-27。

- [ ] 來源、原稿、校對稿、Gemini 候選、朗讀稿、語音區塊、圖片／背景影片、批次與總成品都透過專案相對路徑保存。
- [ ] 來源原檔已搬走仍能使用專案副本；整個書籍資料夾搬移後，所有上述資料與版本關係可讀，已有音訊可離線再製片。
- [ ] 缺檔列出實際缺項及受影響功能，不報完整成功、不阻擋無關批次的可行操作。
- [ ] API Key 保持本機設定、不放入專案；缺金鑰仍能人工校對及使用既有成品。
- [ ] 驗證中文／空白／標點路徑及中斷任務搬移後的有效進度辨識；寫入失敗／空間不足保留既有成功成果，日誌不預設記錄全文。
- [ ] 本切片的 UI、公開專案工作流程、保存資料及行為測試一併完成；以真實操作及可觀察結果驗證，不以只有內部函式或替身回傳成功代替交付。

## Blocked by

- T15：背景 MP4 裁切、循環與最後一格定格
- T18：批次更新後追蹤總影片待更新狀態
