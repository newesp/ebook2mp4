# T13：全書語音預設與局部改稿增量合成

## Parent

[首版規格 #1](https://github.com/newesp/ebook2mp4/issues/1)

## What to build

同書批次可沿用或覆寫語音預設，修改部分校對稿後只重做失效語音；舊成品清楚標待更新。

## Acceptance criteria

對應核定 spec User Stories：10、49、65、83。驗收條件：AC-17、AC-24、AC-25。

- [ ] 新批次沿用全書音色／語速／停頓預設，每批可個別保存設定；更改預設不自動改既有批次。
- [ ] 明確套用到指定舊批才依音色／語速／停頓變化失效相應成品，不影響未選批次。
- [ ] 局部改稿取消該批確認並標舊成品待更新；重新確認後只合成文字／設定／規則不一致的區塊，重用其他有效區塊並重組 MP3／SRT。
- [ ] 快取由實際內容與相關設定／規則識別，不只靠檔名、順序或稿件整體版本；不同音色／語速不得混用。
- [ ] 停頓變更重組及必要切分失效正確；舊成品保留可播且來源可辨，取消／失敗不破壞舊檔。
- [ ] 多批次與插入／修改段落的工作流程測試驗證真正重用，測試外部 TTS 請求數與最終完整內容。
- [ ] 本切片的 UI、公開專案工作流程、保存資料及行為測試一併完成；以真實操作及可觀察結果驗證，不以只有內部函式或替身回傳成功代替交付。

## Blocked by

- T02：同書多 TXT 批次與編碼預覽
- T11：自然／舒緩節奏與自訂句尾、段落停頓
- T12：語音斷網、取消及重開後重用有效區塊
