# T18：批次更新後追蹤總影片待更新狀態

## Parent

[首版規格 #1](https://github.com/newesp/ebook2mp4/issues/1)

## What to build

清楚辨識每份批次與總影片使用的文字及設定版本，只有實際選入內容變更才使相關總影片待更新。

## Acceptance criteria

對應核定 spec User Stories：78、83、84。驗收條件：AC-17、AC-29。

- [ ] 總影片保存選入批次的文字／MP4 版本、順序、解析度及交接設定，舊成品顯示來源版本並可播。
- [ ] 選入 A／B、未選 C 的總影片，A 改稿或更新 MP4 時待更新；C 改稿不影響這份總影片。
- [ ] 新合併只接受與目前文字／批次語音設定一致的有效 MP4；恢復有效批次後可重新合併，不新增 TTS 請求。
- [ ] 總影片自己的選取／順序／解析度／交接設定變更只失效總 MP4／SRT，批次成品不失效。
- [ ] 執行中選入批次被修改時，結果維持任務開始快照並正確標版本，不冒充目前結果；重開後版本關係仍一致。
- [ ] 本切片的 UI、公開專案工作流程、保存資料及行為測試一併完成；以真實操作及可觀察結果驗證，不以只有內部函式或替身回傳成功代替交付。

## Blocked by

- T13：全書語音預設與局部改稿增量合成
- T16：選取批次合併總 MP4／SRT，預設交接 0.5 秒
